Texto:
**“How to Use Claude & MCPs to INSTANTLY Build n8n AI Agents (MASTERCLASS)”**:

---

## **Visão geral**

* O vídeo ensina a criar agentes de IA e fluxos de trabalho n8n automaticamente usando **Claude** e **MCP Servers**.
* São apresentadas **3 abordagens (níveis)** que vão de simples a avançadas.
* Objetivo: com um único prompt, gerar fluxos completos no n8n, prontos para uso.

---

## **Nível 1 – Básico: Claude Desktop + MCP Servers (Remoto)**

* **Como funciona**:

  * Adiciona servidores MCP ao Claude Desktop via arquivo `config.json`.
  * Permite que Claude busque documentação, exemplos e fluxos diretamente de repositórios GitHub.
* **Ferramentas usadas**:

  * `n8n-workflows Docs` (milhares de fluxos prontos)
  * `Context7` (acesso à documentação atualizada)
  * `n8n-mcp Docs` (criação e edição de fluxos)
* **Processo**:

  1. Copiar o JSON com as configurações dos MCP Servers.
  2. Colar no arquivo de configuração do Claude Desktop.
  3. Reiniciar Claude Desktop para ativar os servidores.
  4. Usar um prompt no Claude para gerar um fluxo n8n baseado em exemplos e documentação.
* **Limitação**: sem Docker, não é possível executar todas as funções do n8n-mcp.

---

## **Nível 2 – Intermediário: Claude Desktop + Docker (MCP Local)**

* **Como funciona**:

  * Instala o MCP Server localmente via Docker para liberar todas as funções.
  * Claude consegue criar, editar e escrever fluxos diretamente na sua conta n8n.
* **Ferramentas usadas**:

  * Docker Desktop (executa o servidor MCP local)
  * Warp (terminal com IA para simplificar comandos)
* **Processo**:

  1. Instalar Docker Desktop (Windows/Mac).
  2. Usar Warp para configurar o MCP Server localmente.
  3. Atualizar o arquivo `config.json` do Claude Desktop com URL e API Key do n8n.
  4. Reiniciar Claude e acessar até **38 funcionalidades** do n8n-mcp.
* **Benefício**: cria fluxos completos no n8n sem precisar copiar e colar JSON manualmente.

---

## **Nível 3 – Avançado: Claude + Docker + Cursor**

* **Como funciona**:

  * Usa o **Cursor** (editor de código com IA) para gerenciar grandes repositórios de fluxos e agentes.
  * Permite Claude interagir com milhares de arquivos JSON e criar fluxos complexos com agentes.
* **Ferramentas usadas**:

  * Cursor (acesso a todos os arquivos e integração com Claude)
  * Docker (executa MCP local)
  * Repositórios com agentes e fluxos (agent tools e workflows)
* **Processo**:

  1. Abrir Cursor e configurar MCP Servers no arquivo `config.json`.
  2. Importar pastas com agentes e fluxos prontos no Cursor.
  3. Enviar prompts para Claude criar fluxos que combinam automações e agentes.
  4. Claude pode validar, corrigir erros e até criar diagramas dos fluxos.
* **Benefício**: geração de **workflows multiagente** completos, sem limitações de contexto ou tamanho.

---

## **Principais Repositórios no GitHub**

* **n8n-workflows (Zie619)**
  [https://github.com/Zie619/n8n-workflows](https://github.com/Zie619/n8n-workflows)
  → Contém milhares de fluxos de trabalho n8n prontos.

* **Context7 (Upstash)**
  [https://github.com/upstash/context7](https://github.com/upstash/context7)
  → Fornece documentação atualizada para diversos serviços.

* **n8n-mcp (PromptAdvisers)**
  [https://github.com/promptadvisers/n8n-mcp](https://github.com/promptadvisers/n8n-mcp)
  → MCP Server para criação e gestão de fluxos no n8n.

---

## **Principais Conceitos**

* **MCP (Multi-Context Protocol)**: permite que Claude acesse várias APIs e funcionalidades com uma única chave.
* **Remote MCP**: mais fácil de configurar, ideal para iniciantes.
* **Local MCP (Docker)**: mais potente, necessário para criar fluxos diretamente no n8n.
* **Cursor**: editor com IA que elimina limitações de contexto e facilita trabalhar com grandes volumes de dados.

---

## **Destaques**

✅ Claude pode **diagnosticar e corrigir** fluxos automaticamente.
✅ Possibilidade de criar **exércitos de agentes de IA** no n8n.
✅ Integração total com GitHub, Docker e editores avançados como Cursor.
✅ Métodos acessíveis tanto para iniciantes como para desenvolvedores experientes.
