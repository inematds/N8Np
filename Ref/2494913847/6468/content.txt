**Resumo do vídeo: Este agente n8n cria e edita imagens com a nova API de imagens da OpenAI**

- A OpenAI lançou sua nova API de geração de imagens (gpt-image-1), que também suporta DALL-E 2 e DALL-E 3.
- O vídeo ensina como usar a API para criar e editar imagens através do n8n, usando um sistema dividido em três fluxos principais:

1. **Criação de Imagens**:  
   - O usuário envia um prompt via gatilho de chat.
   - O agente IA do n8n identifica a intenção e cria imagens com as configurações escolhidas (modelo, qualidade, tamanho).
   - As imagens são salvas automaticamente no Google Drive.

2. **Edição de Imagens**:  
   - Permite modificar imagens já criadas, usando um link de imagem salvo no Google Drive.
   - As imagens são alteradas conforme o novo prompt e também salvas no Drive.
   - Existe uma opção experimental para editar imagens externas (fora do Drive), mas pode falhar.

3. **Registro em Planilha**:  
   - Cada operação (criação ou edição) é registrada automaticamente em uma planilha Google Sheets.
   - Guarda informações como link da imagem, tipo de operação, modelo utilizado e o prompt.

- O sistema é projetado para ser simples: você pode gerar, editar e acompanhar imagens de forma organizada.
- A automação usa conversão de imagens em formato base64 para movimentação interna antes do upload no Drive.
- Para múltiplas imagens, o sistema separa e gera vários links de acesso.
- Todos os fluxos (subworkflows) estão disponíveis para download gratuito no Gumroad do criador.

---

**Fluxos disponíveis:**
- Orquestrador principal (AI Agent)
- Criação de imagem
- Edição de imagem
- Registro no Google Sheets

API de imagem OpenAI Agentes 🤖 🖼️ n8n



Subfluxo de Criação de Imagem: Basta inserir um prompt, modelo e configurações para criar visuais impressionantes — automaticamente salvos no seu Google Drive.

Subfluxo de Edição de Imagem: Modifique imagens existentes com prompts detalhados (ex.: “substituir bola por osso”) e envie os resultados diretamente para a nuvem.

Subfluxo de Registro no Google Sheets: Cada prompt, modelo e link de saída é armazenado automaticamente em uma planilha do Google — perfeito para auditorias ou bibliotecas de inspiração.

Fluxo Principal de Orquestração de IA: Um roteador inteligente que pega prompts em linguagem natural e envia para a ferramenta correta (criar/editar) com base na tarefa.

Todos os arquivos JSON dos fluxos de trabalho estão incluídos, para que você possa importar, modificar e escalar instantaneamente.

Nenhuma configuração extra necessária — inclui credenciais pré-mapeadas e lógica de pastas para os fluxos de trabalho do Google Drive.

❤️ Minha equipe e eu dedicamos muito tempo para criar este pacote e tornar sua jornada com IA mais tranquila — se isso ajudar você, agradeceríamos muito seu apoio adquirindo e compartilhando com outros.

Resumo  
Um kit de ferramentas poderoso para quem quer aproveitar a nova API de Imagem da OpenAI — criar, editar e organizar ativos visuais em minutos usando linguagem natural e n8n.

Visão geral do fluxo de trabalho  
Você envia seu pedido via gatilho de chat

Esse gatilho de chat irá recusar o pedido se for muito vago

Enviará esse pedido para criar ou editar a imagem

Registrará esse pedido na planilha do Google (você precisará configurar suas credenciais para isso)

Recursos  
- Fluxo Principal de Orquestração de Agentes de IA  
- Subfluxo de Criação de Imagem  
- Subfluxo de Edição de Imagem  
- Subfluxo de Registro na Planilha do Google
