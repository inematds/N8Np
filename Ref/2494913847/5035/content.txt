### **🧠 Fluxo Completo do Agente de IA 2.0 para Vídeos Anônimos Animados**

---

### **1. Entrada: Definir o tema do vídeo**
- Criar um campo no Google Sheets com:
  - Título
  - Categoria do vídeo (ex: “história de um pato na selva”)
  - Status de postagem (YouTube, Instagram, TikTok)
  - URL do vídeo
  - Captions
  - Horário de postagem

---

### **2. Geração do Roteiro com DeepSeek AI**
- Criar um nó HTTP Request:
  - Método: POST
  - Modelo: `deepseek-coder`
  - Prompt: “Você é um roteirista de vídeos curtos no YouTube. Crie uma micro-história cativante de 15 segundos sobre [tema].”
- Retorna um pequeno texto (roteiro narrativo curto)

---

### **3. Narração com ElevenLabs**
- Criar um novo nó:
  - Método: POST
  - URL: `https://api.elevenlabs.io/v1/text-to-speech/[VOICE_ID]`
  - Enviar o texto gerado pelo DeepSeek AI
  - Retorna arquivo de áudio `.mp3`
- Salvar o áudio no Google Cloud Storage
  - Nomear com ID único (para evitar cache)

---

### **4. Transcrição com OpenAI Whisper**
- Fazer um POST para `https://api.openai.com/v1/audio/transcriptions`
  - Enviar o `.mp3` gerado
  - Retorna o texto do áudio (transcrição)
- Esse texto será usado para gerar imagens

---

### **5. Geração de Prompts de Imagem com Together AI**
- Quebrar o texto em trechos (ex: 3 frases)
- Para cada trecho:
  - Criar prompt com o seguinte comando:
    - “Você é um designer de prompts para IA de imagem. Converta esse trecho em um prompt detalhado de imagem no estilo [fantasia, realista, Pixar etc.].”
- Retorna prompts de imagem

---

### **6. Geração de Imagens com modelo Flux**
- Enviar cada prompt para a API Together AI (modelo Flux)
  - Recebe imagens em `base64`
  - Converter `base64` em imagem `.jpg`
  - Salvar no Google Cloud

---

### **7. Criar Animação com Hailuo AI**
- Enviar a primeira imagem para a API da Hailuo (Minimax)
  - Parâmetros:
    - `first_frame_image`: URL da imagem no Google Cloud
    - `prompt`: texto do roteiro
  - Monitorar status (loop de 30s)
  - Quando pronto: fazer download do `.mp4`
  - Salvar no Google Cloud

---

### **8. Montagem do Vídeo com AnyNoCode**
- Combinar:
  - Áudio (.mp3)
  - Animação (.mp4)
  - Música de fundo (opcional)
  - Legenda (transcrição)
- Chamada via API do AnyNoCode:
  - Criação de vídeo final
  - Esperar processamento (loop de 30s)
  - Obter link final do vídeo renderizado

---

### **9. Atualizar Google Sheets**
- Preencher:
  - Título do vídeo
  - URL final do vídeo
  - Status: “Pendente” para cada rede
  - Caption gerada via prompt:  
    - “Crie um título cativante e uma legenda de até 500 caracteres, com emojis e CTA.”

---

### **10. Publicação automática nas plataformas**

#### **YouTube**
- Agendador (Trigger diário)
- Se status = "Pendente"
  - Posta usando API do YouTube
  - Atualiza status = "Postado"

#### **Instagram Reels**
- Usar token da Meta (Gerado no Graph API Explorer)
- Posta usando API `instagram_graph_api`
- Espera 1 minuto para confirmar
- Atualiza status no Google Sheets

#### **TikTok (conta privada)**
- Criar app em `https://developers.tiktok.com`
- Obter:
  - `client_key`, `client_secret`, `scope`, `redirect_url`
- Fazer upload com chunk:
  - Etapas:
    1. Gerar URL de upload
    2. Enviar vídeo em partes
    3. Finalizar o upload
- Marcar como conteúdo AIGC (gerado por IA)
- Atualiza status no Google Sheets

---

**Resumo direto do tutorial [V2.0 – Agente de IA para Vídeos Anônimos Animados]**

**Objetivo:**  
Criar vídeos anônimos curtos e animados com IA e publicar automaticamente no YouTube, Instagram e TikTok.

---

**Ferramentas utilizadas:**
- DeepSeek AI – roteiro curto
- ElevenLabs – narração
- OpenAI Whisper – transcrição
- Together AI (modelo Flux) – imagens
- Hailuo AI – animação
- Google Cloud – armazenamento
- AnyNoCode – renderização
- Google Sheets – controle
- APIs do YouTube, Instagram, TikTok

---

**Fluxo dividido em 4 etapas principais:**

1. **Geração de roteiro e áudio**
   - DeepSeek AI cria texto (ex: “história de um pato na selva”)
   - ElevenLabs transforma em voz
   - Salva o áudio no Google Cloud

2. **Imagens e prompts**
   - Transcreve o áudio com Whisper
   - Cria prompts com Together AI
   - Gera imagens com modelo Flux
   - Salva imagens no Google Cloud

3. **Animação**
   - Usa primeira imagem e cria animação com Hailuo AI
   - Acompanha status até completar

4. **Renderização do vídeo**
   - Junta voz, imagens e música
   - Gera o vídeo final com AnyNoCode
   - Salva no Google Cloud

---

**Publicação automática:**

- **YouTube:** via API Google (requisição + upload)
- **Instagram:** via API Meta (Reels)
- **TikTok:** apenas para contas privadas (API + upload em blocos)

---

**Extras:**
- Todos os dados são organizados no Google Sheets
- Templates prontos disponíveis na comunidade AnyNoCode
- Suporte técnico e chamadas mensais incluídas (plano pago)

---
