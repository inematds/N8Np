**Raspador de agente de IA baseado em visão**  
*Com Google Sheets, ScrapingBee e Gemini*

**O que isso faz?**

1. **Disparo Manual**  
   Você inicia o processo manualmente (é só clicar em “Testar fluxo de trabalho” e ver a mágica acontecer).

2. **Captura de Alvos**  
   Ele busca uma lista de URLs de sites a partir de uma planilha no Google Sheets — sua própria lista de lugares a serem raspados.

3. **Preparação dos Dados**  
   Define e configura cada URL do site a ser processado.

4. **Captura Visual**  
   Utilizando o ScrapingBee, tira uma captura de tela de página inteira de cada URL, pegando todos os detalhes visuais (como tirar uma foto da sua página favorita).

5. **Plano B – Backup em HTML**  
   Se a captura de tela não for suficiente, ele baixa o HTML da página como alternativa (porque até os melhores fotógrafos precisam de uma segunda opinião às vezes).

6. **Entra o Agente de IA**  
   O modelo Gemini Chat (baseado no Gemini-1.5-Pro) entra em ação para analisar a captura de tela — e, se necessário, o HTML convertido em Markdown — e extrair informações importantes como títulos de produtos, preços, marcas e promoções.

7. **Organização dos Dados**  
   Os dados extraídos são organizados em um formato JSON estruturado.

8. **Divisão e Armazenamento**  
   Por fim, os dados são divididos em linhas individuais e adicionados a uma aba chamada “Resultados” na planilha do Google Sheets, deixando tudo organizado em um só lugar.

**Recursos**  
- Modelo JSON estruturado (para facilitar o uso dos dados em outras aplicações)
