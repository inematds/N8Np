Para descobrir o seu **chat ID** no Telegram (necessário para o *Human-in-the-Loop* no n8n), siga este passo a passo simples:

---

### **Passo a passo para descobrir o chat ID no Telegram**

#### **Opção 1: Usando o Bot ****@userinfobot**** (mais fácil)**

1. Abra o Telegram no celular ou desktop.
2. Pesquise e inicie uma conversa com o bot:
   **`****@userinfobot****`**
3. Clique em **Iniciar** (ou **Start**).
4. Ele responderá com algo assim:

   ```   ID: 123456789
   First Name: SeuNome
   Username: @seu_usuario
   ```
5. C**opie o número que aparece no campo “ID” **– esse é o seu c**hat ID pessoal.**

---

#### O**pção 2: Para grupos ou canais (caso esteja usando com equipe)
**
1. Adicione seu bot ao grupo.
2. Envie uma mensagem qualquer no grupo.
3. Vá até o n**8n ou use um webhook **com a função "esperar por mensagem".
4. A mensagem capturada trará algo como:

    ```  "chat": {
     "id": -123456789,
     "title": "Nome do Grupo",
     ...
   }
   
```5. O número com sinal negativo (`-123456789`) é o c**hat ID do grupo.**

---

#### I**mportante:
**
* Se o chat ID c**omeça com “-”,** é um grupo.
* Se o chat ID é p**ositivo,** é uma conversa privada (1:1 com seu bot).

Aqui estão **hacks e boas práticas** para otimizar seu fluxo *Human-in-the-Loop* com n8n, baseado no vídeo e nas melhores implementações:

---

### **1. Use `Set` para normalizar dados**

Antes de enviar qualquer informação à IA, use um nó **Set** para:

* Padronizar campos (`from`, `subject`, `snippet`, etc.).
* Remover ruídos desnecessários no input da IA.
* Garantir que os dados venham sempre no mesmo formato.

---

### **2. Reutilize o mesmo fluxo com `Execute Workflow`**

Em vez de duplicar lógica:

* Use o nó *Execute Workflow* para **reativar o fluxo original** com novas variáveis (ex: nova sugestão de resposta).
* Isso evita complexidade e mantém o sistema escalável.

---

### **3. Estruture a saída da IA com `Structured Output Parser`**

Sempre ative a opção:

* `Require Specific Output Format`
* Escolha `Structured Output Parser` e defina um **modelo JSON fixo**.

Exemplo:

```{
  "original_email": "",
  "from": "",
  "sender_email": "",
  "sender_sentiment": "",
  "reply_body": "",
  "subject": "",
  "thread_id": ""
}```

Isso garante que você sempre tenha os dados certos para uso posterior.

---

### **4. Faça a validação com `If` baseado no texto “ok”**

* Use o nó `If` com:

  * `{{ $json.text }}` igual a `"ok"`
* **Lembrete:** o valor é **case sensitive**. Faça uma transformação `.toLowerCase()` se quiser aceitar variações.

---

### **5. Evite loops infinitos com controle de tentativas**

* Adicione uma variável de controle (ex: `retry_count`) para limitar quantas vezes o e-mail pode ser reescrito.
* Exemplo: se `retry_count > 3`, envie para um humano direto ou finalize com erro.

---

### **6. Substitua o Telegram por outras ferramentas se necessário**

* Pode usar **Slack, Discord, WhatsApp Business, Email, Webhook** etc.
* Ideal para adaptar o fluxo à equipe ou cliente final.

---

### **7. Faça log de decisões**

* Use `Append to Google Sheet`, `Airtable` ou `Notion` para registrar:

  * E-mail original
  * Resposta da IA
  * Feedback humano
  * Decisão final

---

### **8. Use o prompt da IA como variável externa**

* Armazene o prompt em um campo do tipo texto ou variável externa.
* Assim, você pode **ajustar o comportamento da IA sem mexer no fluxo**.

---

### **9. Simule mensagens para testes**

* Crie um segundo trigger para testar o fluxo com dados simulados (sem esperar e-mail real).
* Exemplo: `Webhook Manual Trigger` com JSON de exemplo.

---

### **10. Acelere com Templates**

* Crie **subfluxos prontos (Sub-workflows)** para:

  * Verificar sentimento
  * Validar entrada
  * Reescrever com base em sugestões
* Isso agiliza a criação de novas automações baseadas nesse modelo.

Aqui está o **passo a passo completo** para montar a automação *Human-in-the-Loop* com **n8n**, conforme mostrado no vídeo:

---

### **1. Criar o fluxo no n8n**

* Crie um novo workflow no n8n.

---

### **2. Adicionar o gatilho do Gmail**

* **Nó:** *Gmail → Trigger (New Email)*
* Configure a autenticação com uma conta do Gmail.
* Defina os filtros de recebimento (por exemplo, assunto ou pasta).
* Este nó detectará automaticamente os e-mails recebidos com feedbacks.

---

### **3. Criar o agente de resposta com IA**

* **Nó:** *AI Agent (HTTP ou OpenRouter/ChatGPT)*

* Configure com o modelo GPT (ex: OpenRouter com GPT-4 ou GPT-3.5).

* **Prompt sugerido:**

  ```  Você é um assistente de IA que responde e-mails de feedback para um restaurante.

  ---
  ID do Tópico: {{ $json.threadId }}
  De: {{ $json.From }}
  Assunto: {{ $json.Subject }}
  Trecho: {{ $json.snippet }}
  Sugestão anterior: {{ $json.suggestion || 'N/A' }}
  ---

  1. Determine se o feedback é positivo, negativo ou indefinido.
  2. Resuma os principais pontos.
  3. Escreva uma resposta adequada.
  4. Adicione rodapé fixo.
  5. Assine como "Equipe do Restaurante Andy".
  ```

* **Habilite o output estruturado** com o seguinte JSON:

  ```  {
    "original_email": "",
    "from": "",
    "sender_email": "",
    "sender_sentiment": "",
    "reply_body": "",
    "subject": "",
    "thread_id": ""
  }
  ```

---

### **4. Enviar mensagem no Telegram para revisão**

* **Nó:** *Telegram → Send & Wait for Response*
* Configure o Bot do Telegram.
* Envie uma mensagem ao humano com:

  ```  Você recebeu um e-mail de {{ $json.output.from }} com sentimento {{ $json.output.sender_sentiment }}.
  Conteúdo original:
  {{ $json.output.original_email }}

  Resposta sugerida:
  Assunto: {{ $json.output.subject }}
  Corpo: {{ $json.output.reply_body }}

  Para aprovar, responda com "ok".
  ```

---

### 5**. Adicionar lógica condicional
**
* N**ó: ***If*
* Verifique se a resposta recebida no Telegram é e**xatamente **o`k.`

  * S**e sim **→ vá para envio do e-mail.
  * S**e não **→ vá para reescrita com base na sugestão.

---

### 6**. Se aprovado: enviar e-mail de resposta
**
* N**ó: ***Gmail → Send Email (Reply)*
* Use os seguintes campos:

  * T**hread ID: **{{ \$json.output.thread\_id }}
  * M**ensagem: **{{ \$json.output.reply\_body }}
  * F**ormato: **Texto simples (`text`)
* Desative a opção “append attribution” se não quiser a assinatura do n8n.

---

### 7**. Se reprovado: coletar sugestão e reexecutar
**
* N**ó: ***Set*

  * Campos:

    * s`uggestion `→ conteúdo da resposta humana
    * f`rom,` s`ubject,` s`nippet,` t`hread_id,` etc.

* N**ó: ***Execute Workflow*

  * Escolha o m**esmo workflow **atual para reiniciar o ciclo.
  * Adicione outro gatilho:

    * *Trigger → Executado por outro workflow*
    * Mapeie os mesmos campos: s`uggestion,` f`rom,` s`ubject,` etc.

---

### 8**. Testar o workflow
**
* Envie um e-mail para a conta conectada.
* Verifique se:

  * A IA gera a resposta.
  * O Telegram recebe a sugestão.
  * Ao responder “ok”, o e-mail é enviado.
  * Se responder com sugestão, o fluxo reinicia e apresenta nova resposta.

---

### C**uidados
**
* Use e**-mails diferentes **para envio e recebimento (evita erro de envio).
* "**ok" deve ser minúsculo,** ou o fluxo de reescrita será ativado.
* Teste com vários tipos de feedback: positivo, negativo e indefinido.

---

### D**ica final
**
O modelo pode ser adaptado para:

* WhatsApp, Slack, Discord, Outlook.
* Outras tarefas como aprovação de artigos, imagens, posts e atendimento.

**Resumo “\[Free Template] Your AI Never Send a Bad Email Again – AI Replies with Human Approval”**


### **Resumo Geral**

O vídeo ensina como criar um sistema em n8n que:

1. **Recebe um e-mail de feedback de cliente** (restaurante como exemplo).
2. **Gera automaticamente uma resposta com IA**.
3. **Envia a sugestão de resposta para um humano no Telegram**.
4. **Espera aprovação ou ajustes**.
5. **Envia o e-mail final ao cliente se aprovado**.
6. **Se reprovado, reescreve com base na sugestão humana e reenvia para aprovação**.

---

### **Etapas e Funcionalidades**

1. **Criação do Agente de E-mail (Email Agent):**

   * Usa um modelo de IA (ex: OpenRouter + GPT-4).
   * Analisa o sentimento do e-mail: positivo, negativo ou indefinido.
   * Resume o feedback.
   * Gera uma resposta com base no tipo de sentimento.
   * Aplica rodapé fixo e assinatura.

2. **Configuração do Human-in-the-Loop:**

   * Envia o rascunho da resposta para o Telegram via n8n.
   * Aguarda o comando "ok" (minúsculo) para continuar.
   * Se não for “ok”, coleta sugestão e executa nova tentativa com base na sugestão.

3. **Estrutura de Fluxo Condicional (If Node):**

   * Se a resposta for "ok", envia o e-mail.
   * Se não, reexecuta o processo com os ajustes feitos.

4. **Envio de E-mail Final (Gmail Node):**

   * Usa dados como `thread_id`, `from`, `subject`, `body` e `snippet`.

---

### **Detalhes Técnicos**

* **Prompt IA:** pré-formatado, com campos para análise e resposta.
* **Saída em JSON estruturado:** para fácil manipulação posterior.
* **Reutilização do fluxo via “Execute Workflow”**: permite reaproveitar lógica para reescrever e-mails.

---

### **Dicas Importantes**

* O sistema é **case-sensitive**: precisa digitar "ok" em minúsculo.
* **Não use o mesmo e-mail como remetente e destinatário** durante os testes.
* O modelo pode ser personalizado e baixado na **comunidade gratuita do autor**.

---

### **Conclusão**

A automação com IA no n8n usando o *Human-in-the-Loop* permite criar um fluxo confiável, onde a IA ajuda a economizar tempo, mas o humano mantém o controle de qualidade.
É ideal para quem quer automatizar atendimento com personalização e segurança, especialmente em negócios como restaurantes.

---

### **Exemplos de Aplicação**

* Atendimento ao cliente em lojas online.
* Respostas automáticas a e-mails de suporte.
* Aprovação de mensagens para redes sociais.
* Respostas a reviews no Google ou TripAdvisor.
