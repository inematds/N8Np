Esse link que você colocou:

[https://www.notion.so/profile/integrations/internal/](https://www.notion.so/profile/integrations/internal/)

é o **atalho direto** para acessar suas **integrações internas no Notion**. É exatamente onde você pode:

- Ver as integrações já criadas  
- Criar uma nova integração (clicando em “+ New integration”)  
- Copiar o **token secreto da API** (Internal Integration Token)

### Dica importante:
Depois de criar a integração, **não esqueça de dar acesso à página ou banco de dados** que você quer usar com a API:

1. Abra a página ou banco de dados no Notion.
2. Clique em **"Compartilhar"** (Share).
3. Na lista de permissões, selecione sua integração e ative o acesso.

Para obter a chave de API (token de integração) do Notion, siga este passo a passo:

1. Acesse o link oficial do Notion para criar integrações:  
   [https://www.notion.com/my-integrations](https://www.notion.com/my-integrations)

2. Clique em **"New integration"** (Nova integração).

3. Preencha os campos obrigatórios, como:
   - **Name** (nome da integração)
   - **Associated workspace** (escolha o espaço de trabalho)
   - Marque as permissões necessárias, como leitura e escrita.

4. Após criar a integração, você verá o **"Internal Integration Token"** (token de integração interna). Copie esse token — ele será sua **API Key**.

5. Depois disso, vá até a página ou banco de dados do Notion que você deseja acessar via API e:
   - Clique em **"Compartilhar"**
   - Selecione a integração que você criou para **conceder acesso**.
