Aqui estão os principais parâmetros disponíveis para a chamada `https://youtube.googleapis.com/youtube/v3/search?` (método `search.list`) da YouTube Data API v3:

---

### 🔧 Parâmetros obrigatórios

* `part` (string): define quais partes do recurso de resposta devem ser retornadas, geralmente `snippet` ([developers.google.com][1]).

---

### Parâmetros de busca e filtragem

* `q` (string): termo de busca; suporta operadores booleanos como `|` (OU) e `-` (NÃO) ([developers.google.com][2]).
* `type` (string): filtra por tipo de recurso. Valores: `video`, `channel`, `playlist` (pode combinar, ex: `video,channel`) ([developers.google.com][1]).
* `channelId` (string): retorna resultados apenas de um canal específico ([reddit.com][3]).
* `relatedToVideoId` (string): retorna vídeos relacionados; requer `type=video` ([developers.google.com][1]).
* `topicId` (string): filtra vídeos por tópico Freebase ([developers.google.com][1]).

---

### Parâmetros de ordenação e limites

* `order` (string): define a ordem dos resultados. Valores possíveis: `date`, `rating`, `relevance`, `title`, `videoCount`, `viewCount` .
* `maxResults` (integer): número máximo de itens por página (1–50) ([reddit.com][3]).
* `pageToken` (string): token para paginação, obtido via `nextPageToken` ou `prevPageToken` da resposta ([developers.google.com][2]).

---

### Parâmetros de filtros avançados

* `publishedAfter` / `publishedBefore` (datetime RFC3339): filtra por data de publicação ([developers.google.com][2]).
* `regionCode` (string): filtra vídeos disponíveis em um país (código ISO 3166-1 α‑2) ([developers.google.com][2]).
* `relevanceLanguage` (string): define o idioma prioritário de relevância (ISO 639‑1 ou `zh‑Hans`/`zh‑Hant`) ([developers.google.com][2]).
* `safeSearch` (string): controla filtragem de conteúdo sensível. Valores: `none`, `moderate` (padrão) ([developers.google.com][2]).

---

### Parâmetros para vídeos (com `type=video`)

* `videoCaption`: filtra por vídeos com legendas; valores: `none`, `any`, `closedCaption`, `ytClosedCaption` .
* `videoCategoryId`: filtra por categoria do vídeo (ID numérico, ex: `22` para People & Blogs) ([developers.google.com][1]).
* `videoDefinition`: filtra pela definição. Valores: `any`, `standard`, `high` ([developers.google.com][1]).
* `videoDimension`: filtra entre `2d`, `3d`, `any` .
* `videoDuration`: filtra por duração. Valores: `any`, `short` (<4min), `medium` (4–20min), `long` (>20min) .
* `videoEmbeddable`: restringe a vídeos que podem ser incorporados. Valores: `any`, `true` ([developers.google.com][1]).
* `videoLicense`: tipo de licença. Valores: `any`, `creativeCommon`, `youtube` .
* `videoSyndicated`: filtra vídeos divulgáveis fora do YouTube. Valores: `any`, `true` .
* `videoType`: filtra por tipo de vídeo. Valores: `any`, `episode`, `movie` .

---

### Parâmetros de localização

* `location` + `locationRadius`: busca vídeos com geolocalização dentro de raio. Ex: `location=37.42307,-122.08427&locationRadius=5km` ([developers.google.com][1]).

---

### Outros parâmetros úteis

* `forContentOwner` / `onBehalfOfContentOwner`: para parceiros com múltiplos canais ([developers.google.com][1]).
* `quotaUser`: string para atribuir cota de uso ([developers.google.com][1]).
* `prettyPrint`: formata JSON com indentação (`true`/`false`) .
* `oauthToken`: token OAuth 2.0 para acesso autenticado ([developers.google.com][1]).

---

### 📝 Lista resumida com exemplos

| Parâmetro                                | Valores / Obs.                                |                     |
| ---------------------------------------- | --------------------------------------------- | ------------------- |
| part                                     | `snippet` (obrigatório)                       |                     |
| q                                        | termo de busca com booleanos (\`gatos         | cachorros -briga\`) |
| type                                     | `video`, `channel`, `playlist`, etc.          |                     |
| channelId                                | ID do canal

! Abaixo está o **passo a passo completo do fluxo ** “Faceless Video Research System That Makes You $20K/yr”, com foco na criação de **dois fluxos automatizados no n8n**: um para **pesquisar vídeos recentes** e outro para **monitorar o crescimento diário das visualizações**.

---

## ⚙️ FLUXO 1: Pesquisa de Vídeos Recentes por Nicho

### Objetivo:
Buscar vídeos recentes no YouTube de um nicho específico (ex: "bedtime stories") e salvar no Google Sheets com os dados essenciais.

### Passo a passo:

1. **Agendador (Schedule Trigger)**
   - Defina para rodar diariamente (ou conforme desejado).
   - Exemplo: a cada 24h.

2. **Google Sheets – Carregar IDs Existentes**
   - Conecte sua planilha do Google com o n8n.
   - Use `Get Rows` para obter os IDs de vídeos já armazenados (evita duplicação).

3. **HTTP Request – Buscar vídeos no YouTube**
   - Método: GET  
   - URL: `https://youtube.googleapis.com/youtube/v3/search`
   - Parâmetros:
     - `q`: palavra-chave (ex: bedtime stories)
     - `publishedAfter`: data de ontem no formato ISO
     - `part`: snippet
     - `type`: video
     - `videoDuration`: long
     - `maxResults`: 50
     - `regionCode`: US
     - `key`: sua API Key do YouTube

4. **Loop de Paginação (While Loop ou IF + WAIT)**
   - Verifica se há `nextPageToken`.
   - Se sim, espera 5 segundos e faz nova requisição para continuar coletando resultados.

5. **Split Items**
   - Divide o JSON de retorno em vídeos individuais para processar um por um.

6. **Filtro – Remover vídeos já existentes**
   - Compara os `videoId` com os IDs existentes carregados do Google Sheets.
   - Mantém apenas vídeos novos.

7. **Inserção no Google Sheets**
   - Use `Append Row`.
   - Colunas:
     - `Video ID`: `id.videoId`
     - `Título`: `snippet.title`
     - `URL`: `https://youtube.com/watch?v={{videoId}}`
     - `Canal`: `snippet.channelTitle`
     - `Data de publicação`: `snippet.publishedAt`

---

## 📈 FLUXO 2: Coleta Diária de Visualizações

### Objetivo:
Verificar diariamente quantas visualizações cada vídeo listado acumulou e registrar no Google Sheets para análise de crescimento.

### Passo a passo:

1. **Agendador (Schedule Trigger)**
   - Defina para rodar diariamente.

2. **Google Sheets – Carregar todos os vídeos**
   - Use `Get Rows` para obter todos os vídeos previamente salvos.
   - Pegue o campo `videoId`.

3. **Loop de vídeos**
   - Use o node `Loop Over Items` para iterar um por um.

4. **HTTP Request – Consultar estatísticas de cada vídeo**
   - URL: `https://youtube.googleapis.com/youtube/v3/videos`
   - Parâmetros:
     - `id`: `{{videoId}}`
     - `part`: `snippet,statistics`
     - `key`: sua API Key
   - Retorno incluirá contagem de visualizações (`viewCount`).

5. **Formatar a data atual (YYYY-MM-DD)**
   - Para identificar qual o dia da coleta.

6. **Inserir no Google Sheets**
   - Adicione nova coluna no seu Google Sheets com o nome da data.
   - Adicione o número de visualizações naquele dia para cada vídeo.
   - Mapear:
     - `videoId` (linha de referência)
     - `data` (coluna nova com a contagem de views)

7. **Esperar entre as requisições**
   - Use `Wait (5s)` entre cada vídeo para não sobrecarregar a API.

---

## 🧠 Resultado Final:

Você terá:
- Uma **planilha com todos os vídeos do seu nicho**.
- Colunas diárias com o número de visualizações.
- Capacidade de **analisar crescimento, tendências** e encontrar vídeos com maior potencial viral.

---

## 🚀 Recursos Extras:

- A comunidade do autor oferece o **template pronto no n8n** e suporte.
- Você pode adaptar para outros nichos mudando a palavra-chave da pesquisa.
