**Google Drive and Dropbox**[**#**](https://json2video.com/docs/v2/api-reference/json-syntax/element/image#google-drive-and-dropbox)
JSON2Video also supports images stored in Google Drive and Dropbox, but they must be set to public access. If the file is private or requires special permissions, the system will be unable to fetch it for video creation.

**Generating AI images dynamically**[**#**](https://json2video.com/docs/v2/api-reference/json-syntax/element/image#generating-ai-images-dynamically)
In addition to using pre-existing image files, JSON2Video allows you to generate AI images dynamically using text prompts. This is useful when you don't have access to stock images or need visuals that match specific content, such as a voiceover or theme.

Currently, JSON2Video supports AI image generation using models from different providers. The available models include:

**Flux Pro** (`flux-pro`) – Designed for generating high-quality, realistic images.
**Freepik Classic** (`freepik-classic`) – Provides visually appealing digital artwork and illustrations.
Since AI-generated images require additional processing, they may consume extra credits. For more details, refer to [Credits Consumption](https://json2video.com/docs/v2/pricing/credits-consumption).

**Example**

This example creates a vertical video with an AI generated image that fills the full video canvas.

`{
  "resolution": "custom",
  "width": 1080,
  "height": 1920,
  "scenes": [
    {
      "elements": [
        {
          "type": "image",
          "model": "freepik-classic",
          "prompt": "A stunning sunset over a calm ocean, with vibrant orange, pink, and purple hues reflecting on the water.",
          "aspect-ratio": "vertical",
          "resize": "fill",
          "duration": 10
        }
      ]
    }
  ]
}
`Copy
By leveraging AI image generation, you can dynamically create unique and context-relevant visuals without relying on external image sources.

**Resumo geral:**  
Como automatizar a criação de vídeos longos no estilo "Top 10" para o YouTube, sem mostrar o rosto, utilizando:

- **n8n**: para orquestrar toda a automação  
- **Google Sheets**: como banco de dados com ideias e status dos vídeos  
- **OpenRouter + GPT-4**: para geração de roteiros (intro, rankings, etc.)  
- **JSON to Video**: gera imagens e monta o vídeo completo com voz  
- **ElevenLabs**: faz as narrações realistas em voz  
- **YouTube API**: publica automaticamente o vídeo  

---

**Etapas do fluxo de trabalho:**  

1. **Geração de ideias (opcional)**
   - Um agente cria 10 ideias e adiciona ao Google Sheets com status "to-do"

2. **Leitura do Google Sheets**  
   - O n8n busca ideias com status "to-do" para iniciar a criação

3. **Agente de Introdução e Conclusão**
   - Gera o texto e imagem de introdução e de encerramento
   - Usa mensagens específicas com formato de saída forçado (JSON)

4. **Agente de Rankings**
   - Cria os 10 itens do vídeo (ex: top 10 cidades)
   - Para cada item: texto para narração, imagem e título
   - Também com saída JSON estruturada

5. **Criação do vídeo via JSON to Video**
   - API recebe tudo: título, intro, rankings, imagens e narração
   - Usa template específico e faz a renderização do vídeo completo
   - Conecta com ElevenLabs (via ID da voz) e gera tudo automaticamente

6. **Espera e Verificação do Vídeo**
   - Usa “polling” para verificar o status da renderização a cada 10s
   - Quando estiver “done”, continua para a próxima etapa

7. **Atualiza Google Sheets**
   - Marca o status como “created”
   - Insere o link do vídeo gerado

8. **Download do Vídeo**
   - Faz requisição GET para baixar o vídeo como binário

9. **Upload no YouTube**
   - Usa a API do YouTube para publicar
   - Define título (Top 10: assunto), descrição e status “não listado”

10. **Atualiza Google Sheets novamente**
   - Marca como “postado” no status final

---

- **Assunto:** Top 10 cidades da Europa
