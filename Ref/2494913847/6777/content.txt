Resumo completo:

Como criar um **Agente de IA** para **automatizar Reels do Instagram** no estilo **Threads/X Twitter**, sem usar código, usando **OpenAI, n8n, Google Sheets e a API Graph do Instagram**.

Resumo por tópicos:

- **Ferramentas necessárias**:
  - OpenAI
  - Google Sheets
  - API Graph do Instagram
  - n8n
  - Text Video Generation API 

- **Três Workflows criados**:
  1. **Gerenciamento de perfil Instagram**:
     - Obtenção manual do primeiro token de acesso (SS Token)
     - Conversão em token de longa duração
     - Ligação de contas
     - Recuperação de dados do perfil (nome, foto, handle)
     - Atualização das informações no banco de dados (Sheets)

  2. **Criação automática de legendas e vídeos**:
     - Geração de vídeos a partir de textos usando a Text Video API
     - Divisão de textos longos em vários posts no estilo Threads
     - Criação automática de legendas com OpenAI (modelo GPT-4)
     - Atualização dos dados (URL do vídeo e legenda) no Google Sheets

  3. **Upload automático dos Reels**:
     - Leitura dos vídeos prontos no Google Sheets
     - Upload dos vídeos como Reels no Instagram
     - Atualização do status de postagem no Google Sheets

- **Demonstração prática**:
  - Exibe o Google Sheets vazio
  - Executa o fluxo para gerar o vídeo
  - Mostra o preenchimento automático dos campos (URL do vídeo, status)
  - Faz o upload do vídeo no Instagram e atualiza o status no Sheets

- **Passos de configuração**:
  - Criar aplicativo no painel da Meta (Meta App Dashboard)
  - Gerar o App ID e o App Secret
  - Obter SS Token usando o Graph API Explorer
  - Converter token para longa duração
  - Configurar n8n com as credenciais obtidas

- **Detalhes técnicos**:
  - JSON de requisição para geração de vídeo e upload no Instagram é fornecido no tutorial
  - Espera automática (delay) entre as ações
  - Atualização contínua dos dados no Google Sheets

- **Observação final**:
  - Todo o processo foi criado para a comunidade da ferramenta n8n 
  - O sistema facilita transformar conteúdos longos em vídeos curtos com aparência moderna e adaptada a redes sociais.
