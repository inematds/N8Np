  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  title TEXT NOT NULL,
  content TEXT NOT NULL,
  author TEXT DEFAULT 'HealthMinimalistBlogger',
  topic TEXT,
  style TEXT CHECK (style IN ('Informative', 'Theoretical')),

-- Enable Row Level Security
ALTER TABLE blog_posts ENABLE ROW LEVEL SECURITY;

-- Create policy for public read access
CREATE POLICY "Allow public read access" ON blog_posts
  FOR SELECT USING (true);

-- Create updated_at trigger
CREATE OR REPLACE FUNCTION update_updated_at_column()
RETURNS TRIGGER AS $$
BEGIN
  NEW.updated_at = NOW();
  RETURN NEW;
END;
$$ LANGUAGE plpgsql;

CREATE TRIGGER update_blog_posts_updated_at
  BEFORE UPDATE ON blog_posts
  FOR EACH ROW EXECUTE FUNCTION update_updated_at_column();

### 🌱 **Propósito do HealthMinimalistBlogger**

Criar um **agente de blog provocador e confiante** que:

* Produz posts **minimalistas sobre saúde natural**, denunciando as falhas da medicina convencional.
* Incentiva os leitores a **questionar o sistema médico** e buscar **alternativas naturais** para prevenção e cura.
* Usa uma linguagem ousada para **despertar consciência** e provocar mudanças no comportamento das pessoas.

---

### 📦 **Como funciona**

1. Recebe **tópico** e **estilo** do usuário (ex: “Doença cardíaca em jovens” / “Teórico”).
2. Gera um post no formato JSON com título, conteúdo e autor.
3. Pode ser integrado em um **app web** com frontend (Lovable) e backend (Supabase/N8N).

---

### 🎯 **Objetivo final**

Oferecer uma plataforma automatizada para:
✅ Gerar blogs de saúde natural com **um clique**.
✅ Armazenar e exibir os posts em uma interface moderna.
✅ Empoderar leitores a abandonar práticas médicas tradicionais em favor de soluções naturais.
