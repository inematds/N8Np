**19. Claude + Apify: Investigue sem limites**

🎯 **Objetivo da aula**
Aprendemos a conectar Claude com qualquer ator do Apify através de um único servidor MCP. Isso permite criar projetos avançados sem consumir tokens adicionais e obter informações enriquecidas de milhares de fontes públicas, tudo dentro do ambiente do Claude.

🔧 **Estrutura de funcionamento**

* Claude se conecta a um único servidor MCP.
* Este servidor se comunica com múltiplos atores do Apify (Instagram, TikTok, YouTube, Web Scraper, etc.).
* A integração permite consultar e fazer scraping de conteúdo diretamente a partir do Claude.

💡 **Casos de uso explicados**

1. **Análise da concorrência**

   * Inserimos o nome de um criador de conteúdo.
   * São rastreadas redes sociais, site oficial e últimas publicações.
   * Extraímos:

     * Seguidores, frequência de publicação, hashtags, estilo de comunicação.
     * 10 postagens recentes por rede social.
     * Relatório detalhado com insights e métricas.
   * 🧪 *Exemplo*: Mago More – Gera um relatório completo com suas métricas no Instagram, TikTok, Twitter e YouTube.

2. **Análise de comentários do YouTube**

   * Inserimos a URL de um canal ou vídeo.
   * São extraídos os comentários dos últimos 5 vídeos.
   * Gera:

     * Análise de temas, interesses do público, perguntas frequentes.
     * Relatório com sugestões de melhoria.
     * Relatório com 20 ideias de novos vídeos com títulos justificados com base nos comentários e tendências do mercado.
   * 🧪 *Exemplo*: Canal de Chaimillana – Analisam-se os comentários de 5 vídeos e geram-se ideias virais com justificativa detalhada.

3. **Pesquisa para podcast**

   * Inserimos o nome do convidado.
   * O sistema busca:

     * Biografia, entrevistas, artigos, redes sociais e site oficial.
     * 5 podcasts onde participou + transcrição automática.
   * Gera:

     * Ficha do convidado: nome, idade, cidade, resumo biográfico, estilo de comunicação.
     * 10 temas para a entrevista.
     * 20 perguntas virais únicas.
     * 3 perguntas polêmicas justificadas.
     * Análise de polarização, temas pouco abordados, simulação de viralidade, ajuste por audiência e personagem antagonista.
   * 🧪 *Exemplo*: Mago More – O sistema identifica perguntas impactantes, temas pouco explorados e possíveis pontos de controvérsia.

🛠️ **Configuração técnica**

* Utiliza-se o ator `actors-mcp-server` do Apify.
* Configura-se um arquivo `.json` com:

  * Token da API do Apify.
  * Lista separada por vírgulas dos atores que queremos conectar (ex: `instagram-scraper`, `youtube-transcript`, etc.).
* Edita-se o `desktop.json` no Claude para definir essa configuração.
* Reinicia-se o Claude para aplicar as alterações e começar a trabalhar com todos os atores conectados.

✅ **Vantagens principais**

* Não consome tokens da OpenAI ou de outros LLMs por chamada, pois o Claude gerencia tudo.
* Compatível com a versão gratuita e paga do Claude.
* Pode ser usado tanto em projetos quanto no chat livre do Claude.
* Ideal para criadores de conteúdo, podcasters, analistas e agências.

🚨 **Código para Claude com os scrapers do Apify mostrados no vídeo**

```{
  "mcpServers": {
    "actors-mcp-server": {
      "command": "npx",
      "args": [
        "-y",
        "@apify/actors-mcp-server",
        "--actors",
        "apify/website-content-crawler,apify/instagram-scraper,karamelo/youtube-transcripts,streamers/youtube-scraper,apify/rag-web-browser,apidojo/tweet-scraper,streamers/youtube-comments-scraper,clockworks/tiktok-scraper,apimaestro/linkedin-profile-posts,apify/web-scraper,apify/puppeteer-scraper,lukaskrivka/google-maps-with-contact-details,apify/facebook-url-to-id,topaz_sharingan/Youtube-Transcript-Scraper-1"
      ],
      "env": {
        "APIFY_TOKEN": "SUA_CHAVE_API_APIFY"
      }
    }
  }
}```

**Recursos**

* Prompt YouTube
* Prompt Análise de Redes Sociais
* Prompt Podcast
* Ator MCP Apify
