**Passo a passo da automação do Pinterest com n8n + Claude 3.7 Sonnet + Flux**

Este fluxo automatiza a criação de postagens no Pinterest com geração de conteúdo, imagem, upload e registro em planilha.

---

### 1. **Configuração Inicial**

* Crie um novo workflow no **n8n**.
* Ative o **gatilho (Trigger)** — pode ser agendado (1x por dia) ou manual.

---

### 2. **Geração do Conteúdo com Claude 3.7 Sonnet**

* Adicione o nó **Advanced AI (LLM Chain)**.
* Modelo: **Claude 3.7 Sonnet** via **OpenRouter**.
* Prompt:
  `Crie um post envolvente para Pinterest com dicas de saúde. Use linguagem vibrante e tom amigável.`
* Saída: Título, legenda, estrutura (em JSON).

---

### 3. **Geração do Prompt de Imagem**

* Adicione outro nó **LLM Chain**.
* Prompt:
  `Gere um prompt de imagem hiper-realista de um alimento saudável.`
* Use histórico de frutas anteriores para evitar repetição.
* Saída: JSON com prompt formatado.

---

### 4. **Geração da Imagem com Flux**

* Adicione um nó **HTTP Request** (POST).
* URL: API do Flux Image Model.
* Envie o prompt no corpo (JSON).
* Resultado: imagem em **base64**.

---

### 5. **Conversão e Armazenamento da Imagem**

* Nó: **Convert Base64 to File**.
* Nó: **Google Cloud Storage**.

  * Armazene com nome do tipo: `imagem-{ID}-{índice}`.
  * Gere e salve o **link público da imagem**.

---

### 6. **Registro no Google Sheets**

* Conecte com a planilha via **Google Sheets Node**.
* Operação: `Append Row`.
* Campos:

  * Título
  * Legenda
  * Link da imagem
  * Status = `Aguardando postagem`
  * Data de criação

---

### 7. **Captura de Tela de Pré-visualização (opcional)**

* Nó: **HTTP Request**.
* API: **ScreenshotOne**.
* Entrada: URL da landing page do post.
* Saída: imagem da página, que também pode ser armazenada.

---

### 8. **Criação do Post no Pinterest**

* Nó: **HTTP Request (POST)**.
* URL: `https://api-sandbox.pinterest.com/v5/pins` (ou produção).
* Headers:

  * Authorization: `Bearer {sua_token_do_app_Pinterest}`
* Corpo JSON:

  * board\_id
  * title
  * description
  * media\_source (URL da imagem)
  * link (URL do site)

---

### 9. **Atualização do Status no Google Sheets**

* Operação: `Update Row`.
* Critério: `status` vazio → atualize para:

  * Status = `Postado`
  * Data de postagem = `agora`

---

### 10. **Uso de Redis (opcional)**

* Armazene temporariamente:

  * IDs de boards
  * Lista de frutas usadas (para variar imagem)

---

### Resultado Final:

Você terá 5 postagens completas no Pinterest com:

* Texto gerado por IA
* Imagem única gerada
* Registro completo na planilha
* Totalmente automático e escalável

**Resumo da Automação de Pinterest com n8n + Claude 3.7 Sonnet + Flux (sem código)**

Este projeto automatiza a criação e publicação de postagens no Pinterest, com geração de conteúdo e imagem, tudo controlado por n8n.

**Passo a passo da automação:**

1. **Geração do Conteúdo**

   * Utiliza Claude 3.7 Sonnet via OpenRouter para criar textos com dicas fitness.
   * O prompt gera título, legenda, estrutura e formato amigável para o Pinterest.

2. **Geração de Imagens**

   * Um segundo prompt cria descrições de imagens detalhadas (com variação de frutas para evitar repetição).
   * As imagens são geradas com o modelo Flux (via HTTP request) e armazenadas em Google Cloud Storage como arquivos base64 convertidos.

3. **Organização em Planilha**

   * Os dados são salvos no Google Sheets: link da imagem, título, legenda, status da postagem, data, entre outros campos.

4. **Criação de Capturas de Tela**

   * Usa um serviço de screenshot (ScreenshotOne) para capturar páginas da web e gerar imagens adicionais.

5. **Publicação no Pinterest**

   * Usa API do Pinterest (modo sandbox ou produção).
   * Cria quadros (boards), faz upload da imagem, título, legenda e vincula aos dados da planilha.
   * Atualiza o status da postagem para "Postado" no Google Sheets.

6. **Credenciais e Integrações**

   * Claude 3.7 e Flux via OpenRouter com chave de API.
   * Armazenamento em nuvem com Google Cloud.
   * Dados e controle via Google Sheets.
   * Redis usado para armazenar IDs temporários e controle de fluxo.

**Exemplos de uso:**

* Criar posts automáticos para nichos (como saúde e bem-estar).
* Agendar e publicar conteúdos personalizados diariamente no Pinterest.
* Manter rastreamento e status de cada publicação via planilha integrada.

**Técnicas usadas:**

* Engenharia de prompt avançada.
* Uso de IA para texto e imagem.
* HTTP requests e automações no n8n.
* Armazenamento e controle com Google Sheets e Redis.

Essa automação permite gerar tráfego gratuito para sites a partir do Pinterest de forma 100% automatizada.
