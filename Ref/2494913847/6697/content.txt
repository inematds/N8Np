Um Agente de IA para gerar posts ilimitados de imagem no Instagram automaticamente (sem código)  

**Resumo geral:**  
Como criar um sistema automático que gera imagens, legendas e publica posts no Instagram, usando n8n, Exa.ai, Deepseek AI, Flux, ScreenshotOne e Google Sheets — tudo sem necessidade de programar.

---

**Demonstração inicial:**  
- Usam o n8n + Google Sheets para organizar:
  - Link da imagem gerada (Flux)
  - Link da imagem no Instagram
  - Legenda
  - Status
  - Data de publicação
- Notícias são buscadas online, resumidas em legenda via Deepseek AI, imagens são criadas via Flux.

---

**Ferramentas necessárias:**  
- **Exa.ai**: busca de notícias (API Key necessária).  
- **ScreenshotOne**: captura de tela para gerar imagens a partir de páginas HTML (API Key necessária).  
- **Together AI (Flux)**: criação de imagens estilizadas (API Key necessária).  
- **Deepseek AI**: reescrever notícias em legendas otimizadas (API Key necessária).  
- **Redis**: armazenamento temporário de tokens e IDs.  
- **AnyNoCode (opcional)**: templates prontos para motivacionais.

---

**Configuração de credenciais:**  
- Cada ferramenta configurada dentro do n8n como credencial segura (com Header Authorization ou Query).
- Redis é usado para armazenar tokens e dados intermediários.
- Configura-se o acesso à API do Facebook e Instagram (Meta Developers) para publicação.

---

**Descrição dos dois principais Workflows:**  

1. **Workflow de Criação de Conteúdo:**
   - Buscar notícias no Exa.ai sobre um tema (ex: "Robótica").
   - Gerar uma legenda usando Deepseek AI.
   - Criar imagem no estilo Flux com Together AI.
   - Converter imagem para JPEG (com ScreenshotOne).
   - Armazenar no Google Cloud e registrar no Google Sheets.
   
2. **Workflow de Publicação no Instagram:**
   - Gerar token longo do Facebook.
   - Buscar ID da conta de Instagram associada.
   - Fazer upload da imagem e legenda.
   - Publicar post no Instagram automaticamente.
   - Atualizar o status no Google Sheets para "Publicado".

---

**Bônus:**  
- Template para imagens motivacionais:
  - Cria posts de frases motivacionais para Instagram no mesmo fluxo.
  - Escolhe entre três estilos visuais oferecidos.

---

**Dicas Extras:**  
- Para os prompts de imagem, você pode usar o ChatGPT para converter o estilo visual desejado em um prompt para o Flux.
- Usa a captura de tela de uma página HTML para transformar em imagem final no formato JPEG (compatível com Instagram).
- Sempre aplicar JSON.stringify nos conteúdos que serão enviados por API para não dar erro de formato.

---

**Exemplos usados:**  
- Post: "Top 5 tendências de robótica moldando as indústrias em 2024"
- Motivacional: "Uma jornada vibrante e dinâmica da vida adulta jovem"

---

**Ferramentas citadas e suas funções resumidas:**  
- Exa.ai → Busca de notícias  
- Deepseek AI → Transformação da notícia em legenda  
- Together AI (Flux) → Criação da imagem estilizada  
- ScreenshotOne → Geração de imagem JPEG de uma página HTML  
- Google Sheets → Organização dos dados  
- Redis → Armazenamento temporário de tokens  
- Facebook API/Instagram API → Publicação no Instagram
