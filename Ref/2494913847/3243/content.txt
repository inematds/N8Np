### Como Raspar Dados do Twitter/X com n8n de Forma Eficiente  

Fuxo de trabalho do **n8n** que desenvolvi para raspar **tweets ilimitados** do **Twitter/X**. Essa ferramenta é útil para análises de mercado, análise da concorrência ou simplesmente para acompanhar as últimas tendências de uma indústria. 

Basta baixar, conectar e rodar o fluxo para começar a raspar tweets.  

### Passo 1: Baixar Recursos  
Para acessar o **workflow** e o **Google Sheets template**

### Passo 2: Demonstração ao Vivo  
O fluxo de trabalho que vamos explorar inclui:  
- **Raspagem de tweets** do Twitter/X  
- **Verificação do número de rodadas**  
- **Armazenamento das informações em um Google Sheet**, incluindo **ID do tweet, URL, conteúdo, curtidas, retweets, respostas, citações, visualizações e data**  

Para essa demonstração, configurei o fluxo para rodar **três vezes** e capturar **até 58 tweets**. Se quiser aumentar esse número, basta modificar a variável de contagem no fluxo.  

### Passo 3: Configuração da API  
Usaremos uma **API do Twitter/X** para acessar os tweets. Essa API permite raspar **1.000 tweets por apenas $0,15**. Se você usar o **link da descrição**, receberá **$6 de crédito inicial**, em vez de apenas $1 ao se cadastrar normalmente.  https://twitterapi.io/?ref=NateHerkelman

Na documentação da API, temos diferentes **endpoints**, como:  
- **Usuário**: obter tweets, seguidores e menções de um usuário  
- **Tweet**: buscar tweets por ID, respostas e retweets  
- **Busca Avançada**: encontrar tweets por palavras-chave  

### Passo 4: Configuração do n8n  
Para integrar a API ao n8n, siga estes passos:  

1. **Copie o comando cURL da documentação da API**  
2. No n8n, **crie uma requisição HTTP**  
3. **Importe o cURL** e ele preencherá os campos automaticamente  
4. **Defina a URL base** da API  
5. **Configure a autenticação**  
   - A API exige uma **chave de autorização**  
   - No painel da API, copie sua **chave API**  
   - No n8n, vá até a aba **Autenticação** e insira a chave como um **Header**  

Agora, precisamos definir os **parâmetros da busca**:  
- **query**: o termo que estamos pesquisando (exemplo: "OpenAI")  
- **queryType**: tipo de busca (**"latest"** ou **"top"**)  

Além disso, a API permite **paginação** com um **cursor**. Cada requisição retorna **cerca de 20 tweets**. Para buscar mais tweets, usamos o **cursor** da última resposta e fazemos novas chamadas à API até atingir o número desejado.  

### Passo 5: Salvando Tweets no Google Sheets  
1. No n8n, crie um **nó do Google Sheets**  
2. Configure para **adicionar novas linhas**  
3. Mapeie os campos do tweet para as colunas do Google Sheets  

Agora, ao rodar o fluxo, os tweets serão automaticamente salvos na planilha!  

### Passo 6: Automatização e Paginação  
Para capturar tweets automaticamente todos os dias, adicionamos um **gatilho de agendamento** e configuramos a **paginação**.  

O fluxo inclui:  
1. **Contador** que começa em 1  
2. **Chamada à API** para buscar tweets  
3. **Extração dos dados**  
4. **Salvamento no Google Sheets**  
5. **Atualização do cursor e do contador**  
6. **Repetição do processo até atingir o limite**  

A cada rodada, o cursor obtém a **próxima página de tweets**, e o fluxo continua rodando até coletar o número desejado de postagens.  

### Conclusão  
Este **workflow do n8n** permite raspar tweets de forma eficiente e automática, sem precisar de código complexo. Se quiser explorar mais funcionalidades, como **obtenção de perfis, análise de menções e extração de dados de concorrentes**, confira a documentação da API e personalize seu fluxo de trabalho.
