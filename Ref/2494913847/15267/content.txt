e55. Chatbot Pro com Banco de Dados Real


Construir um chatbot profissional e escalável, capaz de manter conversas reais com usuários e armazenar todas as informações em um banco de dados relacional (Supabase).
O objetivo é criar um sistema pronto para produção, não apenas um protótipo: um chatbot que funcione como um nutricionista digital (ou qualquer outro especialista) e que aprenda e atue com base em dados personalizados de cada cliente.

🛠️ O que conseguimos com essa automação:

* Criar um chatbot inteligente com memória persistente para cada usuário.
* Registrar e atualizar todos os dados (perfil, objetivos, refeições, histórico) em tabelas SQL interconectadas.
* Automatizar mensagens diárias, semanais e mensais com IA.
* Simular comportamento humano no WhatsApp (leitura, pausas, encerramento de sessão).
* Reduzir ao mínimo o consumo de tokens graças à conexão direta com o banco de dados.
* Ter uma estrutura reutilizável para qualquer negócio (nutrição, fitness, educação, consultoria...).

🧩 Estrutura do fluxo automatizado

**Fluxo principal (chat no WhatsApp com Evolution API)**

* Recebe a mensagem do usuário (texto, áudio ou imagem).
* Transcreve ou analisa conforme o tipo de mensagem.
* Envia o conteúdo ao agente principal de IA (Gemini ou GPT) junto com o contexto e dados anteriores.
* Retorna a resposta formatada e limpa para o WhatsApp.

**Agente principal (Onboarding + Conversação)**

* Realiza um processo completo de onboarding (nome, idade, altura, alergias, objetivos, hábitos...).
* Armazena e atualiza os dados do cliente com consultas SQL dinâmicas geradas pela IA.
* Controla o tom, as mensagens e a personalização conforme o estado do usuário (novo, ativo, pausado...).

**Subagente SQL Query**

* Recebe instruções em linguagem natural do agente principal.
* Gera e executa automaticamente as consultas SQL no Supabase (insert, update, select...).
* Evita a necessidade de criar múltiplas automações manuais.

**Fluxos programados**

* **Diário:** envia uma mensagem com lembrete ou plano do dia.
* **Semanal:** solicita métricas e atualiza o progresso.
* **Mensal:** gera um relatório em HTML com a evolução e envia ao usuário (via WhatsApp ou e-mail).

**Banco de dados relacional (Supabase)**

* Tabelas de clientes, objetivos, refeições, preferências, histórico de conversas, equivalências nutricionais etc.
* Tabelas conectadas por ID para acompanhamento completo do usuário.

🧰 Ferramentas utilizadas

* N8N (motor de automação).
* Supabase (banco de dados relacional).
* Gemini 2.5 Flash / GPT 4.1 (IA conversacional e geradora de SQL).
* Evolution API (integração com WhatsApp).
* PostgreSQL Query (execução direta de SQL).
* Make / Lovable (para front-ends ou dashboards, opcional).

🧠 Dicas essenciais aprendidas

* Armazenar a memória no banco de dados, não dentro do prompt.
* Sempre simular comportamentos humanos no WhatsApp (ler, pausar, encerrar sessão).
* Estruturar o sistema com subagentes especializados (IA principal + IA SQL).
* Usar prompts claros: uma ação por execução.
* Implementar tabelas relacionadas para evitar duplicidades e escalar para centenas de usuários.
* Se você trabalha em outro setor (fitness, coaching, consultoria...), basta adaptar o conteúdo das tabelas.

**Recursos:**

* Chatbot Nutricionista Principal
* Fluxo Supabase SQL
* Fluxo de Envios Programados
* Tabelas SQL
