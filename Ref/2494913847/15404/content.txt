Resumo completo

**Guia Completo – Crie QUALQUER COISA com Agentes de IA Sora 2 + n8n (para iniciantes)**

**1. Objetivo do Tutorial**
Ensinar, de forma simples e prática, como integrar o modelo de geração de vídeo **Sora 2 (OpenAI)** ao **n8n**, permitindo automatizar a criação de vídeos com agentes de IA, sem precisar programar.

---

**2. Estrutura do Guia**

**Etapa 1 – Preparação e Conta OpenAI**

* Crie uma conta na OpenAI e ative o acesso ao modelo Sora 2.
* Copie sua **API Key** para autenticação.
* No painel da OpenAI, teste manualmente uma geração simples de vídeo a partir de texto para confirmar o funcionamento.

**Exemplo de prompt:**
“Crie um vídeo de 10 segundos mostrando um robô humanoide ensinando crianças em uma sala futurista, iluminação suave e estilo Pixar.”

---

**Etapa 2 – Configuração do n8n**

* Acesse o n8n local ou em nuvem.
* Adicione um novo workflow.
* Crie um **HTTP Request Node** para enviar solicitações à API Sora 2.

**Parâmetros básicos:**

* Método: `POST`
* URL: `https://api.openai.com/v1/video/generations`
* Headers:

  * `Authorization: Bearer {{api_key}}`
  * `Content-Type: application/json`
* Body (JSON):

```{
  "model": "sora-2",
  "input": "uma cena de montanha ao amanhecer, drone, realista, 4k, 10 segundos",
  "mode": "text-to-video"
}```

---

**Etapa 3 – Modo Imagem para Vídeo e Storyboard**
Você pode usar outros modos com pequenas mudanças:

* **image-to-video**

  ```  {
    "model": "sora-2",
    "input": "image_url": "https://meusite.com/imagem.jpg",
    "mode": "image-to-video"
  }
  ```
* **storyboard**
  Permite gerar um roteiro visual a partir de uma sequência de textos, ideal para vídeos narrativos.

  ```  {
    "model": "sora-2",
    "input": [
      {"scene": "Cidade à noite, carros autônomos."},
      {"scene": "Pessoa digitando em laptop com IA."},
      {"scene": "Final com slogan 'O futuro começa agora'."}
    ],
    "mode": "storyboard"
  }
  ```

---

**Etapa 4 – Enriquecendo com Agentes de IA**

* Use um **LLM Node (OpenAI ou ChatGPT)** para gerar automaticamente prompts criativos.
* Conecte o LLM → Sora Node → Armazenamento (Google Drive, Supabase, Dropbox).
* O agente pode receber um tema (“Crie vídeo de lançamento de produto”) e gerar o roteiro + vídeo automaticamente.

---

**Etapa 5 – Práticas Recomendadas e Otimização**

* **Duração curta:** entre 5 e 15 segundos para menor custo.
* **Prompt descritivo:** use estilo, luz, câmera e emoção.
* **Automações:** adicione filtros no n8n (ex.: enviar vídeos apenas se “aprovação = true”).
* **Saída otimizada:** use nó “Move Binary Data” e “Upload” para salvar o vídeo no destino escolhido.

---

**Etapa 6 – Fluxo Completo no n8n (resumo visual)**

1. Start Node →
2. ChatGPT (gera o prompt) →
3. HTTP Request (envia ao Sora 2) →
4. Download Output (Binary) →
5. Armazenamento (Supabase / Drive / Telegram) →
6. Notificação (mensagem com link do vídeo).

---

**Etapa 7 – Exemplos de Aplicações**

* Criação automática de vídeos para redes sociais.
* Agentes que respondem e-mails com vídeo personalizado.
* Campanhas de marketing com vídeos temáticos diários.
* Produção de vídeo para cursos, promoções ou anúncios.

---

**Etapa 8 – Hacks e Dicas Extras**

* Combine **Make + n8n** para fluxos híbridos (texto, voz e vídeo).
* Use **Google Sheets** como painel de controle (lista de temas → vídeos automáticos).
* Adicione **voz gerada** com TTS e sincronize com o vídeo.
* Integre **Stable Diffusion ou DALL·E** para gerar imagens base e transformar em vídeo.

---
