### 🚀 HACKS GERAIS

1. **Use GPT-5 para preencher campos automaticamente**

   * Em vez de mapear campos manualmente, clique na **estrela (✨)** nas configurações e deixe o GPT-5 preencher título, texto, datas, destinatários e muito mais.

2. **Combine múltiplos agentes em uma única mensagem**

   * Exemplo: “Verifique meu CRM e agende uma reunião com o João às 14h de amanhã.”
   * O sistema identifica que deve usar o agente de CRM + agente de calendário.

3. **Use variáveis do Telegram diretamente nos nós**

   * Ex: `${$json["message"]["chat"]["id"]}` para o `chat ID`
   * Permite respostas automáticas específicas por usuário.

4. **Use o mesmo fluxo para diferentes plataformas de entrada**

   * Substitua o `Telegram Trigger` por `Slack`, `WhatsApp (via API)`, ou `Webhook` para usar o mesmo motor de automação.

5. **Crie um painel com status das execuções**

   * Use `Notion` ou `Google Sheets` para logar cada interação com data, tarefa, status, e resposta da IA.

---

### 🧠 HACKS DE PROMPTING

6. **Use system prompts claros e com função definida**

   * Exemplo: `"Você é um assistente de e-mail responsável por criar, responder e enviar mensagens via Gmail."`
   * Isso ajuda o GPT-5 a agir com mais precisão.

7. **Oriente o modelo com exemplos de resposta**

   * Adicione um bloco no system message com 2–3 exemplos de entradas e saídas esperadas.
   * Aumenta a consistência nas ações do modelo.

8. **Adicione regras no prompt**

   * Exemplo: “Nunca envie e-mail sem assunto. Sempre use linguagem formal. Sempre agende eventos com 1h de antecedência mínima.”
   * Isso cria um padrão de comportamento da IA.

---

### 🔧 HACKS DE CONFIGURAÇÃO

9. **Use `context window = 20` para manter conversas curtas e rápidas**

   * Ideal para interações com comandos diretos e sem memórias extensas.

10. **Organize os agentes com nomes claros**

* Ex: `email_agent`, `calendar_agent`, `crm_agent`
* Facilita o reuso e manutenção futura do fluxo.

11. **Use `IF nodes` para condicionar a resposta ou executar múltiplos agentes**

* Ex: se a mensagem contiver “e-mail”, ative o Email Agent; se contiver “agenda”, ative o Calendar Agent.

12. **Salve o histórico em um banco (Airtable, Supabase, Notion, etc.)**

* Permite análise posterior, geração de dashboards e logs de desempenho.

---

### 💡 HACKS AVANÇADOS

13. **Implemente fallback para GPT-4 ou Claude**

* Caso o GPT-5 esteja lento ou instável, use roteamento condicional para outro modelo.

14. **Adicione verificação de contexto antes da execução**

* Ex: “Você já enviou este e-mail hoje. Deseja repetir?”
* Isso evita duplicações e melhora a experiência do usuário.

15. **Transforme os fluxos em uma API REST para outros apps**

* Exporte o fluxo com `Webhook` e consuma via sites, apps mobile ou outros bots.

Aqui está um **passo a passo completo** para montar o *AI Agent Army* no **n8n** com o **GPT-5**, baseado no vídeo. Dividi em blocos organizados por etapas principais e agentes envolvidos.

---

### ⚙️ ETAPA 1 – CONFIGURAÇÃO INICIAL DO n8n

1. **Crie um bot no Telegram**

   * Acesse o [BotFather](https://t.me/BotFather)
   * Crie um novo bot e copie o **Token de Acesso (API Token)**

2. **Adicione o nó `Telegram Trigger` no n8n**

   * Conecte com o token do seu bot
   * Tipo de recurso: `Message`
   * Operação: `On New Message`

3. **Adicione o nó `Edit Fields`**

   * Captura e formata o input do usuário
   * Campo: `chat input`
   * Tipo: `text`

4. **Configure o nó `AI Agent`**

   * Modelo: `GPT-5 (via OpenAI)`
   * API Key da OpenAI
   * Mensagem do sistema define o papel do agente (ex: "Você é um assistente de e-mail, agende, envie e responda mensagens.")
   * Entrada do usuário conectada ao prompt
   * Habilite **tools** e defina as ferramentas por agente

5. **Adicione o nó `Telegram Send Message`**

   * Conecta ao mesmo bot
   * Recurso: `Message`
   * Operação: `Send Message`
   * Chat ID: vindo do nó de trigger
   * Texto: resposta do GPT-5

---

### 🧠 ETAPA 2 – CONFIGURAÇÃO DOS AGENTES (SUBAGENTES)

#### 1. **Email Agent (Gmail)**

* Função: Redigir, enviar, responder e deletar e-mails
* Integração: Google Gmail API
* Ações:

  * `Create Draft`
  * `Send Email`
  * `Get Messages`
* Parâmetros como assunto, corpo e destinatário definidos **automaticamente pelo GPT-5**

#### 2. **Calendar Agent (Google Calendar)**

* Função: Criar, deletar, atualizar e listar eventos
* Integração: Google Calendar
* Campos:

  * `start time`, `end time`, `description`, `summary`
  * Todos preenchidos automaticamente pelo modelo
* Permite agendamentos com base em linguagem natural

#### 3. **Database Agent (Airtable)**

* Função: Buscar, criar e atualizar registros
* Integração: Airtable
* Campos: nome, e-mail, empresa, etc.
* Operações:

  * `Search Record`
  * `Create or Update Record`
* Tokens e tabelas da Airtable devem estar configurados

#### 4. **CRM Agent (Sales Tracker - Airtable)**

* Função: Gerenciar oportunidades e leads
* Campos: nome da oportunidade, status, prioridade, valor, prazo
* Ações:

  * Atualizar status ou prioridade de leads
  * Automatizar mudanças de estágio no funil

#### 5. **Social Media Agent**

* Função: Postar em redes sociais
* Integrações:

  * LinkedIn: criar post como pessoa ou empresa
  * Twitter/X: criar tweet
  * Threads (via Graph API do Facebook)
* Campos como texto da publicação definidos automaticamente

#### 6. **Proposal Agent (Google Docs)**

* Função: Criar e atualizar propostas em documentos
* Integração: Google Docs
* Ações:

  * `Create Document`
  * `Update Document`
* Define título, conteúdo, posição de inserção via IA

#### 7. **Web Research Agent (Pesquisa Online)**

* Função: Buscar informações externas
* Ferramentas usadas:

  * Perplexity
  * Google Search
  * YouTube
* Não foi detalhado no vídeo, mas funciona com o GPT-5 consultando essas fontes

---

### 🧩 ETAPA 3 – FLUXO DE EXECUÇÃO (EXEMPLO)

1. Usuário envia mensagem no Telegram (ex: “Marcar reunião com João amanhã às 14h”)
2. `Telegram Trigger` capta a mensagem
3. `Edit Fields` estrutura o conteúdo
4. `AI Agent (GPT-5)` interpreta e aciona o agente necessário (ex: `Calendar Agent`)
5. `Calendar Agent` agenda o evento no Google Calendar
6. `Telegram Send Message` responde ao usuário com confirmação

---

### 📁 EXTRAS

* Todos os agentes utilizam memória simples
* O template **pode ser baixado gratuitamente**
* A maioria dos parâmetros (como horários, e-mails, campos) são definidos pelo GPT-5 automaticamente
* Pode-se adicionar outras ferramentas ao fluxo, como Notion, Slack, etc.

---

### 📌 Exemplo de tarefas que você pode enviar ao Telegram:

* “Crie um rascunho de e-mail para reunião na sexta às 14h”
* “Agende um evento no calendário amanhã às 10h”
* “Publique um post no LinkedIn com este conteúdo”
* “Atualize o status da oportunidade XYZ para ‘Em negociação’”

Como usar o GPT-5 para montar um “exército” de agentes de IA integrados no n8n, com um template gratuito. Ele faz demonstrações e depois explica a configuração de cada agente.

Principais pontos:

  * GPT-5 usado para responder mensagens, criar e-mails no Gmail, agendar eventos no Google Calendar e executar múltiplas tarefas em sequência (buscar dados no CRM, criar e-mail, agendar reunião etc.).

* **Configuração no n8n**

  * Gatilho inicial via Telegram Bot (configurado pelo BotFather).
  * Nó de edição de campo para capturar o input do chat.
  * Nó AI Agent configurado com GPT-5, prompts para orientar o papel do agente e ferramentas necessárias.
  * Nó final do Telegram para enviar a resposta ao usuário.

* **Agentes criados no template**

  1. **Email Agent** – integra com Gmail para criar, enviar, responder e gerenciar e-mails.
  2. **Calendar Agent** – gerencia Google Calendar (criar, atualizar e deletar eventos).
  3. **Database Agent** – conecta ao Airtable para buscar, criar ou atualizar contatos e registros.
  4. **Social Media Agent** – publica em LinkedIn, Twitter/X e Threads (via Facebook Graph API).
  5. **Proposal Agent** – cria e atualiza documentos no Google Docs para propostas comerciais.
  6. **CRM Agent** – gerencia oportunidades no CRM do Airtable, atualizando status, prioridade e informações.
  7. **Web Research Agent** – realiza pesquisas usando GPT-5 com ferramentas como Perplexity, Google Maps e YouTube Search (explicado apenas de forma superficial).

* **Observações finais**

  * O template é personalizável e gratuito.
  * Apesar de todo o sistema usar GPT-5, o autor não percebeu grande diferença prática entre GPT-5 e outros modelos para essa aplicação específica.
