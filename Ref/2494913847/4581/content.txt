**10. Agente de vendas com IA e revisão humana**

Criamos um agente de vendas que responde automaticamente a clientes potenciais com base no histórico de projetos da nossa empresa. Além disso, incluímos um validador humano para revisar e aprovar (ou modificar) as mensagens antes de serem enviadas. 

Desenvolvemos todo o fluxo no N8N, pois no Make não é tão simples implementar essa lógica.

🧩 **Estrutura do fluxo passo a passo**

1. **Formulário de contato**  
Criamos um formulário nativo no N8N para coletar:  
- Nome, e-mail, telefone, empresa  
- Serviço solicitado, orçamento, prazo de implementação  
- Descrição do projeto  

Todos os campos são obrigatórios e com validações básicas.

2. **Armazenamento no Airtable**  
Todos os leads que preenchem o formulário são salvos em uma base de dados no Airtable.  
A tabela se chama *Clientes potenciais* dentro da base *Base de clientes*.

3. **Agente de vendas com IA**  
Usamos um modelo GPT-4-O-Mini via OpenRouter.  
O agente recebe todas as informações do cliente e acessa um banco de dados de projetos anteriores para buscar exemplos relevantes.  
Com essas informações, ele redige um e-mail personalizado e com tom humano.

4. **Validação humana da mensagem**  
Usamos o módulo “Send and Wait for Response” do Gmail no N8N para enviar o rascunho do e-mail ao validador (neste caso, nós mesmos).  
Podemos aprovar ou enviar feedback textual para ajustes.

5. **Verificador de feedback**  
Implementamos um classificador de texto para identificar se o feedback é:  
✅ Aprovado → O e-mail é enviado diretamente ao cliente.  
🔁 Requer mudanças → Um segundo agente é ativado para modificar o e-mail conforme o feedback.

6. **Agente revisor com IA**  
Reescreve o e-mail com base no feedback recebido.  
O processo se repete em loop até que a mensagem seja aprovada.

🛠️ **Detalhes técnicos relevantes**  
- Utilizamos um *output parser* com *JSON schema* para extrair o assunto e o corpo do e-mail.  
- O agente tem acesso a uma ferramenta conectada ao Airtable para ler todos os projetos anteriores.  
- Pode ser escalado facilmente com validadores personalizados via switches.  
- Se houver muita informação, recomenda-se usar um banco de dados vetorial (como Supabase ou Pinecone).

💡 **Ideias e melhorias sugeridas**  
Este fluxo pode ser adaptado para outros processos que exigem validação humana, como:  
- Envio de orçamentos  
- Aprovação de postagens em redes sociais  
- Revisão de pedidos  

Também podemos melhorar o sistema atribuindo validadores conforme o responsável por cada cliente.
