**Título: Criei um agente no n8n que cria outros agentes automaticamente**

**Resumo do projeto:**
Um fluxo automatizado no n8n onde, com **apenas um prompt simples**, o sistema:

1. **Interpreta o pedido**
2. **Consulta uma base de dados com centenas de automações do n8n**
3. **Pesquisa a documentação atualizada do n8n usando Perplexity**
4. **Gera o workflow completo com IA (em JSON)**
5. **Entrega um link clicável para importar direto no seu workspace**

---

**Componentes principais do projeto:**

1. **Workflow Principal (Simples)**  
   - Recebe o prompt via chat  
   - Envia para o Agente de IA  
   - Aciona o **Subfluxo Avançado**

2. **Subfluxo Avançado (Agente Criador de Agentes)**  
   - Processa o prompt com **OpenAI** para refinar  
   - Gera palavras-chave para busca em **base vetorial (Pinecone)**  
   - Recupera os fluxos similares salvos no banco vetorial  
   - Usa **Perplexity** para pesquisar exemplos e documentações  
   - Gera JSON estruturado com **boas práticas do n8n**  
   - Remove erros comuns (ex: nomes de propriedades mal formatadas, comentários)  
   - Valida o JSON com LLM  
   - Usa o módulo do n8n para **criar o workflow automaticamente** e gerar um link direto

---

**Base de Conhecimento de Automação (KB):**

- Criada com scripts em Python (via Google Colab)
- Scraping de automações do marketplace (foco em IA)
- Transformadas em vetores com **embedding OpenAI**
- Armazenadas no **Pinecone**
- Cada fluxo é rotulado com nomes descritivos para facilitar buscas (ex: `agent_openai_google_sheets`)

---

**Ferramentas e recursos usados:**

- **n8n**: Plataforma de automação
- **OpenAI**: Para interpretação de prompt, refinamento e geração de JSON
- **Perplexity**: Para busca em documentação atualizada
- **Pinecone**: Base vetorial para armazenar e consultar fluxos
- **Google Colab**: Para rodar o script que cria a base vetorial
- **Sonar Pro** (modelo LLM): Para gerar e validar os fluxos com precisão
- **n8n Create Workflow Module**: Cria o workflow direto no workspace

---

**Exemplo de prompt dado no chat:**
> "Crie um agente que leia uma linha de uma planilha do Google Sheets, resuma e envie por e-mail para mark@promptadvisors.com"

**Resultado:**  
- Workflow criado automaticamente  
- Link gerado no chat para importar o fluxo direto

---

**Benefícios principais:**

- **Gera fluxos completos e úteis com prompts vagos**  
- **Economiza horas de trabalho**  
- **Evita copiar e colar JSON manualmente**  
- **Reutilizável em outros contextos (ex: GPTs personalizados, APIs)**

**Fluxo de trabalho 🤖 de agente para agente do n8n**


1. **Fluxo Principal do Criador de Agentes de IA**  
   Um fluxo poderoso no n8n que cria dinamicamente agentes de IA sob demanda.

2. **Subfluxo secundário**  
   Um fluxo complementar que executa tarefas detalhadas acionadas pelo fluxo principal.  
   Faz referência automaticamente a automações ou conectores relevantes, garantindo uma transição suave entre os fluxos.

3. **Script de Criação de Base de Conhecimento de Automação (KB)**  
   Um script especializado que divide e insere diferentes automações no banco vetorial **Pinecone**.  
   Inclui também:  
   - Link para **300 automações com IA no n8n** disponíveis no marketplace.  
   - Permite que seu agente de IA consulte uma biblioteca extensa de automações pré-construídas, reduzindo drasticamente o tempo de configuração.

4. **Integração com Pesquisa Profunda (Deep Research)**  
   Módulo embutido com **Perplexity** para pesquisas em tempo real na documentação e atualizações mais recentes do n8n.  
   Garante que seu agente de IA esteja sempre atualizado sobre novos nós, boas práticas e mudanças nas funcionalidades do n8n.

5. **Modelos prontos para importação**  
   Arquivos de fluxo baseados em **JSON**, incluindo o fluxo principal, subfluxo e expansões opcionais.  
   Basta fazer upload no n8n e começar a gerar agentes de IA adaptados às suas necessidades — sem necessidade de programação avançada.



**Resumo**

Com esse pacote, você pode criar e implantar agentes de IA totalmente funcionais no **n8n**, usando um conjunto de fluxos, scripts e uma base de conhecimento de automação — **sem precisar de habilidades técnicas avançadas**.

---

**Recursos incluídos**

- Fluxo do Criador Principal  
- Subfluxo (subflow)  
- Script de criação da base de conhecimento (KB)  
- Link para Google Drive
