**e18. Agente de Vendas Multicanal (FB, IG, WA)**


Construir um agente de vendas que responde automaticamente em três canais: WhatsApp, Instagram e Facebook, coleta informações, cria contatos e oportunidades, e agenda reuniões. Tudo isso sem perder nenhum lead.



1. **🧪 Demonstração inicial**
   Mostra-se como o agente funciona preenchendo um formulário estilo oficina mecânica.
   O formulário coleta: nome, e-mail, marca, modelo, ano, serviço, placa e número de WhatsApp.
   Ao enviar:

* Cria ou atualiza o contato no PostgreSQL
* Gera uma nova oportunidade
* Dispara uma mensagem automática no WhatsApp via Evolution API

2. **🟢 WhatsApp como canal de entrada**

* Um webhook detecta mensagens recebidas
* Filtra mensagens do tipo `message.received` e que **não** foram enviadas pelo próprio agente (`fromMe = false`)
* Limpa o número de telefone para encontrar correspondência no banco de dados
* Um *switch* decide se a entrada é texto ou áudio
* Se for texto, constrói um *prompt* com os dados e envia ao agente de vendas (GPT 4.1)
* O agente responde, agenda reunião (se necessário) e atualiza o CRM

3. **🟣 Instagram como canal de entrada**

* Processo igual ao anterior, usando integração HTTP com a API do Instagram
* Configurado pelo Meta Developers com webhook e token
* Ao receber uma mensagem, constrói-se o mesmo *prompt* e envia ao agente
* A resposta é enviada via endpoint de mensagens do Instagram

4. **🔵 Facebook Messenger**

* Mesmo processo do Instagram
* Configuração via Meta Developers
* Recebe o webhook, filtra eventos e responde com mensagem gerada pelo agente

🤖 **AGENTES CONECTADOS**

* **Agente Principal**

  * Recebe o prompt, canal e dados do lead
  * Decide se precisa de mais informações
  * Redireciona para:

    * Agente de CRM (para contatos e oportunidades)
    * Agente de Calendário (para agendamentos)

* **Agente de CRM**

  * Busca o contato pelo número de WhatsApp
  * Se não existir, cria novo contato
  * Se existir, atualiza os dados
  * Cria nova oportunidade para cada serviço solicitado
  * Estados possíveis: Qualificado, Reunião Agendada, Proposta Enviada, Negociação, etc.

* **Agente de Calendário**

  * Cria, atualiza ou cancela eventos
  * Agenda a reunião no calendário
  * Usa variáveis como “data estimada +7 dias”

💾 **BASE DE DADOS**

* PostgreSQL armazena contatos, oportunidades e histórico completo das conversas
* Pode ser substituído por AirTable ou Google Sheets caso não haja servidor próprio

📈 **MELHORIAS OPCIONAIS**

* Adicionar base vetorial (com Supabase + Embeddings da OpenAI) com a documentação da empresa para respostas mais contextualizadas
* Inserir *delays* entre as respostas para deixar a conversa mais natural
* Separar claramente os fluxos de saída por canal (usando Switch para WhatsApp, Instagram e Facebook)

🛠️ **FERRAMENTAS UTILIZADAS**

* Evolution API para enviar/receber mensagens no WhatsApp
* PostgreSQL como banco de dados
* Meta Developers para conectar Instagram e Facebook
* OpenAI GPT 4.1 como motor de conversa
* Supabase (opcional) para base vetorial

✅ **RESULTADO FINAL**
Um sistema automatizado que:

* Detecta e responde mensagens em três canais
* Registra contatos e oportunidades
* Agenda reuniões automaticamente
* Responde com contexto e lógica avançada, graças aos agentes

**Recursos:**

* Agente Vendedor
* Sub-Agente CRM
* Sub-Agente Calendário
