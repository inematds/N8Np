**Seu Agente Automatizado de Busca e Candidatura de Empregos DeepSeek AI [Sem Código com n8n, LinkedIn e Perplexity]**

**Resumo Geral:**
Neste tutorial, o autor mostra como criar um agente de IA que automatiza todo o processo de busca e candidatura de empregos: encontrar vagas no LinkedIn, gerar cartas de apresentação personalizadas e enviar as candidaturas — tudo sem escrever uma linha de código, usando n8n, DeepSeek AI e Perplexity AI.

**Demonstração Rápida:**
- Realiza busca de vagas no LinkedIn (exemplo: "Prompt Engineer" nos EUA).
- Atualiza automaticamente uma planilha no Google Sheets com as vagas mais recentes.
- Puxa suas informações pessoais (experiência, currículo, dados de contato).
- Gera e envia cartas de apresentação personalizadas para os e-mails das empresas, junto com o currículo.

**Ferramentas Utilizadas:**
- **n8n** (plataforma de automação no-code)
- **RSS.app** (para capturar as vagas do LinkedIn via feed RSS)
- **DeepSeek AI** (para gerar consultas e customizar cartas de apresentação)
- **Perplexity AI via Sona Pro** (para buscar e-mails das empresas)
- **Google Sheets** (armazenar vagas)
- **Google Drive** (armazenar e enviar currículos)
- **Gmail** (enviar e-mails)

---

### Estrutura do Sistema:

**1. Primeiro Workflow: Captura de Vagas e Contatos**
- Pega vagas recentes do LinkedIn via RSS.
- Converte títulos de vagas em consultas de linguagem natural com DeepSeek AI.
- Busca e-mails de empresas e descrição das empresas usando Perplexity AI.
- Salva os dados únicos (sem duplicação) no Google Sheets.

**2. Segundo Workflow: Agente de Aplicação para Empregos**
- Automatiza:
  - A coleta de vagas do Google Sheets.
  - O acesso aos dados pessoais do usuário (de um Google Doc).
  - A geração de cartas de apresentação personalizadas.
  - O envio dos e-mails para as empresas.
- Permite gatilho por chat (mensagem recebida) ou agendamento (ex.: horário programado).

**3. Terceiro Workflow: Envio de Carta de Apresentação e Currículo**
- Mapeia campos: e-mail, assunto, corpo da mensagem.
- Faz o download do currículo armazenado no Google Drive.
- Envia o e-mail com currículo em anexo via Gmail.
- Retorna um status de sucesso para cada envio.

---

### Principais Etapas Técnicas:

- **Obter o RSS do LinkedIn:** Criado com RSS.app (precisa usar o teste gratuito ou assinar para acessar o LinkedIn).
- **Configurar integração com DeepSeek e Perplexity:** 
  - DeepSeek: usa API Key com autenticação "Header Auth" (inclui o token "Bearer" no cabeçalho).
  - Perplexity (Sona Pro): semelhante ao DeepSeek, para buscar informações das empresas.
- **Gerenciar Planilhas Google e Documentos:** 
  - Google Sheets para vagas.
  - Google Docs para dados pessoais (como um "banco de dados" do seu perfil).
- **Enviar E-mails:** 
  - Via Gmail API, configurada para envio automático das candidaturas personalizadas.
  - Currículo em anexo.
  - Sem assinatura automática do n8n.

---

### Fluxo Visual (Simplificado):

```LinkedIn RSS → n8n → Google Sheets
        ↓
DeepSeek AI → consulta + conversão
        ↓
Perplexity AI → busca de e-mail e resumo da empresa
        ↓
Google Sheets (armazenar dados)
        ↓
n8n Agente → gera carta personalizada
        ↓
n8n → Gmail → Envia e-mail + Currículo```

---

N**otas Importantes:
**- Para usar RSS.app para LinkedIn, é necessário criar o feed pelo painel deles.
- Cada carta de apresentação é personalizada com a descrição da empresa e o perfil do candidato.
- A automação usa três fluxos distintos, mas interligados.
- Todo o processo pode ser acionado manualmente, por chat ou de forma agendada.

**05 Agente de IA para Busca e Candidatura Automatizada de Empregos**

**Pergunta Relacionada**

**P:** Estou procurando ajuda de um administrador ou especialista da comunidade que possa construir um sistema totalmente automatizado de candidatura a empregos usando o n8n e ferramentas de IA.

**R:** Para criar um sistema de candidatura a empregos remotos com IA utilizando o n8n e ferramentas de inteligência artificial, siga estes passos:

1. **Definir Requisitos:** Especifique claramente as funcionalidades desejadas no sistema, como análise de currículos, correspondência de candidatos e respostas automáticas.

2. **Selecionar Ferramentas:** Escolha as ferramentas de IA mais adequadas às suas necessidades, como processamento de linguagem natural (NLP) para análise de currículos ou algoritmos de machine learning para triagem de candidatos.

3. **Configurar o Workflow no n8n:** Use o n8n, uma ferramenta de automação, para criar fluxos de trabalho que conectem diferentes serviços e automatizem tarefas como receber candidaturas, processar currículos e enviar notificações.

4. **Integrar Ferramentas de IA:** Integre as ferramentas de IA escolhidas no fluxo do n8n para permitir o processamento inteligente das candidaturas, como extração de informações relevantes dos currículos ou avaliação das qualificações dos candidatos.

5. **Testar e Refinar:** Teste o sistema minuciosamente para garantir que ele funcione conforme o esperado, ajustando os fluxos e os algoritmos de IA conforme necessário para melhorar a precisão e eficiência.

6. **Implantar e Monitorar:** Implante o sistema para uso e monitore seu desempenho regularmente para identificar problemas ou oportunidades de otimização.
