Aqui está o **resumo completo "Conexões do Google no n8n (Drive, Gmail, Calendar, Docs e Sheets)"** com todos os passos explicados e listados para facilitar sua implementação:

---

## Resumo Geral:
O vídeo ensina como configurar conexões entre o n8n e os serviços do Google (Drive, Gmail, Calendar, Docs e Sheets), criando credenciais OAuth2 via Google Cloud Console e conectando corretamente ao n8n.  

O criador reforça que utilizar uma **conta Google paga** (Google Workspace) evita limitações comuns em contas gratuitas.

---

## Etapas Listadas:

### 1. **Criar um projeto no Google Cloud**
- Acesse: [https://console.cloud.google.com](https://console.cloud.google.com/)
- Clique em “Selecionar projeto” > “Novo projeto”
- Nomeie (ex: `Google YouTube 01-04-25`)
  
### 2. **Ativar as APIs necessárias**
Ative as APIs no projeto:
- Google Drive API
- Google Calendar API
- Gmail API
- Google Docs API
- Google Sheets API

### 3. **Configurar a tela de consentimento OAuth**
- Vá em “Tela de consentimento OAuth”
- Tipo de usuário: Externo
- Nome do app: exemplo `YouTube Google 01-04-25`
- E-mail de suporte: insira seu e-mail
- Domínio autorizado: domínio onde o n8n está instalado (ex: `https://seu-dominio.com`)
- Usuário de teste: insira o e-mail Google que fará login

### 4. **Adicionar os escopos (scopes)**
Clique em “Adicionar ou remover escopos” e adicione os seguintes:
#### Google Drive
- `.../auth/drive` – acesso total ao Drive

#### Google Calendar
- `.../auth/calendar` – editar, criar e excluir eventos

#### Gmail
- `.../auth/gmail.modify` – escrever, enviar e excluir e-mails

#### Google Docs
- `.../auth/documents` – criar, editar e excluir documentos

#### Google Sheets
- `.../auth/spreadsheets` – criar, editar e excluir planilhas

### 5. **Criar uma credencial OAuth 2.0**
- Vá em “Credenciais” > “Criar credencial” > OAuth 2.0
- Tipo de aplicativo: Aplicativo da Web
- Nome: algo como `Google-01425`
- Adicione o URI de redirecionamento do n8n:
  - Encontre em: n8n > Credenciais > Google > campo `Redirect URL`
  - Copie e cole no Google Cloud

### 6. **Copiar Client ID e Secret para o n8n**
- Copie o `Client ID` e o `Client Secret`
- No n8n, vá em Credenciais > Criar nova para:
  - Google Drive
  - Google Calendar
  - Gmail
  - Google Docs
  - Google Sheets
- Cole os dados em cada integração
- Clique para fazer login com o Google (com o e-mail autorizado)
- Permita o acesso

### 7. **Testar cada integração**
- Em cada nó (Drive, Calendar, etc.), escolha o tipo de ação (ex: “Copy File”, “Create Event”, “Get Message”)
- Teste a execução manual para verificar se a conexão está funcionando corretamente

---

## Exemplos de Escopos:
| Serviço         | Escopo sugerido                                 |
|-----------------|--------------------------------------------------|
| Google Drive    | `https://www.googleapis.com/auth/drive`         |
| Google Calendar | `https://www.googleapis.com/auth/calendar`      |
| Gmail           | `https://www.googleapis.com/auth/gmail.modify`  |
| Google Docs     | `https://www.googleapis.com/auth/documents`     |
| Google Sheets   | `https://www.googleapis.com/auth/spreadsheets`  |
