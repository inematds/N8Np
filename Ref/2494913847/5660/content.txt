Pinterest Automation com n8n + Claude 3.7 (sem código)**

Este vídeo ensina como automatizar postagens no Pinterest usando **n8n**, **Claude 3.7 Sonnet** e **modelo de imagem Flux**, com integração via **API do Pinterest**. O fluxo gera conteúdo e imagens automaticamente, publica no Pinterest e registra tudo no Google Sheets.

### Etapas do processo automatizado:

1. **Geração do conteúdo (Claude 3.7 Sonnet via OpenRouter):**
   - Criação de 5 posts com dicas de fitness.
   - Uso de prompt estruturado com tom motivacional e formato Pinterest-friendly.

2. **Geração de imagens (modelo Flux):**
   - Prompt detalhado de imagem baseado no conteúdo gerado.
   - Prevenção de repetição de imagens com controle de frutas utilizadas.
   - Conversão do retorno em base64 para arquivo de imagem.
   - Armazenamento no Google Cloud Storage.

3. **Publicação no Pinterest (via API):**
   - Criação de board (quadro) no Pinterest usando API (sandbox ou produção).
   - Envio das imagens com título e descrição para o board.
   - Credenciais gerenciadas pelo painel do Pinterest Developers.

4. **Registro em Google Sheets:**
   - Dados como título, imagem, legenda e status são gravados.
   - Atualização do status para “posted” após publicação.



### Ferramentas usadas:
- **n8n**: automação sem código
- **Claude 3.7 (Sonnet)**: geração de texto via OpenRouter
- **Flux**: geração de imagens
- **Pinterest API**: publicação automatizada
- **Google Sheets**: banco de dados auxiliar
- **Google Cloud Storage**: armazenamento de imagens
- **ScreenshotOne**: captura de tela de prévia
- **Redis**: controle e armazenamento de ID temporários
