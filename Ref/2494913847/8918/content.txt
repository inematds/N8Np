promtp do agente

Você é um assistente inteligente de busca de produtos para uma empresa de suprimentos de escritório doméstico. Ajude os clientes a encontrar produtos, verificar disponibilidade e fornecer preços precisos por meio de uma conversa natural.

\##Ferramentas

\###Ferramenta Pinecone

* Buscas amplas: "fones de ouvido sem fio", "notebooks baratos"
* Pesquisas por características: "cancelamento de ruído", "caixas de som à prova d’água"
* Navegação por categoria: "tablets Apple", "acessórios para gamers"

\###Ferramenta Airtable

* Usada após a busca com Pinecone
* Verifica níveis de estoque e preços exatos
* Consultas específicas: "estoque do caderno Moleskine"
* Buscas diretas por nome ou categoria do produto

\##Fluxo de Trabalho

* **Descoberta**: Use a Ferramenta Pinecone para realizar uma busca semântica com a consulta do cliente
* **Verificação**: Use a Ferramenta Airtable com o termo ou categoria específica para verificar estoque e preços dos produtos encontrados
* **Resposta**: Apresente as opções disponíveis com dados em tempo real

\##Exemplos

* Consulta: "fones de ouvido sem fio abaixo de 200 reais"

* Processo:

  1. Busca com Ferramenta Pinecone: "fones de ouvido sem fio abaixo de 200"
  2. Consulta na Ferramenta Airtable: filtrar resultados com preço ≤ R\$200 e estoque > 0
  3. Apresentar opções disponíveis com preços atuais

* Complemento: "algo mais barato"

* Processo: buscar na mesma categoria com faixa de preço menor, com base no contexto da conversa

\##Regras Importantes

* **SEMPRE** verifique o estoque com a Ferramenta Airtable antes de confirmar disponibilidade
* Use preços **EXATOS** do banco de dados, nunca estimativas
* Para itens fora de estoque, sugira alternativas disponíveis
* Mantenha as respostas em tom de conversa e limite a 3 a 5 opções de produtos
* Lembre-se do **contexto da conversa** para perguntas de acompanhamento
* **Não** inclua a quantidade em estoque na resposta para o usuário

1.4. Configure o evento para `On Message`
1.5. Cole o token do bot no campo de autenticação
1.6. Salve e teste enviando uma mensagem para o bot

---

* Memória do tipo *window buffer*
* `chat_id` dinâmico baseado na mensagem recebida

2.4. Crie uma mensagem simples de teste ("Recebido. Em que posso ajudar?")
2.5. Adicione o nó **Telegram Send Message**
2.6. Envie a resposta do modelo para o usuário

**Resumo completo sobre o bot com RAG no Telegram usando n8n, Pinecone e Airtable**

Como criar um **agente de IA no Telegram** que faz busca semântica usando **Pinecone** e valida os dados com **Airtable**, usando o **n8n** para orquestrar o fluxo.

### Objetivo

Criar um bot no Telegram que responde a buscas de produtos (como canetas ou cadernos), fazendo uma pesquisa em vetor (Pinecone) e validando os resultados com informações detalhadas via Airtable (como preço e categoria).

---

### Etapas do Projeto

1. **Configuração Inicial**

   * Integração com Telegram via trigger `on message`
   * Criação do bot e inserção do token de acesso
   * Configuração de resposta básica do bot com modelo de chat simples

2. **Criação do Contexto do Agente**

   * Adição de mensagem de sistema explicando o papel do agente
   * Instruções: usar Pinecone para busca semântica e Airtable para verificar disponibilidade e preço
   * Exemplo: cliente pede uma caneta → busca semântica no Pinecone → filtro no Airtable

3. **Banco de Dados**

   * Pinecone:

     * Dados vetoriais embutidos com metadados (ID, descrição, marca, preço, etc.)
     * Embedding com modelo do OpenAI
   * Airtable:

     * Estrutura parecida, mas com uso de filtros (ex: produtos abaixo de R\$ 45)
     * Usado para validar e complementar a resposta

4. **Criação das Ferramentas**

   * **Ferramenta Pinecone:**

     * Nomeada como "pinecone tool"
     * Faz busca por descrição, marca ou categoria
   * **Ferramenta Airtable:**

     * Nomeada como "inventory tool"
     * Requer escopo de leitura
     * Conectada com token e configurada para buscar registros

5. **Fluxo no n8n**

   * Recebe mensagem do Telegram
   * Usa Pinecone para busca semântica
   * Passa os resultados para o Airtable, que filtra por critérios (ex: preço)
   * Retorna ao usuário os produtos encontrados
   * Mantém a conversa aberta para respostas adicionais

6. **Exemplos e Testes**

   * Teste com busca de "notebook de couro" → retornou nome, preço e descrição
   * Teste com "caneta abaixo de 20" → retornou sugestões e perguntou se queria mais informações
   * Ajustes finos: removido o campo de quantidade em estoque da resposta

7. **Possibilidades Futuras**

   * Incluir nota média dos produtos, número de vendas, integração com Shopify para compra
   * Escalabilidade para centenas ou milhares de produtos

---

### Conclusão

* O sistema combina **busca inteligente (Pinecone)** com **verificação estruturada (Airtable)**.
* A interação é fluida e pode ser facilmente personalizada.
* Pode ser replicado para outros tipos de atendimento automático, em poucas horas, com ferramentas no-code como o n8n.

---

### Exemplos de uso

* Lojas online com grande catálogo
* Assistente de recomendação de produtos
* Atendimento automatizado via Telegram com IA
