Aqui está o **passo a passo completo** da automação explicada no vídeo, usando **Airtable + n8n + IA (Perplexity, Claude, Gemini ou ChatGPT)**. Ele cobre desde a criação do projeto até a geração e revisão de guias publicitários.

---

## Etapa 1 – Estrutura Inicial no Airtable

1. **Crie 3 abas principais**:

   * `Projetos`: nome do projeto, cliente, status.
   * `Serviços`: nome do serviço, descrição, status, tipo de ação, ID do projeto.
   * `Guiões`: onde serão gerados os ângulos e roteiros finais.

2. **Adicione campos manuais e automáticos**:

   * Campos manuais: descrição, tipo de guião, feedback do cliente.
   * Campos automáticos: status do processo, campos gerados por IA (detalhes, ângulos, guião).

3. **Adicione botões (opcional se for versão gratuita)**:

   * Botão para "Gerar Detalhes"
   * Botão para "Gerar Ângulos"
   * Botão para "Gerar Guião"
   * Botão para "Revisar Guião"

---

## Etapa 2 – Criação do Webhook no n8n

1. **Crie um node Webhook** com método `POST`.
2. **Defina os campos que serão recebidos**:

   * `record_id`
   * `action` (ex: gerar\_detalhes, gerar\_angulos, etc.)

---

## Etapa 3 – Fluxo de Ações com Switch

1. **Adicione um `Switch` logo após o Webhook**:

   * Condição: `action` igual a:

     * `gerar_detalhes`
     * `gerar_angulos`
     * `gerar_guiao`
     * `gerar_feedback`

2. **Para cada fluxo, crie um caminho separado no n8n**:

   * Cada caminho deve obter os dados via `Airtable → Get Record` usando `record_id`.

---

## Etapa 4 – Gerar Detalhes com Perplexity

1. **Monte o `user_prompt` com os dados do serviço**:

   * Nome do serviço
   * Descrição
   * Notas do cliente

2. **Configure o `HTTP Request` com Perplexity**:

   * Endpoint: `https://api.perplexity.ai/completions`
   * Authorization: `Bearer <SUA_API_KEY>`
   * Body: JSON com:

     ```     {
       "model": "sonar-reasoning",
       "messages": [
         {
           "role": "system",
           "content": "Você é um analista de marketing que escreve análises profundas sobre serviços e perfis de cliente."
         },
         {
           "role": "user",
           "content": "{{user_prompt}}"
         }
       ]
     }
     ```

3. **Limpe o texto entre tags `sync` com `Function`**:

   * Remova o conteúdo entre `sync` para deixar só o conteúdo útil.

4. **Atualize a aba `Serviços` no Airtable**:

   * Campos: `status = detalhes gerados`, `detalhes = resposta do Perplexity`.

---

## Etapa 5 – Gerar Ângulos com Gemini/Claude

1. **Crie prompt com:**

   * Detalhes do serviço
   * Cliente ideal
   * Ângulos anteriores (se houver)

2. **Use Gemini ou Claude (HTTP ou API nativa)**:

   * Gere um array JSON com:

     * `titulo`
     * `conceito`
     * `estrutura`
     * `visual`
     * `gatilhos`
     * `técnicas`
     * `viés cognitivo`

3. **Utilize `Split in Batches` para separar cada ângulo**.

4. **Crie registros em `Guiões` (create record)** com os dados gerados.

5. **Atualize status no Airtable para `ângulos gerados`.**

---

## Etapa 6 – Gerar Guiões

1. **Crie `Switch` baseado no tipo de guião** (AIDA, PAS, 4Ps, etc.).

2. **Monte prompt personalizado** com:

   * Dados do ângulo
   * Duração desejada
   * Estrutura escolhida
   * Transcrição do anúncio vencedor (opcional)

3. **Use Claude, ChatGPT ou outro modelo** para gerar o guião.

4. **Atualize no Airtable**:

   * Campo `guiao`
   * Campo `status = guiao gerado`

---

## Etapa 7 – Revisão de Guião (Feedback)

1. **Usuário envia comentário direto no Airtable**.

2. **Webhook recebe o comentário e record\_id.**

3. **Prompt para revisão com IA**:

   * Inclui: guião original + feedback do cliente

4. **IA responde com novo guião melhorado**.

5. **Atualiza campo `guiao` e `status = revisado` no Airtable**.

---

## Etapa 8 – Exibição Final e Filtros

1. **Crie views no Airtable**:

   * View só com status “guiao revisado”
   * View com estrela (★) para facilitar navegação

2. **Cliente final pode revisar e ajustar diretamente no Airtable.**

---

**Resumo completo – Parte 2 da Automação de Anúncios com Airtable, n8n e IA**

Esta segunda parte  aprofunda a criação de um sistema de automação de anúncios com base em **AirTable, n8n, Perplexity, Gemini, ChatGPT e Claude**, criando todo o processo desde a coleta de dados até geração e revisão de guias de anúncios publicitários.

### Estrutura da Automação Explicada

1. **Revisão da Parte 1**:

   * Automação para coleta de dados do Meta Ads (semanais, mensais e por anúncio).
   * Transcrição de anúncios vencedores com áudio.

2. **Nova Etapa (Parte 2)**:

   * Expansão do sistema simulando uma **agência de marketing com múltiplos serviços**.
   * Preenchimento manual de informações de projetos e serviços no Airtable.

3. **Geração automática por etapas**:

   * **Gerar Detalhes do Serviço**: definição de serviço, cliente ideal, descrição detalhada, etc.
   * **Gerar Ângulos Publicitários**: a partir dos detalhes gerados, cria sugestões de abordagem para anúncios.
   * **Gerar Guiões**: cria roteiros completos com base na estrutura (AIDA, PAS, 4Ps, etc.).
   * **Gerar Feedback**: revisa e melhora guias existentes com base em comentários manuais.

### Detalhamento técnico e operacional

* **Webhook no n8n** é acionado por botão ou automação no Airtable.
* Um **switch (condicional)** no n8n redireciona o fluxo conforme a ação (detalhes, ângulos, guião, feedback).
* Utilização de **Perplexity (via API REST)** para gerar detalhes dos serviços.
* Utilização de **modelos como Gemini ou Claude** para gerar os ângulos e guias.
* Aplicação de **parsers e estruturas JSON** para garantir organização e evitar erros de formatação.
* **Atualização automática** do Airtable com:

  * Estado ("gerando", "detalhes gerados", "ângulos gerados", etc.).
  * Campos como título, estrutura, sugestões visuais, gatilhos, técnicas de resposta, e viés cognitivo.

### Estruturas de guias usadas:

* **Modelos AIDA, PAS, 4Ps, FAP**, etc.
* Cada tipo de guião tem sua própria automação e prompt adaptado.
* Feedback é aplicado com base nos ajustes fornecidos pelo cliente (ex: início mais impactante).

---

### Tópicos listados com exemplos

1. **Integração com Airtable**
   Exemplo: botão no Airtable aciona webhook com `record_id` e ação `gerar_detalhes`.

2. **Geração de detalhes com Perplexity**
   Prompt inclui: descrição do serviço + notas + público-alvo → resultado: perfil do serviço completo.

3. **Criação de ângulos publicitários**
   IA recebe os detalhes e retorna JSON com:

   * Título
   * Conceito
   * Estrutura
   * Visual sugerido
   * Gatilhos emocionais
   * Técnicas de resposta direta

4. **Geração de guias com diferentes estruturas**
   IA (Claude ou GPT) retorna roteiros completos com base em estrutura escolhida (ex: AIDA).

5. **Sistema de feedback com IA**
   Exemplo: cliente pede mais impacto → IA reescreve o início com frase como “Deixa de te matar de trabalhar como um escravo...”.

6. **Separação de ideias por Split e criação de registros**
   Cada novo guia ou ângulo é armazenado individualmente no Airtable como novo registro.

7. **Flexibilidade e personalização por projeto/cliente**
   Pode ser replicado para múltiplos projetos, serviços e estruturas publicitárias.

8. **Feedback visual via status e campos**
   Campos como `status = guion revisado` e uso de estrela (★) para marcar guias prontos.

9. **Escalabilidade da automação**
   Possível gerar múltiplos guias ao mesmo tempo para diversos tipos de estruturas.

10. **Interface amigável e adaptável ao cliente**
    Clientes podem interagir com campos no Airtable sem ver a lógica por trás.

Aqui estão os **principais hacks e truques **, organizados por etapa da automação e criação de anúncios:

---

### **Hacks de Automação com n8n + Meta Ads**

1. **Filtragem inteligente por status ativo**

   * Evita puxar campanhas/ad sets/anúncios pausados ou antigos.
   * Usa condições `effective_status == ACTIVE` para focar no que importa.

2. **Delay estratégico para evitar bloqueios da API**

   * Adiciona um **nó de espera de 30 segundos** antes de puxar dados detalhados.
   * Isso impede que o Meta bloqueie por excesso de requisições simultâneas.

3. **Extração máxima de métricas com poucos nós**

   * Usa o campo `fields` para pegar todas as métricas de uma só vez:

     * CTR, CPC, CPM, custo, conversões, visualizações, etc.

4. **Condição combinada no final**

   * Só registra o anúncio no Airtable se:

     * O anúncio estiver ativo
     * Os **insights existirem**
     * O **vídeo ID estiver presente**

---

### **Hacks de Organização no Airtable**

5. **Agrupamento por data, campanha e ad set**

   * Permite uma visão semanal/mensal por nível hierárquico.
   * Muito útil para diagnóstico visual e comparações.

6. **Criação de campos com fórmulas**

   * Campos como **ROAS** e **engajamento** são calculados automaticamente.
   * Exemplo: `ROAS = Valor de conversão ÷ Gasto`

7. **Botão ou checkbox para ativar automações**

   * Aciona Webhook no n8n quando clicado.
   * Funciona mesmo em contas gratuitas usando botão.

---

### **Hacks com vídeos e OpenAI**

8. **Transcrição de vídeos do Meta direto pela URL**

   * Extração da **SD URL do vídeo** com HTTP Request básico (sem API externa).
   * Permite baixar o vídeo e extrair o áudio com **Whisper da OpenAI**.

9. **Uso de vídeos vencedores como referência**

   * Transcreve o anúncio que teve melhor desempenho.
   * Usa a transcrição como input para criar novos roteiros com IA.

---

### **Hacks de Criação de Anúncios com IA**

10. **Prompting com contexto real (dados + transcrição)**

    * Ao gerar ângulos e roteiros, inclui:

      * Nome da campanha
      * Público-alvo
      * Produto/serviço
      * Transcrição de anúncio de sucesso

11. **Formatos variados de roteiros prontos**

    * Automatiza geração nos formatos:

      * AIDA
      * PAST
      * 4Ps
      * FAB
      * Storytelling

12. **Customização rápida via prompt**

    * Exemplo: mudar o nome do protagonista ou o nicho (ex: "Pedro Sánchez", advogado).
    * Geração do novo roteiro adaptado automaticamente.

Segue o **passo a passo detalhado** para automatizar **a extração de métricas de anúncios do Meta Ads** e **gerar roteiros publicitários com IA**, usando **n8n**, **Airtable** e **OpenAI**.

---

### **PARTE 1 – Extração e organização de métricas**

#### **1. Criar um App no Meta for Developers**

* Acesse: [https://developers.facebook.com/](https://developers.facebook.com/)
* Crie um app do tipo **Business**
* Preencha: nome do app, e-mail, política de privacidade
* Vá em **Marketing API → Ferramentas**
* Gere o token no **Graph API Explorer** com essas permissões:

  * `ads_management`
  * `ads_read`
  * `pages_read_engagement`
  * `pages_manage_posts`
  * `business_management`
  * `read_insights`
* Copie o token gerado

---

#### **2. Configurar credencial no n8n**

* Vá em **Credentials > Facebook Graph API**
* Adicione o **access token**
* Teste a conexão

---

#### **3. Criar fluxo no n8n**

##### **Passo 1: Agendador**

* Use o nó **Cron** para rodar toda segunda-feira às 07:00

##### **Passo 2: Buscar contas de anúncios**

* Nó: **HTTP Request**
* Endpoint: `/me/adaccounts`
* Método: GET

##### **Passo 3: Listar campanhas**

* Para cada conta (`split`), buscar `/adaccounts/{id}/campaigns`
* Campos: `id`, `name`, `effective_status`

##### **Passo 4: Filtrar campanhas ativas**

* Condição: `effective_status == ACTIVE`

##### **Passo 5: Listar ad sets**

* Endpoint: `/campaigns/{id}/adsets`
* Campos: `id`, `name`, `effective_status`

##### **Passo 6: Filtrar ad sets ativos**

##### **Passo 7: Aguardar 30 segundos**

* Nó: **Wait**

##### **Passo 8: Listar anúncios**

* Endpoint: `/adsets/{id}/ads`
* Campos:

  * `id`, `name`, `effective_status`
  * Creative: `image_url`, `video_url`, `permalink_url`
  * Insights: `clicks`, `impressions`, `cpm`, `cpc`, `ctr`, `spend`, `frequency`, `conversions`, `view_time`, etc.

##### **Passo 9: Filtrar anúncios com insights**

* Condição:

  * `effective_status == ACTIVE`
  * `insights != null`
  * `video_id != null` (se trabalhar com vídeos)

##### **Passo 10: Enviar para Airtable**

* Configure uma tabela com os campos:

  * `Data`, `Campanha`, `Ad Set`, `Anúncio`
  * `CPC`, `CPM`, `Cliques`, `Impressões`, `Gasto`, `Conversões`, `Tempo médio`, `% Visualizado`, `Video ID`, `Transcrição`
* Use o nó **Airtable > Create Record**

---

### **PARTE 2 – Transcrição e criação de roteiros com IA**

#### **11. Automatizar transcrição de vídeos**

* Botão ou checkbox no Airtable ativa Webhook
* n8n:

  * `Webhook` → Recebe `record_id`
  * `Airtable > Get Record` → Puxa o registro
  * `Facebook Graph API` → Usa `video_id` para pegar `permalink_url`
  * `HTTP Request` → Baixa o vídeo
  * `OpenAI > Transcribe Audio` (modelo Whisper) → Transcreve
  * `Airtable > Update Record` → Salva a transcrição

---

#### **12. Criar briefing do projeto com IA**

* Dados do cliente e serviços no Airtable
* Use **Perplexity** via API ou manualmente para enriquecer as informações

---

#### **13. Gerar ângulos publicitários**

* Prompt exemplo:

  `  Com base nesses dados de serviço e público-alvo, gere 5 ângulos publicitários criativos para anúncios que usem storytelling, gatilhos emocionais e técnicas de copywriting.
  `

---

#### 1**4. Gerar roteiros
**
* Escolher formato (ex: AIDA, PAST, 4Ps, FAB, Storytelling)
* Prompt exemplo:

   ` Crie um roteiro de 1 a 3 minutos usando o método AIDA com base nesse ângulo: “A automação que as agências não querem que você conheça”.
  Contexto: [transcrição de vídeo vencedor + dados da empresa]
