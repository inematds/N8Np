IMPORTANTE: Atualização Evolution API


Recebemos muitas mensagens sobre falhas na Evolution API: o código QR não é gerado, os webhooks não funcionam… Mas já temos a solução.

O que aconteceu?
O WhatsApp alterou uma variável interna usada pela Evolution API para sincronização com o WhatsApp Web, causando erros nas versões antigas.

Como resolver?
Você só precisa atualizar a configuração do seu stack no Portainer seguindo estes passos:

PASSO 1: Atualize a imagem do container
Troque a linha do repositório antigo por esta nova:
imagem: evoapicloud/evolution-api\:latest
Esta imagem garante a versão mais recente, compatível com as mudanças do WhatsApp.

PASSO 2: Modifique (ou comente) a variável de ambiente
Se a variável abaixo estiver presente na sua stack:
CONFIG\_SESSION\_PHONE\_VERSION=2.2322.14.0
Substitua por:
CONFIG\_SESSION\_PHONE\_VERSION=2.3000.1023204200
Ou, se estiver usando a versão mais nova da Evolution API, apenas comente ou exclua a linha:

# CONFIG\_SESSION\_PHONE\_VERSION=2.3000.1023204200

PASSO 3: Atualize a stack
Clique em “Atualizar a stack” no Portainer.
Aguarde alguns segundos para que o serviço volte a funcionar.

Pronto! O sistema estará funcionando normalmente.

Dica : Se não for necessário manter versões antigas, utilize sempre a nova imagem e remova essa variável para evitar erros no futuro.

---

**Resumo dos tópicos e exemplos:**

1. **Problema**

   * Falha na Evolution API (QR não gera, webhooks param de funcionar).

2. **Motivo**

   * Mudança de variável interna do WhatsApp.

3. **Solução passo a passo**

   * Atualizar a imagem do container para a mais recente.

     * Exemplo: `evoapicloud/evolution-api:latest`
   * Modificar ou remover a variável de ambiente da sessão.

     * Exemplo: substituir ou comentar a linha da variável.
   * Atualizar a stack no Portainer.

4. **Recomendação**

   * Sempre usar a versão mais atualizada da API e remover variáveis antigas para evitar problemas.
