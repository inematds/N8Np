Aqui vai o prompt perfeito para o Claude Opus criar um workflow n8n com Vibe Code, já otimizado para:

✅ Ler todos os e-mails recebidos em tempo real
✅ Gravar no Google Sheets os campos Assunto, Hora, De (remetente) e Para (destinatário)
✅ Enviar o conteúdo do e-mail para análise por um agente de IA (Claude, GPT, etc.) e gravar o resultado também na planilha


Prompt para Claude Opus (Vibe Code n8n)

Crie um workflow n8n modular, otimizado e legível em formato Vibe Code com os seguintes requisitos:



Gatilho (Trigger):


Use o nó IMAP Email para monitorar uma caixa de entrada de e-mail (pode ser Gmail, Outlook ou outro IMAP).


Configure para buscar e-mails assim que chegarem (polling ou webhook se suportado).


Busque apenas e-mails não lidos.




Processamento do E-mail:


Extraia os seguintes campos de cada e-mail:


subject (Assunto)


date (Hora de recebimento, formato ISO)


from (Remetente)


to (Destinatário)






Gravação no Google Sheets:


Conecte ao Google Sheets via OAuth.


Crie (ou use) uma planilha chamada "Registro de E-mails" no Google Drive.


Cada nova linha deve conter os campos extraídos: Assunto, Hora, De, Para.


Garanta que o workflow verifique duplicidade para não registrar o mesmo e-mail mais de uma vez.




Análise com IA:


Envie o conteúdo completo do e-mail (corpo e assunto) para um agente de IA.


Use uma API REST com o modelo Claude Opus, GPT-4 ou outro LLM configurado (defina URL e key como variáveis de ambiente).


Solicite ao agente um resumo breve e uma classificação do e-mail como: Informativo, Urgente, Tarefa, Spam ou Outro.




Gravação da Análise no Google Sheets:


Adicione uma coluna extra na planilha chamada "Análise IA" para gravar o resumo e a classificação retornados.




Notificação (Opcional):


Envie uma notificação (via Telegram, Slack ou e-mail) quando o agente classificar um e-mail como Urgente.




Boas práticas:


Use funções auxiliares para tratamento de erros (nó IF e Error Trigger).


Nomeie os nós de forma descritiva (ex.: "Extrair Campos", "Gravar no Sheets", "Analisar com IA").


Estruture o Vibe Code para ser facilmente editável para diferentes caixas de entrada e planilhas.





Exemplo de Estrutura do Workflow (Vibe Code)

`# Trigger para novos e-mails
trigger IMAP Email {
  host: "imap.gmail.com"
  port: 993
  secure: true
  credentials: ENV.IMAP_CREDENTIALS
  filter: "UNSEEN"
}

# Extrair campos do e-mail
function extractFields(email) {
  return {
    assunto: email.subject,
    hora: email.date,
    de: email.from.text,
    para: email.to.text,
    corpo: email.text
  }
}

# Enviar para IA
httpRequest POST {
  url: ENV.AI_API_URL
  headers: {
    Authorization: "Bearer " + ENV.AI_API_KEY
  }
  body: {
    content: email.corpo,
    subject: email.assunto
  }
  response: aiResponse
}

# Gravar no Google Sheets
google.sheets.appendRow {
  spreadsheetId: ENV.SHEET_ID
  range: "Registro de E-mails!A:E"
  values: [
    email.assunto,
    email.hora,
    email.de,
    email.para,
    aiResponse.summary + " (" + aiResponse.category + ")"
  ]
}

# Notificação para e-mails urgentes
if (aiResponse.category == "Urgente") {
  telegram.sendMessage {
    chatId: ENV.TELEGRAM_CHAT_ID
    text: "⚠️ Novo e-mail URGENTE de " + email.de + ": " + email.assunto
  }
}
`

e30. Automatize fluxos do N8N

🎯 **Objetivo**
Demonstrar como um agente de inteligência artificial pode construir fluxos de automação completos no N8N, partindo de uma simples instrução do usuário ou até mesmo de uma transcrição completa de um vídeo. Esta aula marca uma nova etapa na automação, onde o “prompt engineering” e o pensamento estratégico passam a ter mais valor do que a implementação técnica manual.

🧩 **Estrutura do fluxo automatizado**
O fluxo apresentado parte de uma ideia simples: processar automaticamente e-mails do Gmail, gerar respostas com IA e reenviá-las. Essa ideia foi transformada em um fluxo completo no N8N usando um agente construtor baseado no Claude Opus.

🔷 **Exemplo 1: Resposta automática a e-mails no Gmail**

* **Entrada:** Comando verbal ao agente descrevendo o fluxo desejado.
* **Processamento:** O agente interpreta o pedido e gera um JSON válido para o N8N.
* **Construção automática:** O fluxo é criado automaticamente e enviado ao ambiente do N8N.
* **Resultado:** Fluxo completo com notas explicativas, configuração de nós e conexões.

🧪 **Segundo exemplo avançado: Automatizar fluxo a partir de um vídeo**

* Foi usada a transcrição de um vídeo explicativo sobre como extrair dados do Google Maps.
* O agente processou toda a transcrição e gerou automaticamente um fluxo com mais de 20 nós bem estruturados.
* **Resultado:** Automação funcional com notas, etapas, variáveis e integração com APIs como o Google Maps.

🛠️ **Como o agente é construído**

* **Entradas-chave:**

  * Prompt do usuário ou transcrição detalhada.
  * Documento base com estrutura válida de fluxos do N8N (nós, conexões, notas).
* **Componentes principais:**

  * Modelo LLM: Claude Opus 4 (ou Sonnet 4 como alternativa).
  * Prompt bem estruturado com instruções claras (JSON esperado, validações, nós, conexões).
  * Documentação de apoio: arquivo .txt com fluxo de exemplo e sticky notes explicativas.
* **Execução técnica:**

  * Usa-se o OpenRouter como intermediário para conectar o agente ao modelo LLM.
  * O JSON gerado é enviado diretamente ao N8N via API para criar o workflow automaticamente.
  * É gerado um link direto para o fluxo criado, facilitando o compartilhamento.

🔧 **Passo a passo para automatizar o processo**

1. Criar um chat simples no N8N onde o usuário possa enviar texto ou transcrições.
2. Extrair o texto de um arquivo .txt ou diretamente do input do chat.
3. Enviar o texto ao modelo Claude Opus 4 com um prompt configurado para gerar JSON válido.
4. Conectar à API do N8N (URL base + chave API).
5. Criar automaticamente o fluxo no N8N e gerar a URL de acesso direto.

💡 **Reflexão final: Onde está o verdadeiro valor?**
“O futuro não está em saber construir automações, mas em imaginar como transformar processos manuais em fluxos automáticos.”

O maior diferencial competitivo não será técnico, mas estratégico e criativo: compreender processos de negócio e traduzi-los em fluxos eficientes. Por isso, dentro da comunidade foi incorporado o módulo Wixyn, focado no desenvolvimento do pensamento de negócio e no design de automações reais.

* Documento exemplo N8N
