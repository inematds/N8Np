Resumo:

Apresenta uma **automação completa no N8N** para **filtrar, classificar e importar mais de 2.000 workflows de um repositório do GitHub**.

### Pontos principais:

* 👥 **Contexto**
  O criador recebeu de sua comunidade um repositório com mais de 2.000 automações para N8N, mas revisar manualmente seria inviável.

* 📥 **Primeiro passo**
  Baixar o repositório do GitHub como ZIP → extrair a pasta *workflows* com os arquivos .json → enviar toda a pasta para o Google Drive em uma pasta chamada *2000 automatizações N8N*.

* 🔄 **Automação no N8N**

  1. **Buscar arquivos no Drive** com o módulo *Search Files and Folders*.
  2. **Loop** para processar cada arquivo JSON individualmente.
  3. **Extrair conteúdo JSON** com *Extract from File*.
  4. **Classificar com IA (Gemini 1.5 Flash gratuito)**:

     * 🟢 Fácil: <10 módulos
     * 🟠 Média: 10-15 módulos
     * 🔴 Avançada: 15-20 módulos
     * 🟣 Complexa: >20 módulos
  5. **Mover arquivos para subpastas no Drive** conforme a classificação e adicionar ícones coloridos aos nomes dos arquivos.

* 🚀 **Upload automático para N8N**
  Apenas os workflows classificados como *Complexos* são enviados para o N8N via API (/api/v1/workflows), com autenticação usando chave API.

* 🔧 **Flexibilidade**
  Pode ser adaptado para outros critérios de classificação (ex.: marketing, redes sociais, HubSpot).

* ⏱️ **Benefícios**
  Filtra e carrega apenas os workflows relevantes, economizando horas de trabalho manual.

* 💡 **Extras**

  * Funciona com Gemini gratuito.
  * O autor usou o sistema para revisar apenas os mais complexos e relevantes.
  * Código para adicionar ícones coloridos aos nomes dos arquivos.

Ele conclui destacando o ganho de tempo e sugere a adaptação para casos de uso específicos (marketing, CRM, etc.). Também disponibiliza o repositório e a automação para download.

29. Domine 2.000 automações no N8N

🧠 Objetivo 

Mostrar como automatizar o processo de filtragem, classificação e upload no N8N de mais de 2.000 workflows disponíveis em um repositório público, utilizando Google Drive, IA para classificação e a API do N8N.

🗂️ Contexto do repositório
É um repositório no GitHub com mais de 2.000 automações para o N8N.

Muitos membros da comunidade compartilharam o recurso, mas revisá-las manualmente é inviável.

O objetivo é classificá-las automaticamente conforme sua complexidade e enviar apenas as mais relevantes para o ambiente de trabalho.

⚙️ Estrutura geral da automação

**Download massivo do repositório**
Acessar o GitHub → Botão "Code" → Opção "Download ZIP".

Dentro do ZIP, há uma pasta chamada *workflows* com todos os arquivos .json.

**Upload para o Google Drive**
Criar uma pasta no Drive: *2000 automações N8N*.

Dentro, gerar subpastas: Fácil, Média, Avançada, Complexa.

Enviar a pasta *workflows* completa para processar os arquivos diretamente do Drive.

**Processamento no N8N**
Usar o módulo *Search Files and Folders* para localizar todos os .json.

Configurar um loop para processar arquivo por arquivo.

**Extração e classificação**
Cada arquivo JSON é baixado e seu conteúdo extraído com *Extract from File*.

Aplicar um *Text Classifier* utilizando Gemini 1.5 Flash (gratuito).

Classificação por número de módulos:

* 🟢 Fácil: menos de 10 módulos.
* 🟠 Média: entre 10 e 15 módulos.
* 🔴 Avançada: entre 15 e 20 módulos.
* 🟣 Complexa: mais de 20 módulos.

**Ações conforme classificação**
Cada automação é movida para a subpasta correspondente no Drive.

Adicionar um ícone de cor ao título do arquivo conforme o nível:

* 🟢 Fácil
* 🟠 Média
* 🔴 Avançada
* 🟣 Complexa

**Upload para o N8N (apenas as complexas no exemplo)**
Usar a API do N8N (/api/v1/workflows) com conexão autenticada.

Criar automaticamente um novo workflow no N8N com o JSON classificado.

Pode ser adaptado para enviar outras categorias, se desejado.

🧩 Adaptabilidade do sistema
A classificação pode ser personalizada com base em:

* Temáticas (marketing, faturamento, redes sociais, etc.).
* Ferramentas usadas no fluxo (ex.: HubSpot, LinkedIn, Facebook, etc.).

O *Text Classifier* permite modificar as instruções para se adequar a qualquer critério útil ao usuário.
