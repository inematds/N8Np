Aqui estão as **principais dicas e hacks práticos** compartilhados no vídeo sobre a automação de anúncios da Meta com avatar:

---

### **1. Faça tudo em massa**
- A automação é feita para rodar com **múltiplos concorrentes** de uma vez.
- Isso permite analisar dezenas de marcas em paralelo, economizando tempo.

---

### **2. Use APIs gratuitas com limite mensal**
- **Website Social Scraper (RapidAPI)** e **Facebook URL to ID (Apify)** possuem planos gratuitos suficientes para testar e rodar pequenos lotes de concorrentes.
- Ele recomenda assinar o plano gratuito e só pagar se for escalar.

---

### **3. Pegue o vídeo em qualidade SD (baixa resolução)**
- Ao fazer scraping dos vídeos, escolha a versão **SD** em vez da HD:
  - **Evita download desnecessário**
  - **Permite pré-visualização direta no Google Sheets**
  - Reduz tamanho e tempo de transcrição

---

### **4. Sempre use `toString()` nos filtros**
- Evita erros de tipo no n8n/Make ao comparar variáveis como IDs ou campos vazios.

---

### **5. Padronize nomes de abas com `replace()`**
- Remove `https://`, `.com`, `.es` etc. da URL para gerar nomes limpos nas abas do Google Sheets:
  - Exemplo: `https://www.herhairsolutions.com` → `herhairsolutions`

---

### **6. Use loops e condições para controle de fluxo**
- Usa **loops condicionais** para:
  - Ignorar concorrentes sem anúncios
  - Esperar até que o vídeo com avatar esteja pronto
  - Repetir etapas até sucesso (ex: polling do status do vídeo)

---

### **7. Configure o Heygen com header fixo**
- Crie uma **credencial de API Header fixa** no n8n/Make para não repetir manualmente o token da API do Heygen em cada requisição.

---

### **8. Ajuste a velocidade da voz (Voice Speed)**
- O valor padrão (1.0) da voz gerada no Heygen é **muito lento**.
- Ele recomenda **1.4 ou 1.5** para uma fala mais natural e dinâmica.

---

### **9. Use Claude Sonnet para gerar textos mais naturais**
- Claude gera roteiros mais "humanos" e envolventes que o ChatGPT, segundo o autor.
- Ideal para **cópias comerciais e vídeos persuasivos**.

---

### **10. Estrutura ideal do roteiro: 40 segundos**
- 5-8s de gancho  
- 20-25s de desenvolvimento  
- 5-8s de fechamento  
- Máximo de 1000 caracteres

---

### **11. Padronize a saída em JSON**
- Ele ensina a configurar o prompt para gerar **JSON autocorrigido** com campos fixos:
  - título, gancho, corpo, CTA, público, ângulo
- Isso facilita leitura, automação e análise posterior.

---

### **12. Atualize o status das fases na planilha**
- Usa os campos “IDEIA”, “CRIAR”, “COMPLETADO” e “SEM ANÚNCIOS” para acompanhar visualmente cada fase da automação.

---

Aqui está o **passo a passo completo da automação de Scrapeador de Anúncios da Meta com geração de vídeos com avatar**, usando ferramentas como **n8n / Make, OpenAI, RapidAPI, Apify, Heygen e Google Sheets**:

---

### **ETAPA 1: INPUT – Inserir URLs dos concorrentes**
1. Criar uma planilha no Google Sheets chamada `Concorrentes`.
2. Adicionar as colunas:
   - Nome da marca
   - URL do site
   - Status
   - Facebook URL
   - Ad Library ID
   - Sheet ID dos anúncios

---

### **ETAPA 2: SCRAPEAR INFORMAÇÕES BÁSICAS DO SITE**
**Objetivo:** Obter Facebook URL e outros dados.

1. Usar a API **Website Social Scraper (RapidAPI)**:
   - Entrada: URL do site do concorrente.
   - Saída: Facebook URL, e-mails, telefone, redes sociais.
2. Gravar os dados no Google Sheets nas colunas correspondentes.
3. Filtrar apenas os que possuem Facebook URL.

---

### **ETAPA 3: OBTER O AD LIBRARY ID (ID dos anúncios)**
1. Usar a API **Facebook URL to ID (Apify)**:
   - Entrada: Facebook URL.
   - Saída: Ad Library ID (Page Library ID).
2. Atualizar a coluna "Ad Library ID" no Google Sheets.

---

### **ETAPA 4: RASTREAR ANÚNCIOS ATIVOS**
1. Usar a API **Ad Library (RapidAPI)** com o Page ID:
   - Buscar anúncios ativos: vídeos, imagens, CTA, corpo, data.
2. Criar uma aba nova para cada concorrente no Google Sheets.
3. Salvar todos os anúncios com os seguintes campos:
   - Vídeo/Imagem
   - Texto do anúncio
   - CTA
   - Link
   - Data
   - Campo vazio para “Test” (marcar manualmente os melhores)

---

### **ETAPA 5: ANÁLISE DOS MELHORES ANÚNCIOS**
**(ativada apenas se o campo “Test” = “Sim”)**

1. Transcrever o áudio do vídeo (com **OpenAI Whisper** ou **OpenAI API**).
2. Usar **LLM (Claude ou GPT)** para gerar auditoria criativa:
   - Gancho
   - Público-alvo
   - Ângulo de venda
   - Pontos fortes e fracos

---

### **ETAPA 6: CRIAR ROTEIRO PERSONALIZADO COM IA**
1. Enviar para o LLM:
   - Transcrição do anúncio
   - Resultado da análise
   - Dados da marca (nome, tom de voz, público, diferenciais)
2. Gerar JSON com:
   - Título
   - Gancho
   - Corpo
   - CTA
   - Público
   - Ângulo

3. Salvar tudo em uma aba `Roteiros Ads` no Google Sheets com status “IDEIA”.

---

### **ETAPA 7: CRIAR VÍDEO COM AVATAR (Heygen)**
**(somente para roteiros com status “CRIAR” e sem link de vídeo)**

1. Usar a **API do Heygen**:
   - Selecionar avatar (customizado ou catálogo).
   - Escolher voz (Heygen ou clonada).
   - Enviar o texto do roteiro.
   - Configurar vídeo 720x1280.

2. Obter `Video URL`.
3. Fazer upload no **Google Drive**.
4. Atualizar o link do vídeo no campo “Vídeo Avatar” no Google Sheets.

---

### **ETAPA 8: PRONTOS PARA EDITAR E USAR**
1. Agora você tem:
   - Concorrente analisado.
   - Anúncio adaptado à sua marca.
   - Vídeo realista com avatar.
2. Enviar para edição (opcional) ou já usar em campanhas.

---

### **Ferramentas Necessárias**
| Etapa | Ferramenta           |
|-------|----------------------|
| 1-2   | Google Sheets        |
| 2     | RapidAPI             |
| 3     | Apify                |
| 4     | RapidAPI             |
| 5     | OpenAI (Whisper API) |
| 6     | Claude ou GPT        |
| 7     | Heygen (API)         |
| 8     | Google Drive         |

**Resumo do vídeo “Meta Ads Scraper com Avatar (Automação Completa)” – YouTube**

**Objetivo do projeto:**  
Criar uma automação completa, sem código, que:

1. **Raspa anúncios ativos** de concorrentes na Meta (Facebook/Instagram).
2. **Armazena os dados** em Google Sheets.
3. **Gera um roteiro publicitário com IA** com base nos anúncios capturados.
4. **Cria vídeos com avatar realista**, narrando o roteiro, usando a API do Heygen.
5. **Faz tudo em massa e no piloto automático.**

---

**Etapas da Automação:**

1. **Scraping de concorrentes:**
   - Insere a URL do site concorrente.
   - Extrai automaticamente Facebook URL e Ad Library ID via RapidAPI + Apify.
   - Salva tudo em Google Sheets.

2. **Coleta de anúncios ativos:**
   - Usando o Ad Library ID, extrai todos os anúncios (imagem, vídeo, CTA, texto, data).
   - Cria uma aba por concorrente com os anúncios.

3. **Análise dos anúncios:**
   - O usuário marca os melhores com "test".
   - O sistema transcreve o áudio do anúncio com OpenAI.
   - Analisa o conteúdo: gancho, público, ângulo, persuasão, etc.

4. **Geração de roteiro com IA:**
   - IA cria um roteiro de até 40 segundos baseado no anúncio analisado e dados da marca.
   - Output formatado em JSON (gancho, corpo, CTA, etc).

5. **Criação do vídeo com avatar (Heygen):**
   - Usa o avatar (customizável) e uma voz (pré-definida ou clonada).
   - Gera vídeo vertical (720x1280).
   - Faz upload automático no Google Drive.
   - Salva link do vídeo no Google Sheets.

---

**Extras e Dicas:**

- Pode ser feito com **Make.com** ou **n8n**.
- O modelo usado para criar os roteiros foi **Claude Sonnet** (OpenRouter) por produzir textos mais naturais.
- A automação é modular e escalável: dá para processar múltiplos concorrentes de forma contínua.
- A integração com Heygen usa a API paga, mas tem créditos gratuitos para testes.

---

**Resultado final:**  
Um sistema que **raspa, analisa, roteiriza, gera e publica** vídeos com base em anúncios concorrentes — tudo de forma automática e adaptada à sua marca.

**16. Scrapeador de Anúncios da Meta**

**🎯 Objetivo**  
Criar uma automação completa que permite:

- Rastrear (scrapear) anúncios ativos da concorrência na Meta Ads.  
- Armazenar essas informações no Google Sheets com todos os dados relevantes.  
- Gerar roteiros adaptados à sua marca usando IA.  
- Transformar esses roteiros em vídeos com avatares via Heygen.

---

**🔁 Fases do processo**

**1. Raspagem de dados dos concorrentes**  
- Você insere a URL do site da concorrência.  
- A automação obtém automaticamente:
  - Página do Facebook.
  - ID da Biblioteca de Anúncios (Ad Library ID).
  - Informações adicionais: e-mails, telefone, redes sociais etc.  
- Ferramentas usadas: APIs do RapidAPI e Apify.

**2. Coleta e armazenamento dos anúncios**  
- Se a empresa tiver anúncios ativos, são criadas novas abas no Google Sheets.  
- São armazenados:
  - Vídeos ou imagens.
  - Texto do anúncio (copy).
  - Chamada para ação (CTA).
  - Data de criação e outros dados técnicos.

**3. Seleção e análise dos anúncios**  
- Você marca manualmente os anúncios com a tag "test".  
- O áudio do vídeo selecionado é transcrito (com OpenAI).  
- A IA gera uma análise criativa com:
  - Gancho.
  - Ângulo de venda.
  - Perfil do público-alvo.
  - Elementos persuasivos.

**4. Geração do roteiro adaptado**  
- A IA cria um roteiro publicitário com base em:
  - A transcrição.
  - A análise anterior.
  - Dados da sua marca (nome, tom, público).
- Estrutura do roteiro: 40 segundos com gancho, desenvolvimento e fechamento.  
- O resultado é gerado em formato JSON com todos os componentes do roteiro.

**5. Criação do vídeo com avatar**  
- No Heygen você:
  - Escolhe o avatar.
  - Define a voz (de catálogo ou clonada).
  - Define a dimensão do vídeo (720x1280).  
- O vídeo é gerado e baixado.  
- É enviado automaticamente ao Google Drive e o link é salvo no Google Sheets.

---

**Recursos**  
- Blueprint Meta Ads  
- Website Social Scraper  
- API - Ad Libraries  
- API - Facebook URL to ID
