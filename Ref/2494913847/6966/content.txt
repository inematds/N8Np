**Como Eu Construí um Agente de IA para Pesquisar Ideias de Vídeos no YouTube (Sem Código) - YouTube**

Como criar um agente para pesquisar ideias de vídeos no YouTube.  
Primeiro, foi feita uma demonstração rápida usando um fluxo no **n8n**.  

O sistema busca vídeos de diferentes canais diariamente e salva as estatísticas no **Supabase**.  

As estatísticas incluem: ID do vídeo, número de visualizações, curtidas, favoritos e comentários, registradas diariamente.

### Configuração Inicial:
- **Contas necessárias**:  
  - Uma conta no **Supabase**  
  - Acesso à **Google Cloud API** para usar a **YouTube Data API v3**

### Existem três fluxos principais:

1. **Adicionar novos canais ao banco de dados**:
   - Coletar URLs completos dos canais do YouTube.
   - Extrair os identificadores (handles) dos canais.
   - Verificar se o canal já existe no banco de dados.
   - Buscar dados do canal pela API do YouTube.
   - Armazenar os canais no banco de dados Supabase.

2. **Buscar vídeos dos canais**:
   - Um gatilho diário ativa a busca dos vídeos.
   - Pega todos os canais salvos no Supabase.
   - Busca os vídeos mais recentes usando a API do YouTube.
   - Processa e salva os dados dos vídeos (ID, título, etc.) no Supabase.

3. **Obter estatísticas dos vídeos**:
   - Um gatilho diário busca as estatísticas dos vídeos.
   - Agrupa IDs de vídeos para otimizar requisições.
   - Busca visualizações, curtidas, favoritos e comentários pela API do YouTube.
   - Atualiza o banco de dados Supabase com as estatísticas.

### Configurações de Credenciais:
- **Supabase**:
  - Criar duas credenciais: uma padrão e outra para ações específicas no banco.
  - Usar URL do projeto e chave secreta de serviço.

- **Google Cloud (YouTube API)**:
  - Habilitar a YouTube Data API v3 no Console do Google Cloud.
  - Criar uma chave de API e usar essa chave como credencial.

### Estrutura dos Bancos de Dados no Supabase:
- **Tabela de Canais (YouTube_statistics_channels)**:
  - Campos: ID, handle do canal, ID do canal, data de criação.
  
- **Tabela de Estatísticas de Vídeos (YouTube_statistics_video_stat)**:
  - Campos: ID, ID do vídeo, visualizações, curtidas, favoritos, comentários, data de registro.

- **Tabela de Vídeos (YouTube_statistics_videos)**:
  - 16 campos relacionados a dados de vídeos.

### Principais Etapas dos Workflows:

- **Adicionar novos canais**:
  - Submissão de formulário com URLs dos canais.
  - Extração do identificador do canal.
  - Verificação de canais duplicados.
  - Busca de dados dos canais pela API.
  - Armazenamento dos canais no Supabase.

- **Buscar vídeos**:
  - Gatilho diário para execução.
  - Buscar canais no banco.
  - Buscar vídeos pelo canal usando a API.
  - Processar respostas e inserir no banco de dados.

- **Obter estatísticas dos vídeos**:
  - Gatilho diário para execução.
  - Selecionar IDs de vídeos no banco.
  - Buscar estatísticas na API do YouTube.
  - Atualizar banco de dados com estatísticas atualizadas.

---

**Resumo final**:

Este tutorial ensina como construir um **agente de IA sem código** para **pesquisar ideias de vídeos para o YouTube automaticamente**, salvando vídeos e estatísticas no Supabase usando **n8n** e **API do YouTube**, com atualizações diárias.
