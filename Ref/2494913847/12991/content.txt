Aqui estão **hacks práticos** que você pode aplicar com a nova **API da Gamma integrada ao n8n**, com foco em automações úteis, lead magnets e geração de apresentações com IA:

---

### 🔧 **HACKS PRÁTICOS COM A API DA GAMMA + n8n**

#### 1. **Lead Magnet Automático (Auditoria IA)**

* **Como funciona:**
  Crie um formulário simples no seu site (Typeform, Tally ou Webflow) que pergunta algo como: “Quer uma auditoria do seu site com IA?”
* **Hack:**
  Use n8n para:

  * Receber a resposta do formulário
  * Enviar a descrição para um agente IA (Claude, OpenAI, etc.)
  * Estruturar o prompt e gerar JSON
  * Enviar para a API da Gamma
  * Aguardar o PDF com a apresentação
  * Enviar por e-mail para o lead

#### 2. **Criação em massa de apresentações**

* **Como funciona:**
  Tenha uma planilha com temas (ex: “IA para gastronomia”, “IA para educação”, etc.)
* **Hack:**
  Configure o n8n para:

  * Ler linha por linha da planilha
  * Enviar para o agente IA para estruturar o conteúdo
  * Gerar várias apresentações com visual profissional
  * Armazenar PDFs no Google Drive automaticamente

#### 3. **Chatbot que entrega apresentações**

* **Como funciona:**
  Um chatbot (Telegram, WhatsApp via Twilio, ou webchat) onde o usuário escreve um tema e recebe a apresentação.
* **Hack:**

  * Integre com o n8n
  * Encaminhe o texto do usuário para a API da Gamma
  * Gere e envie o link da apresentação final

#### 4. **Gatilho por e-mail**

* **Como funciona:**
  Quando alguém mandar um e-mail com o assunto “crie apresentação sobre X”, o sistema gera e devolve.
* **Hack:**

  * Use Gmail Watcher no n8n
  * Pegue o assunto do e-mail e envie ao agente
  * Gere apresentação e responda ao e-mail com o link para download

#### 5. **Venda de apresentações automáticas (produtos digitais)**

* **Como funciona:**
  Compre e receba um link exclusivo com uma apresentação personalizada.
* **Hack:**

  * Integre Hotmart, Gumroad ou Stripe ao n8n
  * Após pagamento, peça o tema
  * Gere automaticamente e envie link ou arquivo final

---

### 💡 DICAS AVANÇADAS

* **Acelere a criação:** Use o `wait/polling` de forma otimizada (comece com 100s, repita se necessário).
* **Evite erros de parsing:** Limpe os caracteres especiais antes de enviar para a Gamma.
* **Modelos de IA recomendados:** Claude 3 Haiku ou GPT-4 Turbo para transformar o texto em JSON limpo.
* **Validação:** Adicione uma etapa de validação para checar se o JSON retornado está dentro do schema exigido pela Gamma.

**Gamma (empresa de apresentações com IA)** finalmente lançou sua **API oficial**, algo inédito até então, e considera isso um grande avanço que está sendo ignorado por outros criadores.

### Pontos principais:

* **API disponível somente no plano Pro da Gamma.**

  * É possível obter a chave da API nas configurações da conta.

* **Fluxo de trabalho criado no n8n:**

  1. O usuário envia um pedido vago como: “Faça uma apresentação sobre IA na caligrafia.”
  2. Um agente de IA transforma essa solicitação em um **JSON estruturado**.
  3. O JSON é enviado para a API da Gamma.
  4. O sistema espera cerca de **3 a 4 minutos** (configurado para 180 segundos).
  5. Após resposta via webhook com status de "completado", o link da apresentação é retornado.

* **Prompt do agente de IA:**

  * Age como assistente da Gamma.
  * Converte o texto do usuário em um JSON válido.
  * Sem explicações, markdown ou caracteres especiais.
  * Modelo usado: O3 Mini.

* **Resultado:**

  * Apresentações visuais completas são geradas mesmo com prompts ruins.
  * Dá para criar **lead magnets** com auditorias de IA automáticas.
  * Exportação disponível em **PDF ou PowerPoint**.

* **Manipulação possível via API:**

  * Temas
  * Separação de cartões (slides)
  * Instruções extras
  * Formato de exportação
  * Inserção de imagens

* **Conclusão:**

  * A API está no começo, mas já é extremamente poderosa.
  * O criador irá disponibilizar o **JSON do workflow**.
  * Planeja um vídeo mais detalhado com a empresa Base44.
