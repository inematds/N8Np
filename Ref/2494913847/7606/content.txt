Segue o **resumo completo** do vídeo com **os 25 truques do n8n** que você vai querer conhecer o quanto antes. Ao final, há uma lista com **cada truque**, **explicações práticas** e **exemplos de uso**:

### Resumo Geral

Este vídeo apresenta 25 truques e recursos escondidos do n8n, que ajudam tanto iniciantes quanto usuários avançados a:

* Ganhar produtividade
* Evitar erros comuns
* Testar fluxos com segurança
* Criar automações mais limpas, confiáveis e eficientes

As dicas cobrem desde atalhos de teclado, uso de dados fictícios e pinagem de resultados, até manipulação de arrays e controle de erros. Cada hack oferece ganhos práticos para acelerar o desenvolvimento de automações.

---

### Lista dos 25 Hacks com Exemplos

1. **Atalho para expressão (`=`)**

   * Ao digitar `=` no campo, o valor vira expressão direto.
   * Exemplo: transforme `High` em `={{ $json["value"] }}`.

2. **Pinar dados**

   * Salva o resultado de uma execução para evitar reprocessar.
   * Ideal para APIs pagas como Perplexity.

3. **Mock Data (dados fictícios)**

   * Simula dados em qualquer nó para testes rápidos.
   * Exemplo: `query: "test"`

4. **Navegação entre nós**

   * Use setas do teclado para navegar e `Enter` para abrir.
   * Economiza cliques.

5. **Desativar nós rapidamente**

   * Use `D` para ativar/desativar sem abrir menus.

6. **Sticky Notes com Markdown**

   * Crie notas explicativas (atalho: `Shift + S`).
   * Exemplo: Categorizar nós por cores: azul (IA), verde (dados), amarelo (comentários).

7. **Histórico de versões**

   * Veja versões anteriores do fluxo e restaure com um clique.

8. **Inserir nós com Tab**

   * Atalho `Tab` abre a caixa de busca de novos nós.

9. **Remover “enviado por n8n”**

   * Desative a atribuição nos nós de e-mail, Telegram e Slack.

10. **Data/hora atual com `{{$now}}`**

    * Útil para timestamp, logs ou IA context-aware.

11. **Salvar credenciais de API**

    * Reutilize autenticações e proteja sua chave.
    * Exemplo: API Key de Perplexity com tipo Header.

12. **Workflow de erros**

    * Configure um “Error Trigger” para receber alertas quando um fluxo falhar.

13. **Variáveis do workflow**

    * Acesse ID da execução, nome do fluxo, etc., via `{{$workflow}}`.

14. **Subworkflow com dados específicos**

    * Defina campos como `nome`, `email` ao chamar sub-fluxos.

15. **Visualizar subexecução**

    * Veja o que foi feito por um subworkflow em tempo real.

16. **Logs do agente (agent logs)**

    * Veja como o agente interpretou e respondeu ao prompt.

17. **Copiar dados do subworkflow para edição**

    * Reaproveite dados de execução real para testes.

18. **“Human in the loop”**

    * Pausa o fluxo e espera input humano por Slack, Discord ou email.

19. **Padronizar entradas**

    * Unifica nomes de campos como `chat_input` e `json.ext`.

20. **Continuar mesmo com erro**

    * Use a opção `Continue on Error` para não travar todo o fluxo.

21. **Erro com saída separada**

    * Use `Error Output` para tratar erros em um caminho alternativo.

22. **Configurações avançadas de nós**

    * Exemplo: Retry, duplicação de itens, executar uma vez só, sempre gerar saída.

23. **Saída estruturada de agentes**

    * Gere respostas formatadas com JSON e divida por objetos.

24. **`join()` em arrays**

    * Exemplo: `["apple", "banana", "steak"].join(", ")` → "apple, banana, steak"

25. **Substituir texto com `.replace()`**

    * Útil para limpar expressões com aspas duplicadas.

---

### Conclusão

Esses truques permitem criar automações mais:

* Rápidas
* Inteligentes
* Seguras
* Reutilizáveis

Você pode baixar o template completo no link da comunidade do autor ou aplicar imediatamente os hacks em seus próprios fluxos.
