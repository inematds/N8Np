Abaixo está o **passo a passo explicado **, com a lógica, a fala prática e a sequência real da automação funcionando dentro do N8N, usando Telegram, Gemini e PDF.co — exatamente como o criador mostrou.

---

### 1. Criar o bot do Telegram

* Abre o **Telegram** e procura o **@BotFather**.
* Digita o comando `/newbot`.
* Escolhe o nome do bot (exemplo: `faturador_inema_bot`).
* Depois cria o **username** (exemplo: `faturador_inema_bot`).
* O BotFather vai te devolver o **token de API**, que é o que vamos colar no N8N.

---

### 2. Conectar o bot no N8N

* No N8N, cria um **novo workflow**.
* Adiciona o nó **Telegram Trigger**.
* Coloca o token que o BotFather deu.
* Esse nó é o que vai **escutar as mensagens** que chegam no Telegram (tanto texto quanto áudio).
* Salva e ativa o gatilho para testar.

---

### 3. Receber mensagens e normalizar o input

* Adiciona um **nó Switch** para detectar o tipo da mensagem.
* Se for **texto**, o fluxo segue direto.
* Se for **áudio**, usa o nó de **Transcrição** (pode ser o Whisper ou outro) para transformar o áudio em texto.
* Depois, tudo é unificado em uma variável única chamada **text**, assim tudo funciona igual.
  Exemplo:

  `  text = "Gerar fatura para João da Silva, valor 500€, sem IVA"
  `

---

### 4. Interpretar o texto com nó de código (sem usar API externa)

* Adiciona um **nó de código** (Node Function).
* Dentro dele, pede ao Gemini (via prompt local) para **estruturar os dados** da mensagem.
* O criador chama isso de “dar um papel à IA”:
  Ele diz — *“Gemini, imagina que você é um forno. Eu te dou uma pizza fria (os dados crus) e quero que você me devolva uma pizza quente (os dados formatados)”*.
* Isso faz o modelo devolver os dados limpos e organizados, prontos para gerar o HTML.
* A saída desse nó deve conter algo como:

  ```  {
    "cliente": "João da Silva",
    "valor": "500",
    "iva": "0",
    "descricao": "Serviço de suporte técnico",
    "data": "2025-10-08"
  }
  ```

---

### 5. Gerar o HTML da fatura

* Adiciona outro **nó de código**.
* Pede ao Gemini para gerar o **HTML completo da fatura** com base nos dados anteriores.
* Ele cria dois modelos: um **com IVA** e outro **sem IVA**.
* É aqui que entra o design: você pode personalizar com seu logotipo, cores e layout.
* Atenção: todas as imagens devem ser **URLs públicas**, nada de arquivos locais.

---

### 6. Converter HTML em PDF

* Adiciona o **nó ****PDF.co**.
* Seleciona a ação **HTML to PDF**.
* Cola o HTML vindo do Gemini e gera o arquivo PDF profissional.
* Dá um nome dinâmico, por exemplo:

  `  Fatura_{{cliente}}_{{data}}.pdf
  `

---

### 7. Enviar o PDF por e-mail

* Adiciona o **nó Email Send**.
* No corpo do e-mail, coloca um **HTML bonito**, gerado pelo Gemini também.
* Anexa o PDF gerado.
* Exemplo de corpo do e-mail:

  `  Olá {{cliente}},
  Segue em anexo a sua fatura de {{data}} no valor de {{valor}}€.
  Obrigado pela preferência.
  `
* Observação:
  Desative nas opções do N8N a mensagem “enviado via N8N”, que aparece no rodapé.

---

### 8. Salvar no Google Drive

* Adiciona o **nó Google Drive**.
* Define a pasta destino, por exemplo:
  `/Faturas/2025/Outubro/`
* O arquivo é salvo automaticamente com o nome da fatura.
* Assim tudo fica organizado por **ano e mês**.

---

### 9. Registrar no banco de dados

* Adiciona um **nó Supabase ou Google Sheets**.
* Cria uma tabela com as colunas: cliente, data, valor, IVA, link da fatura.
* Cada nova fatura é adicionada automaticamente.

---

### 10. Criar relatório financeiro mensal

* Adiciona um **nó Cron** para rodar no **dia 1º de cada mês**.
* Ele executa uma **consulta SQL** (PostgreSQL ou Supabase) filtrando os dados do mês anterior.
* Passa os resultados para o Gemini, que gera um **HTML analítico** com gráficos e totais.
* O HTML pode ser convertido para PDF e enviado por e-mail ou salvo no Drive.
* Exemplo:
  “Relatório financeiro de setembro: total faturado 14.300€, IVA 1.500€, despesas 2.000€, lucro líquido 12.300€”

Resumo completo e estruturado 

Tema central
Criação de uma automação completa para geração de faturas e relatórios financeiros usando Telegram, N8N e Gemini, sem depender de APIs externas nem consumir tokens de IA. O foco é ajudar empresas a automatizar faturamento, reduzir custos e gerar relatórios mensais de forma profissional.

1. Objetivo da automação
   • Permitir que qualquer pessoa envie uma mensagem (texto ou áudio) pelo Telegram solicitando uma fatura.
   • O sistema gera automaticamente uma fatura profissional (com ou sem IVA), converte para PDF e a envia por e-mail.
   • A fatura também é armazenada automaticamente no Google Drive, organizada por mês e ano.
   • Os dados podem ser salvos em Supabase ou Google Sheets para histórico e relatórios financeiros mensais.

2. Estrutura técnica do fluxo
   • Entrada no Telegram: o usuário envia um comando de voz ou texto.
   • Normalização: o fluxo identifica o tipo de mensagem e converte tudo em texto padronizado.
   • Interpretação: em vez de usar uma API de IA, um nó de código transforma o texto em dados estruturados.
   • Geração de HTML: Gemini cria o layout visual da fatura (com design e estrutura definidos).
   • Conversão para PDF: feita com PDF.co, sem marcas d’água.
   • Envio por e-mail: o sistema envia automaticamente o PDF com corpo HTML profissional.
   • Armazenamento: o arquivo é salvo no Google Drive e os dados vão para Supabase/Sheets.
   • Relatórios financeiros: mensalmente, um trigger coleta as faturas do mês anterior, faz uma consulta SQL, agrega os dados e gera um relatório HTML analítico.

3. Principais ferramentas usadas
   • N8N como orquestrador do fluxo.
   • Bot do Telegram para entrada do usuário.
   • Gemini para gerar HTML e estrutura de fatura.
   • PDF.co para converter HTML em PDF.
   • Google Drive para armazenamento.
   • Supabase ou Google Sheets para banco de dados.

4. Estratégias e boas práticas
   • Dar “funções metafóricas” à IA (como “você é um forno”) melhora os resultados.
   • Manter nomes de variáveis consistentes (“text”) evita erros entre caminhos diferentes.
   • Usar apenas imagens com URLs públicas no HTML.
   • Desativar a mensagem “enviado via N8N” no Telegram.
   • Pedir com clareza à IA o que se espera de cada parte do processo, definindo o papel e o formato do output.

5. Parte avançada: geração de relatório financeiro
   • O sistema roda no início de cada mês, pega os movimentos do mês anterior e gera um relatório completo.
   • Usa SQL para buscar e filtrar dados automaticamente.
   • Gemini gera o HTML do relatório, que pode ser exibido diretamente ou convertido em PDF.
   • O relatório inclui análise automática dos cinco principais indicadores e resumo visual das receitas e despesas.

6. Conclusão e aprendizado
   • A automação mostra que é possível criar fluxos potentes sem depender de APIs caras.
   • Tudo funciona com prompts bem estruturados e nós de código dentro do N8N.
   • O segredo é aprender a pedir corretamente à IA o resultado desejado.
   • A execução total de uma fatura leva cerca de 10 a 15 segundos, oferecendo grande economia de tempo para empresas.

Exemplo de uso prático
Um cliente envia no Telegram:
“Gere uma fatura para João da Silva no valor de 500€, sem IVA.”
Em segundos, o sistema gera o PDF, envia por e-mail, salva no Google Drive e registra no banco de dados.

Resultado
Uma automação empresarial completa, eficiente e sem custo recorrente de APIs, capaz de gerar faturas e relatórios financeiros em segundos, 100% integrada com Telegram, N8N, Gemini e Google Drive.

e51 - Faturas e relatório financeiro em 1 clique

Você vai aprender a montar uma automação completa que permite gerar e enviar faturas profissionais a partir de mensagens no Telegram (texto ou áudio), sem depender de agentes de IA externos nem consumir APIs. Essa solução é extremamente útil para qualquer empresa que trabalhe com faturamento recorrente, permitindo economizar tempo, reduzir erros e oferecer uma experiência mais profissional aos clientes.

🛠️ O que conseguimos com essa automação
• Gerar faturas automaticamente a partir do Telegram, por voz ou texto.
• Criar PDFs profissionais em segundos sem consumir APIs.
• Enviar a fatura por e-mail com design HTML personalizado.
• Salvar automaticamente as faturas no Google Drive, organizadas por mês e ano.
• Adaptar facilmente o fluxo para faturas com ou sem IVA.
• Reduzir custos a longo prazo ao não usar agentes de IA externos.
• Aplicar o mesmo conceito a relatórios financeiros pessoais ou empresariais.

🧩 Estrutura do fluxo automatizado
**Entrada via Telegram**
O usuário envia uma mensagem (voz ou texto) ao bot solicitando a geração de uma fatura com os dados relevantes.

**Recepção e normalização da entrada**
Detecta-se se a mensagem é de voz ou texto. Ambos os tipos são normalizados para serem processados da mesma forma.

**Interpretação da mensagem (sem API)**
Em vez de usar um agente de IA, utiliza-se um nó de código que transforma a entrada em uma estrutura de dados limpa.

**Geração de HTML personalizado**
Com ajuda do Gemini, é criado um HTML profissional para a fatura, adaptado com design visual.

**Conversão para PDF**
O HTML é convertido em PDF usando o PDF.co, sem marcas d’água nem limitações rígidas.

**Envio da fatura**
O sistema envia automaticamente o e-mail ao cliente, com corpo em HTML visual e o PDF anexado.

**Armazenamento no Drive**
O arquivo PDF é enviado para a pasta correspondente (exemplo: /Faturas/2025/Outubro).

**Geração de relatórios financeiros (opcional)**
Mensalmente, são extraídos os movimentos do mês anterior e criado um relatório visual e analítico.

🧰 Ferramentas utilizadas
• N8N
• Bot do Telegram
• Gemini (para prompts estruturados)
• PDF.co
• Google Drive
• Supabase / Google Sheets (opcional para base de dados)

🧠 Dicas importantes que aprendemos
• Nem sempre é necessário consumir APIs: com um bom prompt, o Gemini pode gerar diretamente o HTML ou a estrutura desejada.
• Atribuir papéis metafóricos à IA (exemplo: “você é um forno”) melhora a resposta do modelo.
• Normalizar variáveis e nomes nos nós (como “text”) evita erros entre ramificações.
• O design HTML da fatura ou do e-mail deve conter apenas imagens públicas (URLs), nunca arquivos locais.
• Desative a atribuição do N8N para que o Telegram não exiba a mensagem “enviado via N8N”.

Recursos
• Geração de faturas
• Geração de relatórios
