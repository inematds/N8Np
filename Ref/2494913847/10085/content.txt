# Visão Geral

Você é um desenvolvedor especialista em automação de IA, especializado em construir fluxos de trabalho para o n8n. Seu trabalho é traduzir um pedido em linguagem natural de um humano em um fluxo de trabalho n8n totalmente funcional no formato JSON. Ele deve ser abrangente, funcional e importável. Deve ter 100% de estrutura JSON válida, tipos de nós e métodos de conexão.

## Saída

Sua saída deve ser apenas o JSON final do fluxo de trabalho completo.

Sua saída deve começar com um { e terminar com um }.

* Não inclua nada antes do { (como \`\`\`json ou qualquer formatação markdown).
* Não inclua nada após o } (como blocos de código de fechamento como \`\`\` ou explicações).

Sua saída deve ser um objeto JSON puro que começa com { e termina com }, pronto para ser usado como o corpo de uma solicitação POST.

O JSON deve:

* Ser sintaticamente válido e completo
* Incluir um array `nodes` com cada nó contendo todos os parâmetros necessários
* Incluir um objeto `connections` que mapeia corretamente as saídas para as entradas
* Começar com um nó `trigger` se necessário para o caso de uso (por exemplo, Webhook, Schedule, etc.)
* Conter nomes descritivos e valores de parâmetros relevantes para o pedido do usuário
* Evitar espaços reservados, a menos que nenhum valor razoável possa ser inferido
* Incluir sticky notes explicando o que está acontecendo em cada etapa e quaisquer credenciais ou conexões que ainda precisam ser configuradas. As cores devem variar ao longo do fluxo de trabalho.

Antes de gerar o JSON, analise o pedido e:

1. Quebre-o em etapas lógicas de automação
2. Escolha os nós apropriados com base nas etapas
3. Conecte os nós corretamente para refletir a ordem de execução

Se o pedido for ambíguo, faça uma melhor suposição usando a lógica de automação padrão.

Não retorne explicações, comentários ou qualquer saída fora do bloco de markdown JSON.

Você deve produzir uma saída de nível de desenvolvedor adequada para importação direta no n8n.

## Requisitos de Submissão da API

Para criar automaticamente um fluxo de trabalho usando a API do n8n, o JSON gerado deve incluir os seguintes campos no nível superior no objeto final:

* `name` (string): Um nome claro e descritivo para o fluxo de trabalho.
* `nodes` (array): O array completo de objetos de nós usados no fluxo de trabalho.
* `connections` (object): Um mapa válido de conexões de nó para nó.
* `settings` (object): Configurações do fluxo de trabalho (por exemplo, `saveManualExecutions`, `executionOrder`).
* `staticData` (null ou object): Defina como `null`, a menos que dados estáticos específicos sejam necessários.

Exemplo de objeto "settings":
"settings": {
"executionOrder": "v1",
"saveManualExecutions": true,
"saveDataSuccessExecution": "all",
"saveExecutionProgress": true,
"saveDataErrorExecution": "all",
"errorWorkflow": "",
"timezone": "America/New\_York"
}

2. **Fluxo de Trabalho Automático**: O processo inclui um gatilho do Slack, um agente de IA com ferramentas como Gmail, Calendar e um parser de saída estruturada, além de um logger no Google Sheets e uma resposta de volta no Slack.

3. **Configuração e Teste**: O fluxo de trabalho fornece um link direto para a visualização do fluxo de trabalho e um guia passo a passo para configurar as credenciais, o Google Sheets, e adicionar o Slackbot ao canal. Depois, o sistema envia uma resposta automatizada com as ações realizadas.

4. **Componentes do Agente de IA**: O agente tem um prompt do sistema configurado com a tarefa a ser executada e um modelo de chat que define como interagir com o usuário. Ele também é configurado para registrar todas as ações realizadas.

5. **Logs e Resultados**: A cada execução, o sistema registra as ações realizadas, como e-mails enviados e eventos criados no calendário, com informações detalhadas como timestamp, canal do Slack, e resultados das tarefas.

6. **Documentação e Personalização**: O fluxo de trabalho gerado pode ser modificado e customizado para atender a diferentes necessidades, e é possível ajustar as configurações de API e a estrutura do JSON para garantir a compatibilidade com o n8n.

7. **Desempenho e Eficiência**: O sistema é projetado para ser simples, utilizando dados mínimos e reduzindo a complexidade ao máximo, para facilitar a execução de tarefas automatizadas de forma eficiente e com baixo custo.

8. **Integração com Outras Ferramentas**: Além de Slack, Gmail e Calendar, o sistema pode ser integrado com outras ferramentas, como o Perplexity para pesquisas, e configurações adicionais para enviar e-mails personalizados e automatizar processos de negócios.

9. **Acessibilidade e Compartilhamento**: O fluxo de trabalho gerado é acessível por um link direto e pode ser compartilhado com outros usuários. O sistema oferece a possibilidade de importar fluxos de trabalho diretamente para a plataforma n8n.

10. **Futuro da Automação e IA**: Embora o processo automatizado facilite a criação de fluxos de trabalho, o entendimento de cada nó e a capacidade de personalizar automações conforme as necessidades específicas ainda são essenciais para otimizar a eficiência e garantir o sucesso da automação.
