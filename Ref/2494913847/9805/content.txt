Aqui está o **passo a passo completo das 3 automações** criadas com n8n, explicadas de forma prática:

---

### **1. Automação de Fotos de Produtos com IA**

Objetivo: transformar imagens comuns de produtos em versões estilizadas automaticamente usando IA (OpenAI) e armazenar no Supabase.

#### Passo a Passo:

1. **Disparo por agendamento**

   * Use o nó `Cron` ou `Schedule Trigger` para rodar automaticamente (ex: 1x por dia).

2. **Leitura do Google Sheets**

   * Nó `Google Sheets (Read)` com colunas: link da imagem e prompt descritivo.
   * Filtro: somente linhas com status em branco.

3. **Download da imagem original**

   * Nó `HTTP Request` com método GET para baixar a imagem do link.

4. **Envio para a API do OpenAI (DALL·E)**

   * Nó `HTTP Request (POST)` com:

     * API Key do OpenAI
     * Prompt e imagem original
     * Modelo: `dall-e` ou `gpt-image-1`

5. **Separação das imagens geradas**

   * Use o nó `Split Out` para dividir a resposta com múltiplas imagens.

6. **Conversão Base64 para Arquivo**

   * Nó `Move Base64 to File` para converter imagens em arquivos utilizáveis.

7. **Upload para Supabase**

   * Nó `HTTP Request (POST)`:

     * Configure URL, token e nome do bucket
     * Envie o arquivo para o armazenamento público

8. **Atualização no Google Sheets**

   * Insira o link da imagem gerada e marque como "feito".

---

### **2. Automação de Geração de Leads com IA**

Objetivo: buscar empresas que estão contratando e gerar e-mails personalizados para contato.

#### Passo a Passo:

1. **Criação de formulário via n8n (nó Form Trigger)**

   * Recebe informações como cargo e localização.

2. **Buscar vagas no Indeed (API Scraper)**

   * Use `HTTP Request` (POST) com API do site `apify.com` ou similar.

3. **Aguardar a resposta da API**

   * Use o nó `Wait` com loop de verificação de status (até status "success").

4. **Extrair os dados das empresas contratantes**

   * Use `HTTP Request` (GET) com dataset retornado do scraper.

5. **Buscar os decisores com ****Apollo.io**

   * Nó `HTTP Request (POST)` com autenticação da Apollo API.
   * Envie o nome da empresa como parâmetro.

6. **Obter e-mails válidos dos decisores**

   * Nova requisição Apollo com `people-match` e filtros por e-mails verificados.

7. **Gerar e-mails personalizados com IA (LLM Chain)**

   * Use nó do OpenAI ou OpenRouter:

     * Envie o nome da empresa, cargo, e descrição da vaga
     * Receba um e-mail profissional formatado em JSON.

8. **Enviar e-mails via SmartLead**

   * Nó `HTTP Request (POST)` com API da SmartLead.
   * Envie os campos preenchidos como: nome, e-mail, cargo, texto do e-mail.

---

### **3. Automação de Recibos via Telegram**

Objetivo: extrair automaticamente os dados de um recibo enviado como imagem e registrar em uma planilha.

#### Passo a Passo:

1. **Criação do Bot no Telegram (via BotFather)**

   * Gere token e conecte ao n8n.

2. **Nó Trigger do Telegram**

   * Detecta quando uma imagem é enviada.
   * Habilite: `download image or files`.

3. **Verificação se a mensagem contém imagem**

   * Use o nó `Switch` para seguir caminhos diferentes se não houver imagem.

4. **Análise da imagem com IA (OCR + LLM)**

   * Use `OpenAI` ou `OpenRouter` com função `analyze image`.
   * Envie a imagem e peça extração dos dados: data, valor, fornecedor, descrição, etc.
   * Solicite retorno em formato JSON puro.

5. **Formatação dos dados (código JS no n8n)**

   * Nó `Code` (JavaScript) para tratar a resposta e transformá-la em objeto legível.

6. **Inserção no Google Sheets**

   * Nó `Google Sheets (Append Row)` com os dados extraídos.

7. **Resposta via Telegram para o usuário**

   * Nó `Send Message`, com mensagem de confirmação e resumo dos dados.

8. **Caminho alternativo (sem imagem)**

   * Enviar mensagem: "Por favor, envie uma imagem de recibo."

Aqui está o resumo completo com os tópicos e exemplos dos **3 sistemas de automação com IA simples, lucrativos e sem código** explicados:

---

**Resumo Geral:**

Foram apresentados **três sistemas de automação com IA** criados usando o **n8n** (sem precisar programar), voltados para negócios que buscam ganhar eficiência. Cada um pode ser vendido por **US\$ 500 a US\$ 1.500**, sendo úteis, repetíveis e valorizados por empresas reais.

---

**1. Automação de Fotos de Produtos (Product Shot Automation)**
Transforma imagens simples de produtos em versões profissionais usando IA de geração de imagens.

**Passo a passo básico:**

* Google Sheets armazena os links das imagens e prompts.
* API do OpenAI gera novas imagens estilizadas (usando DALL·E).
* As imagens são divididas e convertidas de base64.
* São armazenadas automaticamente em um bucket do Supabase.
* Links finais são atualizados no Google Sheets.

**Exemplo de uso:** Lojas virtuais ou e-commerces que precisam criar banners e imagens de produtos de forma automática e criativa.

---

**2. Sistema de Geração de Leads (Lead Gen System)**
Rastreamento automatizado de vagas em sites como o Indeed e geração de e-mails personalizados para captar clientes potenciais.

**Etapas do fluxo:**

* Formulário do n8n coleta o cargo e país desejado.
* API do Indeed busca empresas que estão contratando.
* Apollo.io é usado para encontrar os decisores dessas empresas.
* Um modelo LLM (Large Language Model) gera e-mails personalizados.
* Leads e e-mails são enviados automaticamente para a ferramenta Smartlead.

**Exemplo de uso:** Agências de marketing, freelancers ou especialistas em IA que querem vender serviços de automação para empresas com demanda ativa.

---

**3. Automação de Leitura de Recibos (Receipt Automation)**
Permite que o cliente envie uma foto de recibo pelo Telegram, e o sistema preenche automaticamente uma planilha com os dados extraídos.

**Fluxo completo:**

* Bot do Telegram recebe a imagem e aciona o n8n.
* A imagem é analisada via OpenRouter usando IA de OCR + GPT-4.
* Dados como valor, data, descrição e fornecedor são extraídos em JSON.
* Código interno do n8n formata os dados.
* Dados são inseridos automaticamente no Google Sheets.
* Um resumo é enviado ao cliente via Telegram.

**Exemplo de uso:** Empresas de contabilidade, autônomos ou gestores que precisam organizar comprovantes financeiros com rapidez.

---

**Resumo Final com Aplicações Possíveis:**

1. Criar imagens de produtos para e-commerce → venda para lojas virtuais.
2. Gerar listas de leads de empresas contratando → venda para agências ou freelancers.
3. Automatizar lançamento de despesas com recibos → venda para contadores, MEIs ou clínicas.

Três automações simples e práticas com inteligência artificial e *no-code*, usando o n8n, que podem ser vendidas por valores entre US\$ 500 e US\$ 1.500. 

A primeira é uma automação de geração de imagens de produtos a partir de links e prompts, utilizando o Google Sheets, API da OpenAI, conversão de base64 e upload para Supabase. Essa automação é voltada para e-commerce e permite gerar pôsteres de forma rápida e automatizada.

 A segunda é um sistema de geração de leads: coleta vagas de emprego no Indeed via API, identifica empresas contratando, busca decisores via Apollo, gera e-mails personalizados com LLMs e os envia automaticamente por plataformas como o Smartlead.

A terceira automação é voltada para o registro automático de recibos. O fluxo começa no Telegram, onde o usuário envia uma imagem, que é analisada por uma IA via OpenRouter para extrair informações como data, valor e fornecedor. Os dados são limpos com um script simples e inseridos automaticamente no Google Sheets. Ao final, o usuário recebe uma confirmação via Telegram.

 Essas soluções são totalmente configuráveis sem a necessidade de programação, sendo ideais para agências, freelancers ou iniciantes que querem oferecer serviços úteis e com boa margem de lucro para empresas que buscam economizar tempo e automatizar tarefas operacionais.
