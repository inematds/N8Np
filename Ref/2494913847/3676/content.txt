Como construir o JARVIS sem programar (Tutorial com Lovable, ElevenLabs, n8n)

**Resumo Geral:**  
O vídeo ensina como criar um assistente de IA semelhante ao JARVIS do Homem de Ferro, usando apenas ferramentas no-code: Lovable (para a interface web), ElevenLabs (para voz conversacional) e n8n (para automações e execução de tarefas). Tudo é feito sem escrever código diretamente, usando prompts de linguagem natural.

---

**Principais Tópicos com Exemplos:**

1. **Demonstração do JARVIS em ação:**  
   - Agenda uma reunião com Michael Scott  
   - Envia e-mails automaticamente  
   - Verifica o calendário do usuário  
   - Deleta eventos e classifica e-mails

2. **Arquitetura geral do sistema:**  
   - JARVIS é o agente principal  
   - Ele identifica a intenção do usuário e aciona agentes específicos:  
     - Agente de e-mail (com ações do Gmail)  
     - Agente de calendário (com ações do Google Calendar)  
     - Agente de contatos (usando Airtable)  
     - Agente de criação de conteúdo (usando Tavily)

3. **Interface com o Lovable:**  
   - Criada com linguagem natural  
   - Personalização com elementos dinâmicos (ícones pulsantes, imagem central, fundo com linhas animadas)  
   - Widget de voz da ElevenLabs embutido

4. **Configuração do ElevenLabs:**  
   - Criação de um agente de voz chamado JARVIS  
   - Personalidade com humor sarcástico e seco, criada via prompt no ChatGPT  
   - Voz clonada de JARVIS usando áudios curtos  
   - Integração via webhooks com o n8n para execução das ações

5. **Configuração no n8n:**  
   - Criação de 5 workflows:
     - Agente principal (JARVIS)
     - E-mail, Calendário, Contatos, Conteúdo (cada um como subagente)
   - O agente principal roteia a intenção para o subagente certo  
   - Webhook recebe o comando do ElevenLabs e envia a resposta  
   - Ferramentas como Tavily são usadas para buscas na internet

6. **Exemplo de busca com Tavily:**  
   - Jarvis busca por "mangas japonesas Miyazaki" e responde com sarcasmo  
   - Mostra como o fluxo detecta erro se o webhook estiver inativo

7. **Importação e customização dos fluxos:**  
   - Workflows estão disponíveis gratuitamente na comunidade do criador  
   - Necessário configurar as chaves da API pessoal (Google, Tavily etc.)

8. **Dicas de funcionamento:**  
   - O sistema prompt define como o agente se comporta  
   - As ferramentas são chamadas conforme a intenção do usuário  
   - Cada agente específico executa a tarefa e retorna o resultado para o JARVIS responder
