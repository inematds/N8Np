Abaixo está o **passo a passo completo** para criar um agente de IA que gera e publica automaticamente imagens no Instagram com n8n, sem código:

---

### **PASSO 1 – Configuração das Contas e APIs**

1. **Exa.ai**:

   * Crie uma conta e gere uma **API Key**.
   * Essa API será usada para buscar notícias recentes conforme palavras-chave.

2. **Deepseek AI (ou DPCKI)**:

   * Gere uma API Key.
   * Será usada para reescrever textos das notícias em formato de legenda para Instagram.

3. **Together AI (modelo Flux)**:

   * Gere uma API Key.
   * Será usada para gerar imagens a partir do prompt de texto.

4. **ScreenshotOne**:

   * Crie conta e gere a **API Key**.
   * Usado para transformar links HTML em imagens JPEG para publicação no Instagram.

5. **Google Cloud Storage**:

   * Configure um bucket para armazenar imagens.
   * Gere as credenciais de acesso.

6. **Google Sheets**:

   * Crie uma planilha com colunas: `flux_image_link`, `instagram_image_link`, `caption`, `status`, `post_date`.

7. **Facebook/Instagram for Developers**:

   * Crie um App no [developers.facebook.com](https://developers.facebook.com/).
   * Habilite as permissões: `instagram_basic`, `instagram_content_publish`, `pages_show_list`, etc.
   * Gere e estenda o **Access Token** para 60 dias.

8. **Redis (opcional)**:

   * Usado para armazenar temporariamente tokens e variáveis, via Redis Cloud ou local.

---

### **PASSO 2 – Workflow 1: Gerar Conteúdo e Imagem**

1. **Definir variáveis globais**:

   * Tópico (ex: "robótica").
   * Estilo da imagem (Template 1, 2 ou 3).

2. **Buscar Notícias com ****Exa.ai**:

   * Gere uma query com base no tópico.
   * Pegue as 3 primeiras notícias.

3. **Gerar Legenda com Deepseek AI**:

   * Reescreva o conteúdo da notícia como legenda de post para Instagram (máx. 2.000 caracteres).
   * Gere também o **título com até 8 palavras**, sem emoji ou Markdown.

4. **Gerar Imagem com Together AI / Flux**:

   * Crie prompt visual com base na legenda.
   * Gere imagem base64 e converta para imagem visível.

5. **Salvar imagem no Google Cloud Storage**:

   * Nomeie o arquivo e armazene.
   * Gere o link da imagem.

6. **Gerar Screenshot com ScreenshotOne**:

   * Use o link HTML gerado para gerar imagem JPEG.
   * Salve essa imagem no Cloud Storage também.

7. **Atualizar Google Sheets**:

   * Escreva na planilha: link da imagem, link do Instagram (a preencher), legenda, status `em branco`.

---

### **PASSO 3 – Workflow 2: Publicar no Instagram**

1. **Autenticar com API do Instagram**:

   * Use o token salvo no Redis.
   * Obtenha `Instagram Business Account ID`.

2. **Buscar dados da planilha (Google Sheets)**:

   * Filtre linhas com status vazio.
   * Pegue imagem e legenda para postar.

3. **Publicar imagem no Instagram**:

   * Use a API `graph.facebook.com`.
   * Envie a imagem (em JPEG) com a legenda.
   * Aguarde 20 segundos e publique o post com o ID gerado.

4. **Atualizar Google Sheets**:

   * Atualize status para `Postado`.
   * Registre a data atual como `post_date`.

---

### **PASSO 4 – Workflow Extra (Imagens Motivacionais)**

1. Defina o tema: ex. “mensagens motivacionais para jovens adultos”.
2. Gere a legenda e título com Deepseek AI.
3. Use Together AI (Flux) para criar imagem estilizada.
4. Salve no Cloud, gere screenshot com ScreenshotOne.
5. Armazene na planilha e publique conforme os passos anteriores.

---

### **Exemplos de Palavras-chave que funcionam bem**:

* robótica
* inteligência artificial
* blockchain
* saúde digital
* motivação
* produtividade
* inovação
* futuro do trabalho

Foi criado um sistema automatizado que gera e publica postagens de imagem no Instagram com ajuda de inteligência artificial, sem a necessidade de programação. O processo envolve:

1. **Coleta de Notícias**: Utiliza a API da Exa.ai para buscar notícias recentes com base em palavras-chave como "robótica", "blockchain" etc.

2. **Geração de Conteúdo e Imagem**:

   * O texto das notícias é reescrito em formato de legenda usando o Deepseek AI.
   * Um prompt visual é criado a partir da legenda e transformado em imagem com o modelo Flux da Together AI.
   * O texto e a imagem são preparados para o Instagram (título limitado a 8 palavras e imagem no estilo escolhido).

3. **Conversão e Armazenamento**:

   * A imagem é convertida para formato JPEG com a ScreenshotOne.
   * Ambas as imagens (original e da captura de tela) e os textos são armazenados no Google Cloud Storage.
   * Os dados (links, status, datas) são organizados em uma planilha do Google Sheets.

4. **Publicação no Instagram**:

   * A automação obtém os dados da planilha.
   * Usa APIs do Facebook e Instagram para autenticação e envio do post.
   * O sistema gerencia automaticamente os tokens de autenticação com Redis.
   * Após a publicação, a planilha é atualizada com o status “Publicado”.

5. **Template Motivacional (extra)**:

   * Um segundo fluxo gera imagens motivacionais com base em discursos para jovens adultos.
   * Segue a mesma estrutura, mas com tema e estilo visual diferentes.

Ferramentas utilizadas:

* **n8n**: automação de fluxo
* **Exa.ai**: busca de notícias
* **Deepseek AI**: reescrita de texto
* **Flux / Together AI**: geração de imagem
* **ScreenshotOne**: captura de tela em JPEG
* **Google Sheets** e **Google Cloud**: armazenamento
* **APIs do Facebook e Instagram**: publicação automatizada

Esse sistema permite gerar postagens visuais e legendas baseadas em temas atuais, com diferentes estilos, mantendo o feed do Instagram sempre ativo e atrativo.
