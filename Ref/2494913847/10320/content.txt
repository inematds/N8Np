Aqui estão os **principais hacks e otimizações** usados no sistema apresentado no vídeo para automatizar vídeos virais de ASMR com IA, economizar tempo e aumentar as chances de viralização:

---

### **Hacks de Geração de Conteúdo**

1. **Prompt Estruturado e Rico em Detalhes**

   * Usa estrutura clara com campos como: `sujeito`, `cenário`, `ação`, `som`, `estilo`, `movimento de câmera`, etc.
   * Garante que o prompt gere vídeos consistentes e visualmente impactantes.
   * Exemplo:

     * Objeto: *glass kiwi*
     * Prompt gera: corte hiper-realista, som do vidro, ângulo cinematográfico, iluminação suave.

2. **Reaproveitamento de ideias com lista rotativa**

   * Mantém planilha com as **7 últimas frutas usadas**.
   * Garante que a IA gere algo **sempre novo**, evitando repetição.

3. **Uso de parser estruturado**

   * Força a IA a entregar saída em dois campos separados: `fruta` e `legenda`.
   * Evita erros de formatação e facilita automação no n8n.

---

### **Hacks Técnicos e de Automação**

4. **Automação total com n8n**

   * Sistema executa sozinho: ideia → vídeo → postagem → planilha.
   * Pode ser configurado para rodar **X vezes por dia**, ex: a cada hora.

5. **Delay com verificação contínua**

   * Usa espera de 5 min + checagem por ID até o vídeo estar pronto.
   * Impede que o fluxo trave ou falhe por vídeo ainda em processamento.

6. **Limpeza do JSON antes do envio**

   * Remove `\n` e `"` duplos do prompt antes de enviar à API do FAL.
   * Evita falhas de parsing na geração de vídeo.

---

### **Hacks de Postagem nas Redes**

7. **Uso do Botato para multiplataforma**

   * Um só vídeo postado automaticamente em YouTube, TikTok e Instagram.
   * Suporte também para Threads, Pinterest, X (Twitter), Facebook e LinkedIn.

8. **Transformação de URL via Botato**

   * O link da FAL é convertido para link da Botato, que hospeda e posta o vídeo.
   * Necessário para que o vídeo seja aceito pelas redes sociais.

9. **Publicação com configurações separadas**

   * Cada rede tem seu próprio node de postagem.
   * Evita que uma falha em uma rede afete as outras.

---

### **Hacks de Performance e Alcance**

10. **Volume como fator de viralização**

* Publica vídeos em massa (até 24 por dia), aumentando chance de viral.
* Quanto mais vídeos únicos por dia, maior o alcance potencial.

11. **Vídeos com áudio ativado (ASMR)**

* Gera vídeos com som integrado — muito mais engajadores.
* Áudio é essencial para o formato ASMR e aumenta tempo de retenção.

12. **Aproveitamento de tendências**

* Vídeos com frutas ou objetos de vidro sendo cortados estão em alta.
* Aproveita o momento para crescer no algoritmo das plataformas.

Aqui está o **passo a passo completo** para criar o sistema que gera e publica automaticamente vídeos virais de ASMR com frutas de vidro sendo cortadas, usando **n8n**, **Google Veo V3** (via FAL.ai) e **Botato**:

---

### **1. Preparar os dados iniciais**

* Crie uma **Google Sheet** com duas colunas: `object` (nome da fruta) e `url` (link do vídeo).
* Preencha com 7 exemplos anteriores para iniciar o sistema.

---

### **2. Criar o fluxo no n8n**

#### **Parte 1: Geração da Ideia (Idea Agent)**

* **Trigger agendado**: escolha a frequência (ex: 3x ao dia).
* **Node Google Sheets (leitura)**: leia os 7 últimos objetos (frutas) do sheet.
* **Node de agregação**: junte os 7 objetos em uma lista.
* **Node OpenAI (ou outro LLM)**: gere:

  * Uma **nova fruta** que ainda não foi usada.
  * Uma **legenda** curta para a postagem.
* Use um **structured output parser** para garantir saída separada: `object` e `caption`.

---

### **3. Criar o prompt de vídeo (Prompt Agent)**

* Novo node LLM com instruções claras:

  * Geração de prompt para **vídeo ASMR hiper-realista**.
  * Formato 9:16 (vertical), foco em som, textura e corte visual.
  * Defina estrutura de output: `subject`, `setting`, `action`, `style`, `sound`, `camera motion`, `composition`, `ambience`, `aspect ratio`.

---

### **4. Enviar para o FAL com modelo Google Veo V3**

* Crie conta em [FAL.ai](https://fal.ai/) e gere uma **API Key**.
* Use um **node HTTP Request**:

  * Método: POST
  * Header: Authorization = `Key SUA_API_KEY`
  * Body JSON:

    ```    {
      "prompt": "PROMPT GERADO",
      "aspect_ratio": "9:16",
      "generate_audio": true
    }
    ```
* Armazene o `request_id` retornado.

---

### **5. Verificar se o vídeo foi gerado**

* Use `setTimeout` + `loop` de checagem:

  * A cada 10 segundos, verifique com o `request_id` se o vídeo está pronto.
  * Se estiver pronto, armazene o `video_url`.

---

### **6. Atualizar a planilha**

* **Node Google Sheets**:

  * Delete a linha 2 (mais antiga).
  * Adicione nova linha com:

    * `object`: nome da nova fruta.
    * `url`: link do vídeo gerado.

---

### **7. Publicar nas redes sociais (Botato)**

* Crie conta em [Botato](https://botato.io/) e gere uma **API Key**.
* Conecte suas redes sociais (YouTube, TikTok, Instagram).
* Em cada node HTTP (um por rede), envie:

  * `title` = legenda do vídeo
  * `url` = URL do vídeo
  * Credencial de autenticação: `Header Auth` com `Botato-API-Key`.

---

### **8. Verificação final**

* Você pode adicionar um node para verificar se a postagem foi realizada com sucesso via painel do Botato (`Published Posts`).

---

### **9. Download do template**

* O autor disponibiliza:

  * Template JSON do fluxo no n8n.
  * Planilha modelo.
  * Tudo na **comunidade gratuita Free School** (link na descrição do vídeo).

---

### **Resumo das Ferramentas**

| Etapa          | Ferramenta          | Função                     |
| -------------- | ------------------- | -------------------------- |
| Ideia e prompt | n8n + OpenAI        | Criar objeto e descrição   |
| Vídeo          | FAL + Google Veo V3 | Gerar vídeo ASMR com áudio |
| Postagem       | Botato              | Publicar automaticamente   |
| Dados          | Google Sheets       | Manter histórico rotativo  |

**Resumo do vídeo “This AI System Posts Viral ASMR Shorts Hourly**

Como construir um sistema completo de automação usando **n8n**, **Google Veo V3** e **Botato** para gerar e postar vídeos virais de ASMR com frutas de vidro sendo cortadas — de forma **totalmente automática** e **sem código**.

### Etapas do sistema apresentado:

1. **Geração da Ideia (Ideia Agent)**

   * Sistema verifica as últimas 7 frutas já utilizadas.
   * Gera uma nova fruta ainda não usada e uma legenda.
   * Usa um **parser estruturado** para garantir que o output tenha dois campos: fruta e legenda.

2. **Geração do Vídeo (Prompt Agent)**

   * Com base na fruta escolhida, gera um prompt para vídeo hiper-realista no estilo ASMR.
   * O prompt é enviado via API para o modelo **Google Veo V3** usando a plataforma **FAL.ai**.
   * O modelo gera o vídeo com **áudio integrado**, que é essencial para o efeito ASMR.

3. **Verificação e Espera**

   * O sistema espera cerca de 5 minutos até o vídeo ser finalizado.
   * Faz verificações contínuas para garantir que o vídeo esteja pronto antes de prosseguir.

4. **Atualização da Planilha Google**

   * Remove a linha mais antiga da planilha e insere a nova fruta com o link do vídeo.
   * Garante que a lista contenha sempre os 7 vídeos mais recentes.

5. **Publicação nas Redes Sociais**

   * Utiliza a plataforma **Botato** para publicar automaticamente no **YouTube**, **Instagram** e **TikTok**.
   * O vídeo é convertido para um link do Botato antes de ser postado.
   * Também é possível postar em outras 6 redes como X (Twitter), LinkedIn, Threads, etc.

6. **Detalhes Técnicos**

   * Integração via APIs do FAL e Botato com autenticação via Header (API Key).
   * Vídeos gerados em formato vertical (9:16).
   * Geração média de **vídeos de 8 segundos a US\$ 6 por vídeo** (incluindo áudio).
   * Custo por segundo com áudio: **US\$ 0,75**.

7. **Personalização e Escalabilidade**

   * O fluxo pode ser programado para rodar quantas vezes quiser por dia.
   * O objetivo é volume e constância para aumentar chances de viralização.


### Exemplos citados:

* Um dos primeiros vídeos gerados (com prompt inicial) teve **35 mil views em um dia**.
* Os prompts evoluíram e estão gerando resultados ainda melhores.

### Objetivo:

Mostrar como automatizar tendências virais com IA, aumentar a produção de conteúdo e crescer canais nas redes sociais de forma escalável e criativa.
