## 🚀 Como Usar os Arquivos

### 1. Preparação Inicial
```# Crie a estrutura de pastas
mkdir -p farmacia-automation/{workflows,config,database,docs}

# Organize os arquivos
mv farmacia_workflow_*.json farmacia-automation/workflows/
mv farmacia_credentials.json farmacia_environment.json farmacia-automation/config/
mv farmacia_database_schema.sql farmacia-automation/database/
mv farmacia_setup_guide.md farmacia-automation/docs/```

### 2. Instalação Rápida com Docker
```cd farmacia-automation

# Use as configurações do farmacia_environment.json
# Crie o docker-compose.yml com base na seção docker_compose

docker-compose up -d```

### 3. Configure o Banco de Dados
```# Execute o schema
docker exec -i postgres-farmacia psql -U farmacia_user -d farmacia_db < database/farmacia_database_schema.sql```

### 4. Importe os Workflows no n8n
1. Acesse http://localhost:5678
2. Configure as credenciais usando `farmacia_credentials.json` como guia
3. Importe os workflows na ordem:
   - Principal → Resposta → Relatórios → Monitoramento

### 5. Configure o Evolution API
```# Webhook para receber mensagens
curl -X POST https://sua-evolution-api.com/webhook/set \
  -H "apikey: sua-api-key" \
  -d '{
    "url": "http://localhost:5678/webhook/farmacia-receitas",
    "events": ["messages.upsert"]
  }'```
