## 🔍 Como Usar

1. **Navegue** pelas categorias acima
2. **Busque** usando a barra de pesquisa (topo da página)
3. **Baixe** os arquivos `.json` dos workflows
4. **Importe** no seu n8n
5. **Configure** as credenciais necessárias

## ⚠️ Importante

- Todos os workflows precisam de **credenciais reconfiguradas**
- Este é um **repositório de referência**, não uma instalação n8n ativa
- Workflows estão em **Português, Espanhol e Inglês**
