## INSTRUÇÃO PARA GERAÇÃO DO JSON – `ong-castracao-central` (n8n 1.104.2)

**Objetivo:** Criar um fluxo n8n modular com um agente orquestrador principal que recebe entrada via WhatsApp ou e-mail, identifica a intenção do usuário e encaminha para um dos 4 subagentes especializados.
**Modelo de referência:** `enxame-de-agentes.json`

---

### 1. Estrutura Geral

**Agente Orquestrador: `OrquestradorONG`**

* Tipo: Entrada e Processamento
* Ativado por: WhatsApp (Webhook EvolutionAPI) ou E-mail (IMAP)
* Função: Interpretar a intenção do usuário (classificação)
* Rota: Switch para Subagentes
* Execução: Sequencial

**Subagentes:**

1. `AgenteCastracao`

   * Função: Agenda castrações com Supabase + Google Calendar
   * Armazena: `castracoes`
   * Memória: Redis e Supabase
2. `AgenteAdocaoDoacao`

   * Função: Gerencia pedidos de adoção e doação
   * Armazena: `adocoes_doacoes`
3. `AgenteAnimaisPerdidos`

   * Função: Coleta e orienta sobre animais perdidos
   * Armazena: `animais_perdidos`
4. `AgenteDicas`

   * Função: Responde dúvidas frequentes via RAG
   * Integra: Base vetorial

---

### 2. Regras para Construção

* Use **somente nodes presentes no modelo `enxame-de-agentes.json`** e nos exemplos técnicos fornecidos.
* Use `set`, `switch`, `httpRequest`, `function`, `subworkflow`, `respondToWebhook`, conforme necessário.
* Inicie sempre com um `set` após entrada externa.
* Cada subagente deve ser um subworkflow separado (modularização).
* Nomear todos os nodes claramente, seguindo boas práticas.

---

### 3. Foco nos Subagentes

**AgenteCastracao:**

* Recebe dados do usuário (nome, animal, data preferida)
* Usa Supabase para salvar os dados
* Cria evento no Google Calendar
* Retorna confirmação via mesmo canal

**AgenteDicas (RAG):**

* Recebe a dúvida
* Consulta base vetorial via Supabase
* Retorna a resposta

**AgenteAdocaoDoacao:**

* Recebe pedido de doação ou intenção de adotar
* Armazena e organiza no Supabase

**AgenteAnimaisPerdidos:**

* Recebe informações do animal perdido
* Armazena com geolocalização (se possível)
* Gera resposta orientadora

---

### 4. Finalização

* Adicionar fallback de erro simples com logging em Supabase
* Incluir um nó de logging em cada subworkflow
* Validar conexões entre os nós com `validate_workflow_connections`
* Validar estrutura do fluxo com `validate_workflow`
