**Tradução Completa do Vídeo "Long-Form Faceless Video AI Agent System: Retro-Future Jazz Music Videos For $5k/mo (n8n Template)"**

**Resumo Geral:**
O criador do vídeo mostra um sistema de agente de IA para criar vídeos de música instrumental no estilo jazz retrô-futurista, automatizando tudo com ferramentas como n8n, Suno, Supabase, Flux, Minimax e OTCode. O sistema pode gerar até US$ 5 mil por mês com menos de 40 vídeos publicados. Ele detalha como configurar cada etapa da automação, incluindo geração de músicas, imagens, vídeos e a renderização final.

---

**Etapas Explicadas:**

1. **Introdução**
   - O criador construiu um sistema de IA para gerar vídeos de jazz futurista que estão tendo milhões de visualizações.
   - Exemplo: canal com 55 mil inscritos e apenas 32 vídeos, gerando cerca de US$ 5 mil/mês.
   - A automação é feita com agentes de IA e n8n.
   - Oferece templates prontos na comunidade Any No Code Premium.

2. **Funcionamento do Sistema**
   - Dá um tema ao gerador de músicas (Suno), como “jazz retrô futurista”.
   - O Suno permite gerar até 10 músicas gratuitas por dia.
   - As músicas são armazenadas no **Supabase** (já que o Suno não tem API estável).
   - Depois, imagens são geradas com **Flux AI**, que são transformadas em vídeo com **Minimax**.
   - O vídeo final é renderizado com **OTCode**.

3. **Etapas Técnicas Detalhadas**

   - **1º passo: Geração de Música (Suno)**
     - Usa trigger agendado no n8n.
     - Gera 4 músicas (exemplo).
     - Músicas são enviadas ao Supabase via HTTP Request.
     - Supabase configurado com chave secreta e URL da API.
     - Após upload, os arquivos são filtrados para capturar apenas arquivos `.mp3`.

   - **2º passo: Geração de Imagens (Flux AI)**
     - Usa modelo de linguagem (LLM) com prompts customizados.
     - As imagens são criadas com base nos prompts e salvas.
     - É feita uma espera de 30 segundos para garantir o tempo de processamento.
     - Depois, é feito um request para obter as imagens já renderizadas.

   - **3º passo: Transformar Imagem em Vídeo (Minimax)**
     - Usa a URL da imagem e envia via HTTP para gerar o vídeo.
     - Espera-se 1 minuto para garantir que o vídeo seja processado.
     - Recupera o vídeo com método GET e salva a URL do vídeo gerado.

   - **4º passo: Renderização Final (OTCode)**
     - Junta música de fundo + vídeos + estilo.
     - Envia para API do OTCode para renderizar o vídeo completo.
     - Espera 3 minutos para garantir renderização.
     - Usa novo request para verificar status e baixar o vídeo final.
     - Exibe o vídeo completo com música e visual relaxante.

4. **Extras**
   - O vídeo recomenda usar a comunidade “Any No Code” para suporte, templates e personalizações.
   - Tudo pode ser customizado por nicho (por exemplo: vídeos motivacionais, música relaxante, etc).
   - O sistema pode rodar diariamente ou a cada hora, conforme desejado.

---

**Exemplos de Ferramentas Utilizadas:**

- **n8n**: Orquestra todos os fluxos.
- **Suno**: Geração de música instrumental (sem API oficial).
- **Supabase**: Armazenamento dos arquivos de áudio.
- **Flux AI**: Geração das imagens com prompts.
- **Minimax**: Conversão de imagem em vídeo.
- **OTCode**: Renderização do vídeo completo com trilha sonora.
