Aqui estão os **principais hacks e truques** usados no vídeo para otimizar a automação de geração de vídeos com personagens animados e IA — mesmo sem saber programar:

---

### **HACKS PARA CRIAR VÍDEOS AUTOMATIZADOS COM DIÁLOGO DE PERSONAGENS**

---

#### 1. **Transformar artigo em diálogo de humor com IA**

* **Prompt customizado** transforma artigos em roteiros estilo *Family Guy*.
* Estrutura do prompt inclui:

  * Alternância de falas (Stewie pergunta, Peter responde)
  * Estilo de fala dos personagens
  * Humor + informação
  * Saída em JSON formatado com `speaker`, `text`, `voice_id`

**Exemplo de saída:**

```[
  {"speaker": "Stewie", "text": "Você viu o investimento da Meta?", "voice_id": "stewie-id"},
  {"speaker": "Peter", "text": "Eu vi. Zuck gastando bilhões como eu gasto no bar!", "voice_id": "peter-id"}
]```

---

#### 2. **Divisão automática de falas com **`Loop Over Items`**

*** Evita sobrecarga da API do Fish.audio dividindo as 8 falas em ciclos.
* Garante envio sequencial das falas para criação de áudios.

**Vantagem:** Respeita limites de API sem falhar.

---

#### 3. **Uso de Supabase como CDN gratuito**

* Supabase é usado como repositório público de:

  * Vídeos base
  * Imagens PNG dos personagens
  * Áudios gerados
* Permite obter URLs públicos automaticamente.

**Dica:** Criar um bucket público e organizar por tipo de mídia.

---

#### 4. **Transcrição sincronizada com Whisper**

* IA da OpenAI transforma os áudios em texto com marcação de tempo (timestamp).
* Garante que a legenda aparece **sincronizada** com a fala no vídeo.

**Habilite no Whisper:**

```"timestamp_granularities": ["word"]```

---

#### 5. **Template reutilizável no Creatomate**

* Crie um modelo com posições fixas para:

  * Vídeo base (fundo)
  * Imagens dos personagens (aparecem só quando falam)
  * Legendas
  * Áudios sincronizados
* Reutilizável com simples troca de conteúdo via API JSON.

**Dica:** Use `if speaker == Peter ? imagem1 : imagem2` para mudar dinamicamente.

---

#### 6. **Pinos no n8n para economizar tokens**

* **Pinning** de nós com dados prontos evita reprocessamento.
* Ideal para testes sem regenerar textos ou gastar tokens da IA.

**Como fazer:** clique com botão direito no nó > “Pin data”.

---

#### 7. **Criação de pipeline 100% no-code**

* Nenhuma linha de código foi usada.
* Tudo construído com:

  * Drag and drop no n8n
  * Templates JSON
  * APIs públicas e gratuitas

---

#### 8. **Geração viral baseada em temas do momento**

* Notícias do **TechCrunch** são extraídas automaticamente para manter o conteúdo atual.
* Usa o nome de celebridades e empresas (Zuckerberg, Meta, OpenAI) para atrair cliques.

---

#### 9. **Importação direta de template **`.json`** no n8n

*** Permite clonar todo o fluxo com um clique.
* Basta importar arquivo JSON do projeto no botão “Import from file”.

---

#### 10. Formatação final de legenda e imagem via IA

* Duração das falas define tempo que imagem do personagem aparece.
* Formatação visual (tipo de fonte, sombra, posição) é customizada via Creatomate JSON.

---

Aqui está o **passo a passo completo** para criar um gerador de vídeos estilo “Family Guy” com diálogo automatizado usando **n8n** e ferramentas no-code, baseado no vídeo do Andy (3.3M views):

---

### **PASSO A PASSO PARA CRIAR VÍDEOS ANIMADOS AUTOMATIZADOS COM DIÁLOGO**

---

### 1. **Preparar Google Sheets**

Use uma planilha com as seguintes colunas:

* `input_video` → link do vídeo base (ex: Minecraft)
* `article_url` → link do artigo (ex: TechCrunch)
* `status` → comece com “pending”
* `character_a_name` e `character_b_name` → ex: Peter, Stewie
* `character_a_image`, `character_b_image` → link para PNG no Supabase
* `character_a_voice_id`, `character_b_voice_id` → ID das vozes do Fish.audio
* `output_url` → será preenchido ao final

---

### 2. **Configurar Supabase (armazenamento de arquivos)**

1. Criar projeto no [https://supabase.com](https://supabase.com/)
2. Ir para **Storage > Create Bucket** (ex: `n-family-guy`)
3. Tornar o bucket público
4. Subir:

   * Vídeo base (ex: `minecraft.mp4`)
   * PNGs dos personagens
5. Obter o link dos arquivos (três pontos > "Get URL")

---

### 3. **Obter Vozes no ****Fish.audio**

1. Acesse [https://fish.audio](https://fish.audio/)
2. Busque por vozes (ex: “Peter Griffin”, “Stewie”)
3. Clique nos três pontos > copiar `Model ID`
4. Cole na planilha nas colunas de `voice_id`

---

### 4. **Criar automação no n8n**

#### Seções principais:

#### A. **Agendamento**

* **Node:** Schedule Trigger
* Define frequência (ex: a cada hora) para verificar planilha

#### B. **Leitura do Google Sheets**

* **Node:** Google Sheets → Get Rows
* Filtro: status = "pending"
* Retornar apenas a primeira linha

#### C. **AI Agent (gerar roteiro de diálogo)**

* **Node:** AI Agent (ChatGPT, Claude ou OpenRouter)
* Prompt: gerar 8 falas alternadas entre os personagens
* Output: JSON com `{speaker, text, voice_id}`

#### D. **HTTP Request para capturar conteúdo do artigo**

* Método: GET
* URL: link do artigo (extraído da planilha)

#### E. **Output Parser (JSON)**

* Formato: 8 objetos com `speaker`, `text`, `voice_id`

---

### 5. **Gerar Áudio com ****Fish.audio**

* **Loop Over Items:** para cada fala

  * **HTTP Request:** API do Fish.audio (POST)

    * Headers: `Authorization: Bearer SEU_API_KEY`
    * Body: texto, speaker, voice\_id

* **Armazenar no Supabase:**

  * Novo **HTTP Request** (PUT/POST com áudio)
  * Bucket: mesmo usado nas imagens
  * Requer `Service Role Key` do Supabase

---

### 6. **Transcrição com OpenAI Whisper**

* **HTTP Request (POST):** para `https://api.openai.com/v1/audio/transcriptions`

  * Body: arquivo de áudio + modelo `whisper-1`
  * Output: texto + duração de cada palavra
  * Gera legendas sincronizadas

---

### 7. **Compilar o vídeo com Creatomate**

* Criar template em [https://creatomate.com](https://creatomate.com/)

  * Inserir faixas de: vídeo base, imagens PNG, áudios, legendas
  * Obter **Template ID**
* **Node: HTTP Request** para `https://api.creatomate.com/v1/renders`

  * Headers: `Authorization: Bearer SEU_API_KEY`
  * Body: JSON com:

    * video\_source
    * audio\_sources
    * subtitles
    * image\_sources
    * image\_durations

---

### 8. **Atualizar Google Sheets**

* **Node:** Google Sheets → Update Row
* Campo `status` → “completed”
* Campo `output_url` → link final do vídeo

---

### **Ferramentas Usadas**

| Ferramenta     | Função                            |
| -------------- | --------------------------------- |
| Google Sheets  | Gerenciar ideias/status           |
| Supabase       | Armazenar vídeos, imagens, áudios |
| Fish.audio     | Gerar vozes IA dos personagens    |
| OpenAI Whisper | Gerar legendas automáticas        |
| Creatomate     | Montar o vídeo final com template |
| n8n            | Orquestrar todo o fluxo (no-code) |

---

### **Exemplo de Aplicação**

* Tema: Notícias de tecnologia
* Estilo: Humor cômico com personagens conhecidos
* Público: TikTok, Shorts, Reels

---

**Resumo do vídeo "How I Built A 3.3M View Cartoon Character Dialogue Video Generator (Viral & No-Code)"**

O vídeo mostra como Andy construiu um gerador automatizado de vídeos estilo “Family Guy”, com diálogo entre personagens como Peter e Stewie, utilizando apenas ferramentas no-code e APIs, atingindo mais de 3,3 milhões de visualizações. A automação completa é feita no **n8n** e integrando diversas ferramentas.

---

**1. Conceito da Automação**

* Sistema cria vídeos verticais com diálogos cômicos e informativos entre personagens animados.
* Baseado em notícias reais (como do TechCrunch) convertidas em roteiros estilo “Family Guy”.

---

**2. Etapas da Automação**

**Etapa 1: Preparação**

* Google Sheets armazena as ideias com status “pending”.
* Campos necessários: vídeo base (ex: gameplay), nomes e imagens dos personagens, IDs de voz, link de artigo e status.

**Etapa 2: Criação do Roteiro**

* AI Agent gera diálogo no estilo Peter e Stewie com base em artigos da internet.
* Utiliza modelo via OpenRouter (padrão: GPT-4 ou 03-Pro).
* Resposta estruturada em JSON com 8 falas (alternando entre os dois personagens).

**Etapa 3: Geração de Áudio**

* Cada fala é enviada à API do **Fish.audio** para gerar vozes realistas.
* Audios são armazenados automaticamente no **Supabase (bucket público)**.

**Etapa 4: Geração de Legendas**

* Utiliza **Whisper API** da OpenAI para transcrição e sincronização das falas com o tempo.

**Etapa 5: Montagem do Vídeo Final**

* Utiliza a API do **Creatomate** com template pré-definido.
* Sobrepõe:

  * Vídeo base (ex: Minecraft)
  * Imagens dos personagens (em sincronia com falas)
  * Legendas transcritas
* Tudo feito com dados vindos do JSON gerado e template ID.

**Etapa 6: Atualização**

* Google Sheets é atualizado automaticamente com link final do vídeo e status "completed".

---

**3. Ferramentas Utilizadas**

* **n8n** (plataforma principal da automação)
* **Google Sheets** (entrada e controle de status)
* **Supabase** (armazenamento de vídeo, imagens e áudios)
* **OpenRouter/OpenAI** (geração de texto estilo roteiro)
* **Fish.audio** (geração de voz para personagens)
* **Whisper API** (transcrição das falas)
* **Creatomate** (montagem do vídeo com template automático)

---

**4. Exemplos de Conteúdo Gerado**

* Vídeos com humor satírico sobre assuntos como Meta, Scale AI e investimentos em IA.
* Estilo visual e de voz idêntico aos personagens de desenhos animados.

---

**5. Vantagens**

* Totalmente **sem código (no-code)**.
* Pode ser adaptado para qualquer tema, personagem ou estilo.
* Pode escalar produção de vídeos curtos para redes sociais.

---

**6. Aplicações práticas**

* Criação de vídeos virais com foco em conteúdo de notícias.
* Criação de personagens com falas automatizadas para TikTok, Reels, Shorts.
* Base para criar uma agência de vídeos animados automáticos com IA.
