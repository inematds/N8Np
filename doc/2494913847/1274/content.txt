### **Automação com DeepSeek R1 no n8n e ****Make.com** 
A automação  permite integrar o modelo de IA **DeepSeek R1** com plataformas **n8n** e **Make.com**, possibilitando a criação de agentes inteligentes que buscam informações na internet, processam dados e enviam resumos automaticamente. 
 
--- 
 
## **1. Conceito da Automação** 
A automação tem dois objetivos principais: 
1. **Criar um agente de IA no n8n** que interage com usuários via Telegram e realiza tarefas como buscas na internet, criação de eventos e envio de e-mails. 
2. **Criar um fluxo de automação no ****Make.com** que coleta artigos de um feed RSS, processa o conteúdo e envia resumos para um e-mail automaticamente. 
 
--- 
 
## **2. Como Criar a Automação no n8n** 
O **n8n** é uma ferramenta de automação visual que permite conectar diferentes serviços sem precisar programar. 
 
### **Passo 1: Criar um Novo Fluxo no n8n** 
1. Acesse o **n8n** e crie um novo fluxo. 
2. Nomeie o fluxo como **"DeepSeek R1 Agent"**. 
 
### **Passo 2: Criar o Gatilho (Trigger)** 
1. Escolha **Telegram Bot** como o gatilho de entrada. 
2. Configure para ativar sempre que uma nova mensagem for recebida. 
 
### **Passo 3: Adicionar o DeepSeek R1** 
1. Adicione um nó **"AI Agent"** no fluxo. 
2. Configure para usar **OpenRouter** como intermediário para conectar ao DeepSeek R1. 
3. Crie uma credencial no OpenRouter: 
   - Acesse [OpenRouter](https://openrouter.ai/) e gere uma chave de API. 
   - No n8n, adicione a API Key e configure o **DeepSeek R1** como modelo de IA. 
 
### **Passo 4: Criar Funções no Agente de IA** 
Agora que o modelo está configurado, defina o que o agente pode fazer: 
1. **Buscar informações na internet** – Adicione uma API como **Google SERP** para permitir buscas em tempo real. 
2. **Gerenciar memória** – Use o **Window Buffer Memory** para armazenar contexto de conversas. 
3. **Criar eventos** – Integre com **Google Calendar** para adicionar compromissos automaticamente. 
4. **Enviar e-mails** – Conecte ao **Gmail API** para permitir que a IA envie e-mails com informações processadas. 
 
### **Passo 5: Testar o Agente** 
1. Envie uma mensagem para o bot no Telegram, como **"Qual a melhor cafeteria em São Paulo?"**. 
2. O agente buscará a informação, usará IA para processá-la e responderá. 
 
--- 
 
## **3. Como Criar a Automação no ****Make.com** 
O **Make.com** (antigo Integromat) permite automatizar processos e conectar serviços. 
 
### **Passo 1: Criar um Novo Fluxo** 
1. Acesse o **Make.com** e crie um novo cenário. 
2. Nomeie o fluxo como **"DeepSeek R1 Summarizer"**. 
 
### **Passo 2: Adicionar um Módulo RSS** 
1. Escolha **"Retrieve RSS Feed Items"**. 
2. Insira um feed RSS de notícias sobre IA, como **https://news.google.com/rss/search?q=OpenAI**. 
3. Defina quantos artigos buscar (exemplo: 5). 
 
### **Passo 3: Extrair o Texto dos Artigos** 
1. Adicione um módulo **"HTTP - Get a file"**. 
2. Use o URL do artigo para baixar seu conteúdo. 
3. Adicione o módulo **"HTML to Text"** para extrair o texto limpo do artigo. 
 
### **Passo 4: Resumir o Conteúdo com DeepSeek R1** 
1. Adicione um módulo **DeepSeek R1 (via OpenRouter ou API direta)**. 
2. Insira um **prompt** pedindo um resumo: 
   ``` 
   Você recebeu um artigo. Resuma em dois parágrafos e cinco tópicos principais com emojis. Seja objetivo e direto. 
   ``` 
3. O modelo de IA processará o artigo e retornará um resumo. 
 
### **Passo 5: Enviar o Resumo por E-mail** 
1. Adicione um módulo **"Gmail - Create Draft"** ou **"Send Email"**. 
2. Configure o destinatário (exemplo: seu próprio e-mail). 
3. No corpo do e-mail, insira o resumo gerado pelo DeepSeek R1. 
4. Teste a automação. 
 
--- 
 
## **4. Resultado Final** 
- No **n8n**, um bot no Telegram pode responder perguntas, buscar informações, criar eventos e enviar e-mails automaticamente. 
- No **Make.com**, artigos são coletados de feeds RSS, resumidos pela IA e enviados por e-mail, automatizando o consumo de informações. 
 
---
