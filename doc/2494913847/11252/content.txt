## 🚀 Hacks para o fluxo no n8n

### 1️⃣ **Reduzir custos com API**

* **Use “Pin Data” (Fixar dados)** nos nós do OpenAI e VEO3 FAST durante os testes.

  * Isso evita chamadas reais às APIs e economiza créditos.
  * Clique com o botão direito no nó → *Pin Data*.

---

### 2️⃣ **Processamento em lote**

* Em vez de processar **1 linha por vez** no Google Sheets, processe **várias linhas em paralelo**:

  * Altere o filtro no nó Google Sheets para buscar **todas as linhas “pending”**.
  * Use o nó **Split In Batches** para dividir em blocos menores (ex.: 3 vídeos por execução).
  * Configure o fluxo para rodar cada lote de forma paralela com o nó **Execute Workflow**.

---

### 3️⃣ **Velocidade com VEO3 FAST**

* O modelo **VEO3 FAST** é 60% mais barato e rápido, mas:

  * Reduza o **tempo no Wait Node** para **90 segundos** se os vídeos forem curtos (até 5s).
  * Use **parâmetro “enhance\_prompt” como false** para geração mais leve em testes.

---

### 4️⃣ **Prompts mais realistas**

* No OpenAI, adicione detalhes ao System Prompt para melhorar a qualidade visual:

  ```  You are a cinematic director. Create highly detailed prompts for macro shots in ASMR style, using vivid descriptions of light, texture, and atmosphere.
  ```
* Resultado: vídeos com mais textura e realismo.

---

### 5️⃣ A**utomação sem intervenção
**
* Use W**ebhook Trigger **no lugar do Schedule para ativar o fluxo ao adicionar uma nova linha no Google Sheets automaticamente (via Make ou Zapier).

---

### 6️⃣ M**onitoramento de erros
**
* Adicione o nó E**rror Trigger **no fluxo:

  * Envie uma notificação no Telegram ou e-mail se uma chamada API falhar.
  * Assim você não perde nenhuma geração.

---

### 7️⃣ R**euso de fluxos
**
* Separe o fluxo em 2:

  * W**orkflow 1:** Gera prompts e chama o VEO3 FAST.
  * W**orkflow 2:** Faz o pós-processamento e atualiza o Google Sheets.
* Chame o Workflow 2 com o nó E**xecute Workflow.**

---

### 8️⃣ C**riação de banco de vídeos
**
* Salve o link do vídeo gerado automaticamente no Google Drive ou S3 via n8n.
* Adicione tags ao vídeo (baseadas no conteúdo do prompt) para facilitar buscas futuras.

---

### 9️⃣ V**ariedade automática
**
* Adicione uma coluna no Google Sheets com uma lista de estilos artísticos (Cyberpunk, Pixar, Realismo) e alterne-os aleatoriamente com o nó S**et **no n8n.

---

### 10️⃣ C**riação em escala
**
* Rode múltiplas instâncias do fluxo com diferentes intervalos no Schedule Trigger (ex.: a cada 10 minutos).
* Assim você gera centenas de vídeos por dia sem sobrecarregar o sistema.

### 🎯 Objetivo

Gerar vídeos ASMR com IA totalmente no piloto automático e sem escrever código.

---

## 1️⃣ Preparação

* **Crie uma planilha no Google Sheets** com as colunas:

  * `substance` (ex.: fine gray powder)
  * `liquid` (ex.: glowing green liquid)
  * `reaction` (ex.: magical reaction)
  * `transformation` (ex.: grass and trees)
  * `art_style` (ex.: cyberpunk)
  * `status` (pending ou complete)
  * `output` (URL do vídeo gerado)

---

## 2️⃣ Fluxo no n8n (7 nós)

### 1. **Schedule Trigger**

* Adicione o nó **Schedule Trigger**.
* Configure para rodar 1x por dia ou conforme desejado.

---

### 2. **Google Sheets - Get Rows**

* Adicione o nó **Google Sheets**.
* Conecte sua conta Google (OAuth2).
* Configuração:

  * **Operation:** Get Rows
  * **Document:** selecione sua planilha
  * **Sheet:** ex.: Sheet1
  * **Filter:** `status` = `pending`
  * **Return Only First Matching Row:** ativado
* Este nó vai buscar apenas uma linha com status *pending*.

O vídeo apresenta um tutorial completo sobre como criar **vídeos ASMR com IA** de forma **automática** e **sem código**, usando o **VEO3 FAST** no n8n.

### Resumo Completo:

1. **Tendência dos vídeos ASMR com IA**

   * Esses vídeos estão viralizando e acumulam milhares de visualizações.
   * O nicho permite muitas ideias criativas.

2. **Demonstração inicial**

   * O criador mostra 3 vídeos ASMR gerados automaticamente como resultado do sistema.

3. **Sistema sem código**

   * Totalmente baseado em **drag-and-drop** no n8n.
   * Composto por **7 nós** principais.

4. **Passo a passo do fluxo**

   * **Trigger (Agendador)**: Define quando o fluxo será iniciado (ex.: 1x por dia).
   * **Google Sheets**: Contém as configurações (substâncias, líquidos, reações, estilos de arte, status e link do vídeo).
   * **OpenAI**: Gera os prompts para o vídeo com base nos dados do Google Sheets.
   * **HTTP Request (FAI)**: Envia o prompt para o modelo VEO3 FAST na plataforma FAI.
   * **Wait Node**: Aguarda o processamento (2 minutos padrão).
   * **HTTP Request (Get)**: Recupera o link do vídeo gerado.
   * **Google Sheets (Update)**: Atualiza a linha com o link do vídeo e muda o status de “pending” para “complete”.

5. **Uso do modelo VEO3 FAST**

   * 60% mais barato que o VEO3 original.
   * Geração de vídeos com áudio incluso e alta qualidade.

6. **Recursos adicionais**

   * Templates prontos para download.
   * Comunidade para suporte técnico e ajuda 1:1.
   * Curso de 6 meses para abrir uma agência de automação com IA.

7. **Dicas técnicas**

   * Fixar dados (pin) no n8n para evitar custos de testes.
   * Configurações detalhadas para autenticação nas APIs (OpenAI e FAI).

8. **Encerramento**

   * Incentivo para participar da comunidade e acessar outros templates gratuitos.
   * Convite para comentários e dúvidas no vídeo.
