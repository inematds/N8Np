**Resumo do vídeo: "This AI Agent INSTANTLY Pulls Real-Time Insights from X (Bolt + n8n Setup)"**

Como criou um agente de IA que coleta **insights em tempo real da rede X (antigo Twitter)**, sem usar scraping ou métodos manuais, combinando **Bolt.new****, n8n** e a **Live Search API do Grok**.

### Principais pontos:

* **Objetivo**: Extrair publicações ao vivo de contas específicas, analisar sentimento da comunidade, detectar memes em alta e identificar tendências.

* **Ferramentas usadas**:

  * **Bolt.new**: para a interface e acionamento do sistema.
  * **n8n**: para o fluxo de automação com webhook e integração da lógica.
  * **Supabase**: como base de dados e ponto de escuta (edge functions).
  * **Live Search API (Grok)**: para consultar postagens públicas em tempo real.
  * **Anthropic Claude 3.5 Sonnet**: para gerar análises e respostas com base nos dados.

* **Fluxo do sistema**:

  1. Usuário envia pergunta pela interface.
  2. Bolt envia os dados ao Supabase.
  3. Supabase aciona o webhook do n8n.
  4. O n8n processa a consulta, usa a API do Grok, aplica prompt no Claude e retorna a resposta.
  5. Bolt exibe a análise com citações clicáveis.

* **Exemplos de uso**:

  * Analisar sentimento sobre o modelo **Google Gemini Veo3**.
  * Ver opiniões de tech leaders como Elon Musk e Greg Brockman sobre **AGI**.
  * Buscar **notícias emergentes** ou **memes populares** no X.

* **Prompt personalizado (Pulse Agent)**:

  * Detecta metadados enviados (como "breaking news", "memes", etc.).
  * Redireciona o fluxo para as ferramentas certas com base na categoria da pergunta.
  * Inclui regras rigorosas para evitar respostas genéricas ou vagas.

* **Desafios técnicos resolvidos**:

  * **CORS delay**: o autor precisou configurar Bolt para aguardar mais tempo pela resposta do n8n.
  * **Importação de cURL**: usou Perplexity para obter comandos cURL prontos, facilitando a configuração da API no n8n.





### Conclusão:

Com este agente, é possível criar uma aplicação que acompanha o **sentimento em tempo real de comunidades no X**, detecta tendências, e gera respostas contextualizadas com **citações diretas** das postagens — tudo isso com **automação no-code**, pronto para ser replicado.
