Aqui está o **passo a passo completo** para criar um **Assistente de Investimentos com IA automatizado** usando **OpenAI, Supabase, FMP API, Google Drive e n8n**, sem codificação.

---

### 1. **Pré-requisitos**

Você precisará ter contas ativas nas seguintes plataformas:

* [OpenAI](https://platform.openai.com/)
* [Supabase](https://supabase.com/)
* [Google Cloud Console](https://console.cloud.google.com/)
* [FMP – Financial Modeling Prep](https://financialmodelingprep.com/)
* [n8n](https://n8n.io/)

---

### 2. **Configurar Supabase (armazenamento vetorial)**

1. Crie um projeto no Supabase.
2. Vá em `Project Settings > API` e copie:

   * `URL do projeto`
   * `Service Role Secret`
3. Vá até o `SQL Editor` e cole o seguinte código (para ativar o banco vetorial):

   ```   -- Criação da estrutura para armazenar embeddings
   CREATE TABLE documents (
     id uuid PRIMARY KEY DEFAULT gen_random_uuid(),
     content text,
     embedding vector(1536), -- ajuste conforme o modelo usado
     metadata jsonb
   );
   ```
4. Confirme a execução.

---

### 3. **Configurar FMP API (dados financeiros em tempo real)**

1. Acesse [https://financialmodelingprep.com/](https://financialmodelingprep.com/)
2. Crie uma conta e copie sua chave de API.
3. Guarde para uso posterior no n8n.

---

### 4. **Configurar Google Drive (armazenamento dos relatórios PDF)**

1. Acesse o [Google Cloud Console](https://console.cloud.google.com/)
2. Crie um novo projeto.
3. Ative a API do Google Drive.
4. Vá em **Credenciais** e crie um **OAuth Client ID**:

   * Tipo: **Web Application**
   * Adicione o redirect URI do n8n: `https://n8n.io/oauth2/callback`
5. Copie:

   * `Client ID`
   * `Client Secret`

---

### 5. **Configurar n8n (criação dos fluxos)**

#### A. **Fluxo 1: Armazenar relatórios no Supabase**

**Objetivo**: Detectar novo PDF, extrair texto, gerar embeddings e salvar no banco vetorial.

1. **Google Drive Trigger** – detectar novo arquivo PDF.
2. **Google Drive > Download File** – baixar o PDF.
3. **PDF Extractor** – extrair texto do conteúdo.
4. **OpenAI Embedding** – gerar vetores com o modelo `text-embedding-3-small`.
5. **HTTP Request para Supabase** – salvar conteúdo + embedding no banco vetorial.

#### B. **Fluxo 2: Consultar dados (RAG Chatbot)**

**Objetivo**: Receber pergunta do usuário, buscar resposta no Supabase e/ou FMP.

1. **Webhook (Telegram ou chat Web)** – entrada da pergunta.
2. **OpenAI Function Call**:

   * Detectar se a consulta exige dados atuais ou estáticos (ex: PE Ratio = FMP API).
3. **Se for consulta estática (ex: receita passada):**

   * Buscar dados na base vetorial do Supabase com embeddings semelhantes.
4. **Se for dados atuais:**

   * Consultar a API FMP com ticker (KO, TSLA, etc.) e retornar dados como PE ratio, market cap etc.
5. **Responder com texto completo usando OpenAI GPT-4 Turbo.**

---

### 6. **Melhorias opcionais**

* Adicione **memória conversacional** usando o `Memory Buffer` do n8n para contextos longos.
* Integre com Telegram, WhatsApp, webchat ou e-mail.
* Adicione um painel no **Retool** ou **WeWeb** para visualizar perguntas/respostas.

---

### 7. **Exemplo prático**

* **PDF no Drive**: Relatório financeiro da Coca-Cola Q3 2024.
* **Usuário pergunta**: "Qual a receita da Coca-Cola no terceiro trimestre de 2024?"
* **Resposta**: Gerada com base no embedding do relatório armazenado no Supabase.

---

Se quiser, posso gerar os blocos prontos do n8n ou criar o JSON com os nós. Deseja?

**Resumo do conteúdo – Assistente de Investimentos com IA automatizado usando RAG, OpenAI, n8n e Supabase**

Este projeto ensina como criar um assistente de investimentos inteligente que analisa dados financeiros e responde perguntas com base em relatórios e APIs de mercado, de forma totalmente automatizada e sem precisar programar.

**Principais etapas e componentes:**

1. **Ferramentas utilizadas**:

   * OpenAI (para embeddings e geração de respostas)
   * Supabase (armazenamento vetorial e interface SQL)
   * FMP API (Financial Modeling Prep – dados financeiros em tempo real)
   * Google Drive (armazenamento de relatórios PDF)
   * n8n (para orquestrar todos os fluxos sem código)

2. **Fluxo de funcionamento básico**:

   * Usuário envia um PDF de relatório financeiro (ex: Coca-Cola Q3 2024) para o Google Drive.
   * O sistema detecta o novo arquivo, extrai o texto, gera embeddings via OpenAI e armazena no Supabase.
   * Quando o usuário faz uma pergunta (ex: "Qual a receita da Coca-Cola em Q3 2024?"), o sistema consulta o banco vetorial e responde com precisão.
   * Se a pergunta envolver dados em tempo real (ex: PE Ratio atual), a resposta é complementada com informações da API FMP.

3. **Dois fluxos principais no n8n**:

   * Armazenamento de relatórios PDF no banco vetorial (Subbase).
   * Consulta de informações: o agente determina se a fonte deve ser o banco vetorial ou a API em tempo real.

4. **Diferenciais do Supabase vs Pinecone**:

   * Supabase permite SQL direto e tem interface rica.
   * Pinecone é mais otimizado para grandes volumes e busca por similaridade.

5. **Configuração técnica**:

   * Credenciais necessárias: chave da API do FMP, client ID/secret do Google Drive, chave secreta do Supabase.
   * Banco vetorial é ativado com SQL específico colado no editor do Supabase.
   * Modelos de embedding usados: `text-embedding-3-small`.

6. **Versão avançada**:

   * Integra memória conversacional para lembrar perguntas anteriores.
   * Usa prompts como: "Você é um assistente financeiro. Encontre o código da empresa e retorne os dados solicitados".
   * Junta informações da base vetorial + dados em tempo real da API FMP para entregar uma resposta completa.

**Exemplos de uso:**

* "Qual foi a receita da Coca-Cola em Q3 2024?" → resposta vem do PDF embutido no Supabase.
* "Qual o PE Ratio atual da Coca-Cola?" → resposta é buscada na API FMP em tempo real.
