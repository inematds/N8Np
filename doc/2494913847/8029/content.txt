**Resumo da Automação de Backup para N8N no Google Drive**

**Objetivo:**
Manter backups automáticos e atualizados de todos os fluxos (workflows) do N8N, evitando perda de dados por falhas, atualizações incorretas ou exclusões acidentais.

**Funcionamento:**

* Obtém todos os workflows via API do N8N.
* Verifica no Google Drive se já existe um arquivo com o mesmo nome.

  * Se existir → atualiza.
  * Se não existir → cria novo arquivo.
* Converte os workflows em arquivos `.json`.
* Salva na pasta "Backup Automatizações N8N" no Google Drive.
* Executa automaticamente todos os dias ao meio-dia com um Schedule Trigger.

**Estrutura técnica:**

* **Módulo N8N:** Conexão com o servidor via API Key e URL.
* **Loop:** Itera sobre todos os workflows.
* **Google Drive:**

  * Busca por nome de arquivo na pasta de backup.
  * Usa um switch para decidir entre atualização ou criação.
  * Salva cada fluxo como arquivo separado (.json).

**Testes realizados:**

* Com 5 workflows → todos criados com sucesso.
* Com 10 workflows → 5 atualizados, 5 novos.
* Com 70+ workflows → todos salvos corretamente.

**Importação e restauração:**

* Os arquivos `.json` podem ser importados diretamente no N8N.
* Mostra como restaurar fluxos a partir do Google Drive.

**Recomendações:**

* Indispensável para quem usa N8N em servidor próprio.
* Útil também em ambientes na nuvem.
* Previne sustos e perda de trabalho.

**Recurso disponível:**
Blueprint da automação pronto para uso.
