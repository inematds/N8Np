**Resumo do vídeo: "How I Use This AI TOOL to Build a Motion Graphics AI System with n8n (No Code!)"**

O vídeo mostra como criar um sistema completo de **geração de vídeos animados (motion graphics)** com IA e **n8n**, sem necessidade de programação, usando ferramentas como Perplexity, CoinMarketCap e a API do **Vibecut**. A automação transforma dados ou comandos simples em vídeos animados prontos para uso.

**Resumo por tópicos com exemplos:**

1. **Objetivo do Projeto**

   * Criar vídeos animados automaticamente com IA e n8n, sem usar After Effects.
   * Geração inclui: gráficos de linha, pizza, barras, textos animados e mapas com zoom.
   * Comunicação com IA feita via bot do Telegram.

2. **Casos de Uso Demonstrados**

   * Animação de notícia sobre FTX (texto com título e fonte).
   * Vídeo com gráfico de pizza mostrando as 5 criptomoedas com maior market share.
   * Gráfico de linha com preços de BTC e ETH entre 2021 e 2023.
   * Gráfico de barras com preços de Solana e Ethereum em 2021-2022.
   * Animação de mapa com zoom sobre a China.

3. **Ferramentas Usadas**

   * **n8n**: Plataforma no-code para montar o fluxo de automação.
   * **Vibecut (FCut)**: Geração dos vídeos animados via API.
   * **Perplexity**: Pesquisa automatizada de notícias atualizadas.
   * **CoinMarketCap**: Obtenção de preços de criptomoedas.
   * **Telegram Bot**: Interface para interagir com o sistema.

4. **Como Funciona o Fluxo**

   * O usuário envia uma mensagem para o bot no Telegram (ex: “criar gráfico de pizza com criptos”).
   * Um agente de IA interpreta e processa a instrução.
   * O sistema busca os dados (via Perplexity ou CoinMarketCap).
   * Os dados são enviados à API do Vibecut para gerar o vídeo.
   * O vídeo pronto é baixado e enviado ao usuário no Telegram.

5. **Templates Disponíveis via Vibecut**

   * Texto animado
   * Gráfico de pizza
   * Gráfico de barras
   * Gráfico de linhas
   * Mapa com zoom

6. **Destaques Técnicos**

   * Uso de autenticação via tokens nas APIs.
   * Reutilização de templates com parâmetros customizáveis.
   * Armazenamento e controle de contexto via Redis (para histórico e continuidade).
   * Verificação do status de renderização e envio automático ao usuário.

**Conclusão:**
Combinando **IA + n8n + Vibecut**, é possível transformar dados em vídeos animados com qualidade profissional sem escrever código. Ideal para criadores de conteúdo, agências ou plataformas de informação automatizada.
