**Hacks para o caso de notícias (GNews + OpenAI + Creatomate)**

* Use sempre **palavras-chave específicas** no GNews (ex.: `"inteligência artificial" OR "AI"`), isso melhora a relevância e evita gastar créditos com notícias irrelevantes.
* No prompt da OpenAI Image, adicione **“sem texto”** e **descrição de estilo** (realista, vibrante, minimalista) para evitar imagens poluídas.
* Configure **fallback de imagem**: se a geração falhar, use uma imagem padrão hospedada no ImageKit/ImgBB para não quebrar o fluxo.
* No GPT-5 Mini para título/caption, peça **saída em formato JSON** para separar facilmente os campos no n8n.
* Programe o loop de checagem no Creatomate com **intervalos progressivos** (5s, 10s, 15s…) para evitar sobrecarga de requisições.
* Se for postar em várias redes, **mande o vídeo primeiro para o Make** e de lá replique para todas as plataformas — economiza requisições no n8n.

---

**Hacks para o caso imobiliário (Formulário + ImgBB + Creatomate)**

* Ao invés de 4 campos separados para imagens, use **upload múltiplo** no formulário e depois divida no n8n, isso agiliza o envio.
* Otimize as imagens no upload para **resolução e peso compatíveis** com redes sociais (ex.: 1080px de largura) antes de passar para o Creatomate — ImageKit pode fazer isso via URL.
* Crie **placeholders de foto** no template (foto padrão de fachada, planta, logo da imobiliária) para casos de campos vazios.
* Inclua no template campos para **logo, cor da marca e contato**, assim todos os vídeos saem padronizados sem esforço extra.
* No caption, insira **variáveis automáticas** (ex.: preço, bairro) para aumentar a relevância na rede social sem digitar nada manualmente.

---

**Hacks gerais para ambos os fluxos**

* Use **múltiplas credenciais de Creatomate** (uma por template) para não confundir variáveis e tokens.
* Organize todos os endpoints e tokens no n8n usando **credenciais genéricas** para facilitar manutenção e evitar expor dados.
* Crie um **modo de teste**: antes de publicar, envie o vídeo para um canal privado no Telegram/Drive para revisão.
* Aproveite o **modo gratuito** do Creatomate para prototipar e só passar para o pago quando o fluxo estiver 100% estável.
* Documente no próprio n8n cada nó com **nota explicativa** para lembrar o que ele faz (útil se precisar ajustar no futuro).

Aqui vai um passo a passo objetivo para montar os dois fluxos de vídeo no n8n + Creatomate + Make, usando GNews, OpenAI, ImageKit/ImgBB.

Passo a passo – Caso 1: vídeos de notícias de IA

1. Preparar contas e chaves
   • Criar contas e pegar chaves: GNews (token/apikey), OpenAI (GPT-5 Mini + imagem), Creatomate (API key), ImageKit ou ImgBB (chave), Make (webhook).
   • Guarde cada credencial em credenciais seguras no n8n (HTTP Request, Generic Credential).

2. Criar o template no Creatomate
   • No Creatomate, escolha um template social (9:16) ou landscape (16:9) e nomeie os campos que pretende preencher: ex. ImageURL, Title.
   • Copie o cURL/JSON de “API Integration” (vai mostrar template\_id e as chaves de modifications).

3. Montar o gatilho no n8n
   • Use um Manual Trigger (ou Scheduler).
   • Crie um Set (ou Input Fields) com: lang, query, gnews\_token/apikey, news\_count (ex.: 4).

4. Buscar notícias na GNews
   • HTTP Request (GET) → endpoint de busca. Exemplo (confirme qual parâmetro seu plano usa):
   • Variante comum: [https://gnews.io/api/v4/search?q={{\$json.query}}\&lang={{\$json.lang}}\&max={{\$json.news\_count}}\&apikey=GNEWS\_API\_KEY](https://gnews.io/api/v4/search?q={{$json.query}}&lang={{$json.lang}}&max={{$json.news_count}}&apikey=GNEWS_API_KEY)
   • Algumas libs usam token=GNEWS\_TOKEN
   • A resposta vem com articles\[]. Faça um Item Lists → Split Out por articles.

5. Preparar contexto por item
   • Em cada artigo, use um Set para guardar title, description, url, content (quando houver) e repassar ao restante do fluxo.

6. Gerar a imagem da capa
   • OpenAI Image (ou HTTP p/ imagens): prompt curto e direto. Exemplo:
   “Crie uma miniatura de notícia sobre ‘{{\$json.title}}’. A imagem deve refletir o tema principal descrito em ‘{{\$json.description}}’. Estilo chamativo, composição clara, sem texto.”
   • Se o nó retorna binário, converta para Base64 (Binary → Move/Convert) antes do upload, se necessário.

7. Subir a imagem para URL pública
   • Opção A – ImageKit (upload via Basic Auth):
   Endpoint: POST [https://upload.imagekit.io/api/v1/files/upload](https://upload.imagekit.io/api/v1/files/upload)
   Body (form-data): file=BASE64\_DA\_IMAGEM, fileName=news.jpg
   Auth: Basic com PRIVATE\_API\_KEY como usuário.
   • Opção B – ImgBB:
   POST [https://api.imgbb.com/1/upload?key=IMGBB\_KEY](https://api.imgbb.com/1/upload?key=IMGBB_KEY)
   form-data: image=@binário\_ou\_base64
   • Guarde a URL pública retornada (display\_url/url).

8. Escrever título e caption com GPT-5 Mini
   • OpenAI Chat (model: gpt-5-mini). Prompt sugerido:
   “Gere:

   1. título jornalístico curto (até 80 caracteres) em português para o vídeo;
   2. caption para redes (3–4 linhas, informativo, sem hashtags).
      Use como base: título, descrição e conteúdo da notícia a seguir: …”
      • Extraia dois campos: title\_final e caption\_final.

9. Renderizar o vídeo no Creatomate
   • HTTP Request (POST) → [https://api.creatomate.com/v1/renders](https://api.creatomate.com/v1/renders)
   Headers: Authorization: Bearer YOUR\_CREATOMATE\_API\_KEY
   Body (JSON):
   {
   "template\_id": "SEU\_TEMPLATE\_ID",
   "modifications": {
   "ImageURL": "URL\_PUBLICA\_IMAGEM",
   "Title": "{{\$json.title\_final}}"
   }
   }
   • O retorno vem com id e status=pending/planning.

10. Checar status em loop
    • Wait 5s → HTTP Request (GET) [https://api.creatomate.com/v1/renders/RENDER\_ID](https://api.creatomate.com/v1/renders/RENDER_ID)
    • Se status != succeeded, volte ao Wait; se succeeded, capture o result\_url.

11. Enviar para o Make e publicar
    • HTTP Request (POST) → webhook do Make com { video\_url: result\_url, caption: caption\_final }.
    • No Make, poste no Instagram/LinkedIn/etc. (módulo da plataforma).
    • No n8n, o loop avança para a próxima notícia até completar news\_count.

e38. Automatize vídeos para redes em minutos

🎯 Objetivo
Aprender a montar um sistema completo para gerar vídeos automáticos a partir de notícias ou formulários, utilizando modelos pré-desenhados e ferramentas de IA. Essa automação permite publicar conteúdo visual nas redes sociais sem intervenção manual, economizando tempo e esforço. São abordados dois casos de uso: notícias sobre IA e setor imobiliário, ambos com resultados 100% automatizados.

🛠️ O que conseguimos com essa automação?

* Criar vídeos automaticamente a partir de um modelo.
* Gerar conteúdo atualizado com notícias de inteligência artificial.
* Publicar imóveis em formato de vídeo a partir de um simples formulário.
* Usar IA para criar imagens e textos atraentes para redes.
* Publicar automaticamente os vídeos no Instagram ou em outras plataformas.
* Reduzir ao mínimo o esforço manual na produção de conteúdo recorrente.

🧩 Estrutura do fluxo automatizado

**Caso 1: Vídeos de notícias de IA**

* Disparo manual no N8N com campos configuráveis: idioma, token e número de notícias.
* Consulta à API do GNews para obter títulos e descrições.
* Geração de imagem com Image 1 (OpenAI) para cada notícia.
* Upload das imagens para domínio público (ImageKit ou IMGBB).
* Geração de texto com GPT-5 Mini: título para o vídeo e legenda para redes.
* Criação do vídeo no Creatomate usando um modelo personalizado.
* Verificação de status e download do vídeo.
* Envio do vídeo e da legenda para o Make, que publica no Instagram.

**Caso 2: Vídeos imobiliários a partir de formulário**

* Recebimento de dados de um formulário externo (endereço, preço, descrição, 4 imagens).
* Upload das imagens para o IMGBB e obtenção de URLs públicas.
* Montagem do vídeo no Creatomate usando modelo do tipo “Real Estate”.
* Verificação do status do vídeo e envio final para o Make.
* Publicação automática nas redes com legenda personalizada.

🧰 Ferramentas utilizadas

* N8N: motor principal da automação.
* Creatomate: plataforma de criação de vídeos com modelos.
* OpenAI (GPT-5 Mini + DALL·E): para gerar textos e imagens.
* GNews API: fonte de notícias para alimentar os vídeos.
* ImageKit / IMGBB: hospedagem de imagens em URL pública.
* Make: para publicação final do vídeo no Instagram ou outras redes.

🧠 Dicas-chave aprendidas

* Aproveitar modelos visuais no Creatomate para acelerar a produção sem perder qualidade.
* Separar tokens e credenciais por projeto ou modelo para evitar erros.
* Sempre trabalhar com URLs públicas para arquivos multimídia quando automatizar com APIs externas.
* Limitar a resolução nos testes gratuitos do Creatomate, mas considerar o pagamento se for escalar.
* Estruturar os fluxos com loops controlados e verificações de status antes de seguir para o próximo passo.
* Ideal para setores como agências, imobiliárias, e-commerce, educação ou fitness.

**Recursos**

* Blueprint
* GNews
* Creatomate
* IMGBB
* ImageKit
