# **Agente de Vendas no WhatsApp (Stripe + Fatura)**   
 
## **Introdução**   
Nesta aula, desenvolvemos um assistente de vendas automatizado que interage com clientes via WhatsApp, gera links de pagamento com Stripe e envia faturas automaticamente após a confirmação do pagamento. Implementamos essa automação no **N8N**, demonstrando como estruturá-la de forma eficiente e comparando com o **Make**. Também abordamos as vantagens e desvantagens de cada plataforma, ajudando a tomar decisões estratégicas para o negócio.   
 
--- 
 
## **Objetivo**   
Criar um fluxo de automação que:   
 
✅ Receba e processe consultas de clientes via WhatsApp.   
✅ Gere links de pagamento pelo Stripe.   
✅ Envie faturas automaticamente após a confirmação do pagamento.   
✅ Mantenha um histórico de interações com cada cliente para um acompanhamento eficaz.   
✅ Personalize as respostas de acordo com os produtos e serviços da empresa.   
 
--- 
 
## **1. Configuração do Assistente no N8N**   
 
### **1.1. Captura de Mensagens no WhatsApp**🔹 Configuração de um **gatilho (trigger)** para receber mensagens no WhatsApp.   🔹 Uso de um **switch** para diferenciar mensagens de texto e áudios.   
🔹 Transcrição automática de áudios usando **OpenAI Whisper**.   🔹 Armazenamento do histórico de conversas para referência futura.   
 ### **1.2. Configuração do Agente de Inteligência Artificial**🔹 Utilização do **GPT-4o Mini** para processar consultas dos clientes.   
🔹 Definição de um **prompt estratégico**, que:      - Responde dúvidas sobre serviços.   
   - Coleta as informações necessárias para processar a compra.      - Usa memória para lembrar dados informados anteriormente.   
   - Personaliza respostas com base no histórico de compras do cliente.    
### **1.3. Geração do Link de Pagamento no Stripe**🔹 Estruturação de um fluxo no **N8N** para:      - Criar um cliente no Stripe.   
   - Gerar um preço de produto e um link de pagamento via **requisição HTTP à API do Stripe**.      - Incorporar metadados com identificadores únicos para vincular a compra à fatura.   
   - Validar as informações do cliente antes de concluir o pagamento.    
### **1.4. Armazenamento da Compra no Google Sheets**🔹 Utilização do **Google Sheets** para registrar transações, com mapeamento das colunas para:      - **Nome do cliente**   
   - **Endereço**      - **CNPJ/CPF**   
   - **Produtos adquiridos**      - **Preço unitário e total**   
   - **Status do pagamento**   
   - **Data da compra e método de pagamento**    
---  
## **2. Geração e Envio da Fatura no Make**    
### **2.1. Configuração do Webhook do Stripe**🔹 Configuração de um **watch event** no **Make** para detectar pagamentos confirmados.   🔹 Extração do **identificador do pedido** dos metadados do Stripe.   
🔹 Busca das informações do cliente e compra no **Google Sheets**.   🔹 Configuração de alertas para possíveis erros na transação.   
 ### **2.2. Criação da Fatura**🔹 Geração de uma **fatura automática** usando um modelo no **Google Docs**.   
🔹 Preenchimento automático dos campos com:      - Dados do cliente.   
   - Produtos adquiridos.      - Informações de pagamento.   
🔹 Geração do documento final em **PDF**.   🔹 Armazenamento da fatura no **Google Drive** para controle documental.   
 ### **2.3. Envio da Fatura por WhatsApp**🔹 Upload do **PDF** na API do **WhatsApp (Meta)**.   
🔹 Envio da fatura diretamente para o cliente via WhatsApp.   🔹 Inclusão de uma mensagem de **confirmação de pagamento** para uma melhor experiência do usuário.   
 ### **2.4. Atualização do Status no Google Sheets**🔹 Atualização da base de dados com:   
   - Status da transação para **"Fatura Enviada"**.      - Link para download da fatura.   
   - Registro da **data e hora do envio** para auditoria.   
🔹 Marcação da transação como **concluída**, evitando duplicações.
