Passo a Passo

### 1. **Pré-requisitos**

* Conta no **n8n** (cloud ou local)
* Conta no **Airtable** com uma base criada
* Workflow com agente (ex: ChatGPT Agent)

---

### 2. **Criar Tabela no Airtable**

Crie uma base chamada `Registro e Gastos` com a tabela `Projetos` contendo os seguintes campos:

* `Data e Hora`
* `Input`
* `Output`
* `Mensagem de Erro`
* `Ações`
* `Tokens`
* `Custo Total`
* `Nome da Automação`
* `Subagente` (opcional)

---

### 3. **No n8n, configure seu agente**

* Use o nó **ChatGPT Agent (ou outro agente)**
* Vá em **Options > Return Intermediate Steps = TRUE**

---

### 4. **Adicionar módulo de código (Function Node)**

* Adicione um nó **Function** após a execução do agente
* Use `JSON.stringify` para transformar os dados:

```return [{
  json: {
    input: $json["input"],
    output: $json["output"],
    error: $json["error"] || null,
    actions: JSON.stringify($json["intermediateSteps"], null, 2),
    tokens: $json["tokenUsage"]?.totalTokens || 0,
    custo: $json["tokenUsage"]?.totalCost || 0,
    nomeAutomacao: $workflow.name,
    dataHora: new Date().toLocaleString("pt-BR"),
  }
}];```

---

### 5. **Adicionar módulo Airtable (Create Record)**

* Configure o módulo **Airtable > Create Record**
* Selecione a base `Registro e Gastos`
* Mapeie os campos do Function Node:

| Airtable          | n8n (Function Output) |
| ----------------- | --------------------- |
| Data e Hora       | `dataHora`            |
| Input             | `input`               |
| Output            | `output`              |
| Mensagem de Erro  | `error`               |
| Ações             | `actions`             |
| Tokens            | `tokens`              |
| Custo Total       | `custo`               |
| Nome da Automação | `nomeAutomacao`       |

---

### 6. **Tratamento de erros**

* No nó do agente, ative a opção **Continue on Fail = TRUE**
* Crie uma rota de erro (via conexão inferior do nó) e duplique o Function + Create Record
* No Function de erro, use `output = "Erro"` e registre `mensagem de erro` do agente

---

### 7. **Testar fluxo**

* Execute o agente com uma pergunta
* Verifique os dados sendo salvos no Airtable
* Simule erro para testar o caminho de erro

---

### 8. **Visualizações no Airtable**

Crie “views” para análise:

* Por Data
* Por Agente/Subagente
* Por Maior Gasto
* Por Ocorrência de Erros

---

Sistema completo para rastrear gastos e ações de agentes de IA com Airtable**

**Objetivo principal:**
Criar um sistema de rastreamento que registre automaticamente cada interação de um agente de IA, incluindo: input, output, erros, ações executadas, tokens consumidos e custo por execução — tudo salvo no **Airtable** (ou Google Sheets).

---

**Componentes e Etapas do Sistema:**

1. **Módulos essenciais configurados no agente (n8n):**

   * Ativação da opção **Return Intermediate Steps**.
   * Captura de input/output, erros, ferramentas utilizadas, tokens e custo.

2. **Transformação dos dados:**

   * Uso de `JSON.stringify` para transformar logs em texto estruturado.
   * Criação de campos como: nome do projeto, data/hora, input, output, erros, ações, tokens, custo e nome da automação.

3. **Envio para Airtable:**

   * Mapeamento dos campos em um módulo “Create a Record”.
   * Criação de visualizações por data, agente, subagente e custos.

---

**Exemplos práticos demonstrados:**

* Execução de agente simples com:

  * Busca de contato
  * Criação de evento no calendário
  * Criação de rascunho de e-mail
* Execução de superagente com subagentes (ex: Gmail, Google Calendar)

  * Separação dos registros de gastos e erros por subagente
  * Registro automático mesmo quando há erro (ex: modelo indisponível)

---

**Casos úteis:**

* Controle de gastos em projetos com IA
* Prova de entregas para clientes
* Diagnóstico de erros recorrentes
* Otimização de uso de tokens e ferramentas
* Visualizações personalizadas por data, automação ou agente

---

**Conclusão:**

* Ferramenta essencial para quem trabalha com automações e agentes de IA.
* Fácil de replicar, personalizável e poderosa para quem quer transparência e controle.
* Código e estrutura fornecidos prontos para copiar e colar.
* Pode ser integrado com Telegram, WhatsApp, Instagram e outros canais.

---

**Resumo visual:**

* **Ferramentas:** n8n + Airtable
* **Uso:** Logs de IA, análise de gastos, controle de subagentes
* **Público-alvo:** Freelancers, agências, equipes que prestam serviços com IA

💸 21. Controle os gastos dos seus agentes de IA

Aprendemos a implementar um sistema que registra cada interação do seu agente de inteligência artificial, incluindo o input, o output, as ações realizadas, os tokens consumidos e o custo total. Tudo isso é armazenado em uma base visual como o Airtable (ou Google Sheets) para analisar gastos, detectar erros e entender como os agentes se comportam.

🧩 O que configuramos?

* 4 módulos principais que extraem informações de cada execução
* Um código personalizado que transforma os logs em um formato legível
* Uma tabela no Airtable que registra:

  * Data e hora
  * Input do usuário
  * Output do agente
  * Mensagens de erro (se houver)
  * Ações executadas
  * Tokens consumidos
  * Custo total
  * Nome da automação

⚙️ Requisitos técnicos

* Ativamos a opção “Return Intermediate Steps” no módulo do agente para registrar as ações intermediárias
* Utilizamos a função `JSON.stringify` para transformar os logs em texto legível e organizado
* Configuramos o módulo “Create a Record” no Airtable, mapeando cada campo relevante

📊 Exemplos ao vivo

* Um agente é executado para:

  * Buscar um contato
  * Criar um evento no calendário
  * Criar um rascunho de e-mail
* Todas as ações e custos são automaticamente registrados no Airtable
* Testes com erros também são realizados: se o modelo estiver indisponível, o sistema detecta e registra como erro sem parar a automação
* Os mesmos módulos são aplicados a um superagente com subagentes (como Gmail e Google Calendar), permitindo o rastreamento separado de gastos e erros por subagente

🔎 Visualização de dados
Podem ser geradas visualizações por:

* Agente
* Data
* Custo
* Subagente
  Isso permite, por exemplo, ver qual agente consome mais, qual dia tem mais atividade ou quanto custa cada processo

💡 Aplicações práticas

* Ideal para uso próprio ou como valor agregado para clientes
* Permite detectar gastos excessivos, erros recorrentes ou comportamentos inesperados do agente
* Muito útil para demonstrar com dados reais o valor entregue pela IA


🧠 Conclusão
Este sistema é essencial para quem deseja trabalhar com agentes de IA de forma profissional. Oferece transparência, controle e melhoria contínua. É fácil de replicar, visualmente poderoso e aplicável a qualquer canal: Telegram, WhatsApp, Instagram, entre outros.
