Entenda QUALQUER documento com Mistral OCR no n8n (passo a passo)"**

Como configurar o **Mistral OCR** dentro do **n8n** para automatizar a leitura de textos de documentos (como PDFs e imagens escaneadas), **sem precisar programar**.

### Etapas principais do tutorial:

1. **Apresentação do Mistral OCR**  
   Mostra resultados impressionantes do OCR, incluindo reconhecimento de tabelas, fórmulas matemáticas e até outros idiomas (como hindi), com boa precisão.

2. **Configuração inicial:**
   - Criar uma conta no Mistral OCR.
   - Ativar o plano gratuito (requer apenas verificação por telefone).
   - Gerar uma chave de API.

3. **Configuração no n8n:**
   - Criar um formulário no n8n para que o usuário possa enviar documentos (PDFs, faturas, recibos etc.).
   - Ao enviar o arquivo, o fluxo executa 3 passos automáticos:
     - **Upload do arquivo para o Mistral OCR.**
     - **Solicitação de uma URL assinada do documento.**
     - **Envio dessa URL para o endpoint OCR e obtenção do texto.**

4. **Importação simplificada com cURL:**
   - O vídeo ensina como importar comandos `curl` direto para o n8n, facilitando a configuração dos nós HTTP sem codificação.

5. **Autenticação simplificada:**
   - Demonstra como criar uma autenticação genérica no n8n, salvando o token para evitar repetir em cada requisição.

6. **Pós-processamento dos dados extraídos:**
   - Com os dados em texto, é possível:
     - Enviar para planilhas do Google.
     - Usar IA (como Gemini ou outros modelos) para extrair informações específicas, como número da fatura, datas etc.
     - Automatizar envio por e-mail ou arquivamento em sistemas.

7. **Dicas finais:**
   - Problemas comuns (ex: erro inicial se a chave ainda estiver "esquentando").
   - Recomenda o uso do nó "Extract Information" com IA para buscar dados específicos.
   - Avisa que o workflow está disponível para download gratuito na comunidade “Free School Community”.

---

### Exemplos citados:
- Fatura escaneada processada corretamente.
- Extração de "invoice number", "tracking number" e outros dados estruturados.
- Uso de IA para extrair campos mesmo quando a estrutura do documento muda.

---

### Conclusão:
Com o **n8n + Mistral OCR**, você consegue montar **um fluxo automatizado de leitura de documentos**, ideal para empresas que lidam com grandes volumes de faturas, contratos, recibos, ou documentos difíceis de ler. Tudo isso com **zero código** e usando **IA para estruturar os dados extraídos**.
