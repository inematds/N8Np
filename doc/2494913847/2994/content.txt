---

## **🔧 Ferramentas e Serviços Necessários**
Antes de começar, você precisará configurar algumas ferramentas:

1. **n8n** – Plataforma de automação  
   - Acesse: [https://n8n.io](https://n8n.io/)  
   - Pode ser usado na nuvem (n8n.cloud) ou instalado localmente.  
   
2. **Planilhas Google** – Para armazenar ideias de vídeos  
   - Crie uma planilha com colunas: **Título, Status, Link do vídeo**  
   
3. **Flux (via Pi API)** – Para gerar imagens com IA  
   - Acesse: [https://piapi.xyz](https://piapi.xyz/)  
   - Crie uma conta e obtenha a **chave da API**  

4. **Runway ML** – Para transformar imagens em vídeos  
   - Acesse: [https://runwayml.com](https://runwayml.com/)  
   - Crie uma conta e gere sua **API Key**  

5. **11 Labs** – Para gerar áudio para os vídeos  
   - Acesse: [https://elevenlabs.io](https://elevenlabs.io/)  
   - Cadastre-se e obtenha a **API Key**  

6. **Creatomate** – Para unir vídeo e áudio e renderizar o arquivo final  
   - Acesse: [https://creatomate.com](https://creatomate.com/)  
   - Crie uma conta gratuita e gere sua **API Key**  

7. **YouTube Data API** – Para publicar vídeos automaticamente  
   - Vá para: [https://console.cloud.google.com](https://console.cloud.google.com/)  
   - Crie um projeto, ative a **YouTube Data API v3** e gere uma **chave de API**  

---

## **🚀 Passo a Passo para Configurar o Projeto**

| Cyberpunk Futurista    | A fazer |              |

> **Obs:** O fluxo de trabalho buscará sempre a **primeira linha com status "A fazer"** para processar.

---

### **2️⃣ Criar o Fluxo de Automação no n8n**
Agora, vamos criar um fluxo no **n8n** para conectar todos os serviços.

1. **📌 Criar um novo fluxo no n8n**
   - Acesse o n8n e crie um novo fluxo de trabalho.

2. **📄 Adicionar um nó de "Google Sheets"**
   - Configurar **conexão com o Google Sheets**.
   - Configurar para buscar a **primeira linha com Status = "A fazer"**.

3. **🤖 Criar um nó de "Geração de Imagem com IA (Flux via Pi API)"**
   - Enviar a descrição do vídeo para a API **Flux**.
   - Receber **URLs das imagens** geradas.

4. **🎥 Criar um nó de "Geração de Vídeo com Runway"**
   - Enviar **as imagens** para a API **Runway**.
   - Receber **URLs dos vídeos curtos**.

5. **🎵 Criar um nó de "Geração de Áudio com 11 Labs"**
   - Enviar **o estilo do vídeo** para gerar um áudio correspondente.
   - Receber **URL do arquivo de áudio**.

6. **🔄 Criar um nó de "Upload no Google Drive"**
   - Enviar o **áudio gerado** para o Drive.
   - **Compartilhar o link publicamente**.

7. **🖼️ Criar um nó de "Edição Final no Creatomate"**
   - Unir **os vídeos curtos e o áudio**.
   - Renderizar o **vídeo final**.

8. **📤 Criar um nó de "Upload no YouTube"**
   - Enviar o vídeo final para o YouTube.
   - Definir **título, descrição e privacidade (não listado).**

9. **📊 Atualizar a Planilha do Google**
   - Mudar o status para **"Processado"**.
   - Adicionar o **link do vídeo publicado**.

10. **📩 Enviar notificação por e-mail**
   - Enviar um e-mail avisando que o **Short foi publicado**.

### **Resumo do Fluxo de Trabalho**

1. **Planilha do Google** → Obtém ideias para vídeos

3. **Conversão de imagens para vídeos** → Utiliza **Runway** para criar vídeos animados  
4. **Geração de áudio** → **11 Labs** cria efeitos sonoros de acordo com o estilo do vídeo  
5. **Upload no Google Drive** → Para armazenar os arquivos de áudio  
6. **Renderização do vídeo final** → Utiliza **Creatomate** para combinar vídeo e áudio  
7. **Upload automático no YouTube** → O vídeo é enviado para o canal e listado como **não listado**  
8. **Atualização da planilha** → Registra o status do vídeo e adiciona o link final  
9. **Notificação por e-mail** → Informa que um novo short foi criado e está pronto para revisão  

---

### **Oportunidades de Melhoria**
- **Aprimorar os prompts** para gerar imagens mais precisas  
- **Aumentar a duração dos vídeos** (atualmente são 20 segundos)  
- **Gerar ideias de vídeos automaticamente** para preencher a planilha do Google  
- **Testar modelos alternativos** para geração de imagens e vídeos  

### **Custo por Vídeo**
- **Geração de imagens**: **~$0,06**  
- **Geração de vídeos**: **~$1,00**  
- **Geração de áudio (11 Labs)**: **Incluso no plano de $5/mês**  
- **Creatomate**: **Plano gratuito cobre boa parte dos usos**

Depois que os prompts são limpos (removendo quebras de linha e pontuações desnecessárias), os enviamos para a API de **texto para imagem**. A geração das imagens leva cerca de **90 segundos**.  

Assim que as imagens são geradas, elas são alimentadas em um **gerador de vídeo a partir de imagens**. O processo de conversão leva mais **2 minutos**.  

**(01:59)** Agora que as imagens foram processadas, passamos para o nó seguinte, que cria os vídeos a partir delas.  

Enquanto isso, vamos dar uma olhada nos vídeos finalizados:  

- **Vikings conquistadores de animais**  
- **Cowboys do Velho Oeste**  

Cada vídeo tem um **áudio diferente**, que foi gerado com **11 Labs** com base no estilo do vídeo.  

Agora, voltamos ao fluxo para verificar o progresso. O sistema está baixando os vídeos finalizados e gerando o áudio correspondente.  

O áudio está sendo criado pela **11 Labs** e será adicionado ao vídeo. Em seguida, o arquivo é enviado ao **Google Drive** e compartilhado publicamente.  

Depois disso, combinamos tudo e renderizamos o vídeo final com o serviço **Creatomate**. O tempo de renderização é de **25 segundos**.
