**j12. Raspagem de Emails Grátis a partir do Google Maps**

✅ **Objetivo**  
Criar uma automação gratuita e em larga escala que, a partir do Google Maps, extraia os sites de negócios locais, escaneie essas páginas para encontrar e-mails, limpe e organize os dados, e envie tudo por e-mail.

🧩 **Estrutura do cenário no N8N**

1. **Formulário de entrada**  
   O usuário informa:
   - Tipo de negócio  
   - Bairro/localização  
   - E-mail de contato  

   O formulário gera termos de busca combinando tipo de negócio + bairro + cidade.

2. **Bloco 1: Geração dos termos de busca**  
   A partir das variáveis fornecidas, são geradas URLs no formato:

   `[tipo_de_negócio]+[bairro]+[cidade]`

   Cria-se uma lista com múltiplas combinações no formato JSON.

3. **Bloco 2: Extração dos sites no Google Maps**  
   - É feita uma requisição HTTP ao Google Maps.  
   - O HTML é obtido e filtrado com JavaScript usando regex para capturar apenas os links dos sites.  
   - São eliminadas URLs irrelevantes como google.com, schema.org, whatsapp etc.  
   - Os resultados duplicados são removidos com o nó "Remove Duplicates".

4. **Bloco 3: Raspagem dos e-mails nas páginas**  
   - Um loop percorre cada site individualmente.  
   - Faz-se o scraping do HTML de cada site e aplica-se regex para extrair e-mails.  
   - São filtrados e-mails genéricos ou inúteis como centri, wixpress, qdqmedia etc.  
   - Todos os e-mails são reunidos, divididos (se houver mais de um por site), e os duplicados removidos.

5. **Bloco 4: Exportação e envio**  
   - Os e-mails são exportados para uma planilha no Google Sheets.  
   - A planilha é baixada como um arquivo .csv.  
   - O arquivo .csv é anexado e enviado ao e-mail informado no formulário.  
   - Após o envio, as linhas da planilha são apagadas para prepará-la para a próxima execução.

📊 **Resultados**  
Teste com 10 bairros para “advogados em Barcelona”:

- Início: 896 resultados no Google Maps  
- Após filtro: 266 sites válidos  
- Raspagem: 433 e-mails encontrados  
- Após limpeza: 134 e-mails únicos  
- Arquivo .csv enviado corretamente ao usuário
