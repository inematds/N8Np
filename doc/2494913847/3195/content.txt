### e7n8. Extraia informações de arquivos sem complicações  

Nesta sessão, exploramos a maneira mais eficiente e econômica de extrair informações de arquivos como **PDFs, imagens e documentos em diversos formatos**. Utilizamos um cenário de **faturamento** para demonstrar como automatizar o processo de extração e armazenamento de dados com **N8N e Llama Cloud**.  

---

### **Processo de Extração**  

#### **1. Recebimento de Arquivos**  
📌 Uma **fatura** é enviada para um **bot do Telegram**.  
📌 A automação detecta o tipo de arquivo (**imagem ou PDF**).  

#### **2. Processamento do Arquivo**  
📌 O arquivo é enviado para uma **API do Llama Cloud**.  
📌 Ele é carregado na API para processamento.  
📌 A automação acompanha o status da extração até receber a confirmação da conclusão.  

#### **3. Transformação e Estruturação dos Dados**  
📌 Os dados extraídos são convertidos para **Markdown**.  
📌 Em seguida, são transformados em um **JSON** com os seguintes campos:  
   - Número da fatura  
   - Data de emissão  
   - **CIF/NIF**  
   - Subtotal  
   - IVA  
   - **Valor total**  
📌 Um modelo da **OpenAI** formata os dados extraídos corretamente.  

#### **4. Armazenamento e Visualização**  
📌 O arquivo original é **salvo no Google Drive**.  
📌 As informações estruturadas são **armazenadas no Google Sheets**.  
📌 Um **mensagem de confirmação** com os dados extraídos é enviada via **Telegram**.  

---

### **Otimizações na Automação**  

✅ **Uso de um Switch no N8N** → Diferencia documentos e imagens para seguir fluxos específicos.  
✅ **Merge de File ID** → Unifica o tratamento dos arquivos, independente do formato.  
✅ **Espera dinâmica** → Um loop monitora o status da API até que os dados estejam prontos.  
✅ **Seleção automática da melhor qualidade de imagem** → Sempre usa a versão de **maior qualidade** das fotos enviadas ao Telegram.  
✅ **Aproveitamento da versão gratuita do Llama Cloud** → Permite extrair informações de **até 3.333 páginas/mês sem custo**.  

---

### **Conclusão**  

Com essa abordagem, conseguimos **otimizar a extração de dados de faturas e documentos**, **sem precisar converter formatos ou realizar processos custosos**. Esse método reduz **tempo, esforço e custo**, proporcionando um fluxo de trabalho **mais eficiente e escalável**.  

---

### **Recursos**  
🔗 **Llama Cloud AI**  
🔗 **Blueprint Faturamento**
