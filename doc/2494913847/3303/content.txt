**Alternativa gratuita e poderosa ao SerpAPI para buscas na web – com a capacidade de restringir a um ou mais sites**

Tenho testado o SerpAPI, e ele é ótimo, mas, para mim, ainda não há necessidade da versão paga, e a versão gratuita oferece apenas 100 consultas por mês. No entanto, existe uma alternativa.

O próprio **Google Programmable Search Engine (CSE)** oferece uma API de busca com **100 consultas gratuitas por dia**.

Além disso, você pode criar mecanismos de busca específicos para diferentes sites. Por exemplo, criei um mecanismo para buscas gerais na web e outro restrito exclusivamente ao meu site.

Estou achando esse último especialmente útil, pois me permite adicionar uma opção de pesquisa na web ao chatbot que estou desenvolvendo para os visitantes do meu site. Por exemplo, tenho uma base de conhecimento vetorial para perguntas aprofundadas, mas, se alguém perguntar *"quais serviços você oferece"*, posso direcionar a solicitação para o mecanismo de busca, permitindo que ele responda com base no conteúdo do meu site (sem a necessidade de manter dados no back-end).

### Como configurar:
Para configurar isso, você precisa ter uma conta do Google (acredito que uma conta gratuita funcione). Em seguida:

1. **Obtenha uma chave de API gratuita**:  
   👉 [Google Custom Search API](https://developers.google.com/custom-search/v1/introduction)

2. **Configure um ou mais mecanismos de busca e recupere o ID do Engine**:  
   👉 [Google Programmable Search Engine](https://programmablesearchengine.google.com/controlpanel/all)  

   **Importante:** Ao usar a chave da API, **não** é necessário configurar credenciais OAuth.

### Limite de buscas
Todos os mecanismos de busca utilizam a mesma chave de API, então **o limite diário de buscas gratuitas é por chave de API, não por mecanismo de busca individual**.

### Exemplo de requisição HTTP (JSON Workflow)
O fluxo de trabalho JSON anexado é apenas uma **requisição HTTP** no seguinte formato:

```https://customsearch.googleapis.com/customsearch/v1?key={key}&cx={engine}&q={query}```

Defini {`key},` {`engine} `e {`query} `como v**ariáveis dinâmicas **na ferramenta HTTP, onde o valor de {`query} `é preenchido dinamicamente com:

{```{ $json["parameters"]["type"] }}
```
Isso permite que a consulta seja passada automaticamente a partir do Agente de IA.
