MENSAGEM 7
Autor: INEMA
Data: 2025-05-27T22:24:49+00:00
Texto:
"How to INSTANTLY Build An AI Agent Army in n8n with Claude"**

O vídeo ensina como criar uma "tropa de agentes de IA" no **n8n** usando **Claude 4 Opus**, a partir de **um único prompt**, sem escrever código manualmente. O processo envolve criação automática de agentes mestres e subagentes, todos com ferramentas conectadas e operacionais via arquivos JSON.

### Principais tópicos abordados:

1. **Objetivo do vídeo:**

   * Mostrar como criar rapidamente sistemas complexos de agentes IA no n8n usando Claude 4 Opus.
   * Todo o processo pode ser feito com apenas **um prompt** e concluído em minutos.

2. **Estrutura dos agentes:**

   * **Agente mestre (orquestrador):** Coordena a rede.
   * **Subagentes:** Cada um com funções específicas e ferramentas conectadas.
   * Todos os agentes são criados automaticamente com estruturas JSON prontos para importar no n8n.

3. **Duas formas de criar os agentes:**

   * Usando um projeto Claude com arquivos JSON.
   * Usando apenas uma conversa direta com Claude + prompt completo.

4. **Uso de web search e extended thinking:**

   * Claude pode buscar informações adicionais na web e refletir antes de gerar os fluxos.
   * Evita erros e melhora a escolha das ferramentas reais.

5. **Prompt detalhado:**

   * Instruções claras sobre como estruturar os agentes.
   * Dividido em duas etapas:

     1. Criar ideias de agentes com nomes e funções.
     2. Criar 3 agentes com ferramentas reais, evitando ferramentas fictícias (hallucinations).
   * Os arquivos devem ser válidos e importáveis no n8n sem erros de propriedades.

6. **Cheat code com arquivo `agents_tools.json`:**

   * Contém uma base com múltiplas ferramentas válidas conectadas a um agente.
   * Serve como exemplo para Claude entender como montar os fluxos corretamente com ferramentas populares (ClickUp, Monday, Slack, Zoom, Airtable etc.).

7. **Exemplos práticos de negócios:**

   * **Flexiflow Studios:** Agência de TikTok com agentes como coordenador de equipe, handler de solicitações, etc.
   * **Pet Pal Concierge:** Uber para pets, com agentes de emergência, gestão de prestadores e agendamento.
   * **Chaos Coffee Co.:** Cafeterias, com agentes de controle de qualidade, inovação de receitas, coordenação e finanças.

8. **Importância da estrutura e conectividade:**

   * Cada agente vem com instruções e ferramentas reais (Zoom, Slack, Monday, Airtable, ClickUp, etc.).
   * As conexões (success/error) precisam estar corretamente configuradas para o agente funcionar.

9. **Recomendações:**

   * Criar apenas 3 agentes de início, para evitar desperdício de créditos e verificar se o sistema funciona.
   * Adicionar o business case no fim do prompt (estratégia de prompt engineering) para garantir que Claude o priorize.

10. **Objetivo final:**

    * Reduzir o tempo de criação de automações no n8n.
    * Ir de 0% a 80% de um sistema funcional com mínimo esforço.
    * Estimular brainstorming e acelerar o desenvolvimento de sistemas com IA.

---

### Exemplos de prompts e ações:

* **Prompt inicial:** define Claude como um arquiteto especialista em workflows n8n.
* **Entrada:** descrição do negócio + ferramentas utilizadas.
* **Saída:** JSON com agentes mestre e subordinados prontos para importar no n8n.
