Resumo por tópicos – Vídeo "Contratação da VPS Hetzner":

1. **O que é a Hetzner VPS**

   * Serviço de aluguel de servidor virtual (VPS) que funciona 24h por dia.
   * Indicado para quem precisa de um servidor estável e com bom desempenho.
   * Site: hetzner.com

2. **Motivo da escolha pela Hetzner**

   * Melhor performance entre os testados pelo autor.
   * Não apresentou problemas até o momento.

3. **Processo de contratação**

   * Acesse o site da Hetzner, clique em “Cloud”.
   * Crie um projeto, dê um nome e inicie a criação do servidor.
   * Cadastro exige cartão de crédito e documento (pode exigir verificação manual pelo suporte).
   * Cobrança ocorre ao final do período, não é imediata.

4. **Escolha da configuração**

   * Servidor da Alemanha (Falkenstein) com sistema Ubuntu 22.04.
   * Arquitetura ARM64 com 4GB de RAM (upgrade possível).
   * Escolha do tipo “Shared vCPU”.

5. **Acesso ao servidor via terminal**

   * Usar o aplicativo **Termius** (term. com).
   * Permite acessar a VPS por SSH de forma prática.
   * Cadastrar o host com IP, username e senha obtidos da VPS.
   * Resetar senha caso necessário para obter novo acesso.

6. **Importância do fingerprint**

   * Salvar o fingerprint ao conectar pela primeira vez.
   * Pode ser necessário para futuras conexões seguras.

7. **Instalação de painel de configuração**

   * Utilização do script criado pelo canal **Orion Design** (oriondesign.art.br).
   * Código colado no Termius usando `Ctrl + Shift + V`.

8. **Painel de instalação automatizado**

   * Compatível com Ubuntu 22.04 (não recomendado o 24.04).
   * Exibe painel com diversas opções de softwares.
   * Uso de comandos P1 e P2 para navegação entre páginas.

9. **Softwares recomendados para instalação**

   * Traefik
   * Ptain
   * Evolution API
   * n8n
   * Supabase

10. **Conclusão**

* VPS pronta para uso e instalação dos sistemas.
* Próximos vídeos tratarão das instalações.
* Convite para participar da comunidade e rede de apoio.
