Os **hacks** (dicas e truques avançados) mostrados no vídeo para usar **Google Gemini + n8n** de forma gratuita e eficiente para análise de vídeos são:

---

### 1. **Uso de Polling para Garantir Confiabilidade**

* **Hack:** Esperar 5 segundos e fazer nova requisição para verificar se o vídeo foi processado.
* **Por quê?** Se não esperar, o Gemini pode retornar erro porque o vídeo ainda está "processing".
* **Aplicação:** Evita falhas, garante que o retorno da análise seja válido.

---

### 2. **Prompt Personalizado na Requisição**

* **Hack:** Você pode **moldar o comportamento do Gemini** dizendo exatamente o que ele deve fazer com o vídeo.
* **Exemplos:**

  * "Descreva o vídeo em detalhes"
  * "Resuma em 3 frases"
  * "Extraia os principais aprendizados"
  * "Liste insights visuais e falas importantes"
* **Benefício:** Controle total sobre o tipo de análise que o Gemini vai retornar.

---

### 3. **Análise de Vídeos do YouTube sem Download**

* **Hack:** Em vez de baixar o vídeo, Gemini aceita diretamente a URL do YouTube.
* **Vantagem:** Mais rápido, sem ocupar armazenamento, nem necessidade de upload local.

---

### 4. **Reaproveitamento de API Key com Query Params**

* **Hack:** Usa a autenticação via **query parameter**, com chave `key` no endpoint.
* **Motivo:** Evita necessidade de configuração complexa de headers ou OAuth.

---

### 5. **Uso de Template JSON no n8n**

* **Hack:** Autor fornece um **template pronto** para importar o fluxo completo no n8n.
* **Como usar:** Baixar JSON, importar no n8n e só mudar a chave da API.

---

### 6. **Extração de Dados Binários com Precisão**

* **Hack técnico:** Nomear o campo binário como `video` exatamente igual ao que Gemini espera.
* **Erro comum evitado:** Nomes errados nos campos causam falhas silenciosas.

---

### 7. **Uso de "Set Node" para Visualizar Resultados Limpos**

* **Hack:** Após receber a resposta, use um **"Set" node** para limpar e formatar o resultado.
* **Vantagem:** Facilita a leitura e uso posterior do texto analisado.

---

Segue o **passo a passo completo** para configurar uma automação no **n8n** usando o **Google Gemini** para análise de vídeos gratuitamente:

---

### 1. **Obter a API Key do Google Gemini**

* Acesse: [https://ai.google.dev](https://ai.google.dev/)
* Clique em **"Get API Key"**
* Copie a chave para usar no n8n

---

### 2. **Importar o Template JSON no n8n**

* Baixe o template JSON fornecido no vídeo (ou crie manualmente)
* No n8n, vá em **Importar workflow**
* Carregue o arquivo `.json` do fluxo completo

---

### 3. **Configurar o Formulário Inicial (Upload Local)**

* Crie um formulário com um campo para **upload de vídeo**
* Ao enviar, o vídeo será salvo como **binary data**

---

### 4. **Enviar o Vídeo para o Google Gemini**

* Crie um **HTTP Request Node**
* Método: `POST`
* URL do endpoint Gemini de upload de vídeo
* Autenticação:

  * Tipo: **Generic Auth**
  * Forma: **Query**
  * Nome: `key`
  * Valor: sua API Key Gemini
* Headers:

  * `Content-Type`: `application/json`
  * `Content-Length`: automático
* Enviar o vídeo como **arquivo binário** com o nome do campo: `video`

---

### 5. **Aguardar o Processamento (Polling)**

* Adicione um **"Wait" node** com 5 segundos
* Em seguida, um novo **HTTP Request** para verificar o status

  * Endpoint de status da análise
  * Envie o `URI` retornado anteriormente no corpo da requisição
  * Inclua novamente a API Key no formato de query
* Verifique o campo `status == completed`

---

### 6. **Obter o Resultado da Análise**

* Quando `status == completed`, o Gemini retornará o **texto com a análise completa do vídeo**
* Use um **"Set" node** para exibir o conteúdo de forma limpa

---

### 7. **Analisar um Vídeo do YouTube (Alternativa)**

* Use outro **HTTP Request Node**
* Endpoint de Gemini para análise de **YouTube URL**
* Corpo da requisição:

  ```  {
    "video": {
      "youtube_url": "https://www.youtube.com/watch?v=XXXX"
    },
    "prompt": "Please summarize this video in 3 sentences"
  }
  ```
* Adapte o prompt conforme desejar: resumos longos, insights, destaques, etc.

---

### 8. **Executar e Visualizar o Resultado**

* Use um **Manual Trigger**
* Clique em **"Test Workflow"**
* Resultado será retornado em texto com a descrição ou resumo do vídeo

---

### 9. **Dicas Finais**

* Sempre use polling com vídeos locais (aguarde o processamento antes de buscar resultado)
* O Gemini pode analisar **elementos visuais** e **transcrição** dos vídeos
* Pode ser usado para vídeos curtos ou longos

Aqui está o resumo completo e estruturado  **"The Simplest Setup for FREE AI Video Analysis (n8n + Google Gemini)"**:

### Visão Geral

Como configurar uma automação com **n8n** e **Google Gemini** para analisar vídeos gratuitamente, usando arquivos locais ou URLs do YouTube — sem necessidade de código.

---

### Passo a Passo Explicado

1. **Envio do Vídeo**

   * O usuário seleciona um arquivo `.mp4` local e envia por um formulário.
   * O n8n envia o arquivo ao Google Gemini via requisição HTTP com autenticação via query parameter (`API key`).

2. **Processo de Análise**

   * Gemini retorna um URI do vídeo e um status `processing`.
   * O sistema faz *polling* (verificação em intervalos) para saber quando a análise estiver concluída.

3. **Exemplo de Resultado**

   * Análise descritiva de um vídeo com latas e garrafas de bebidas (Coca-Cola, Red Bull, Gatorade e Monster) transformadas em edifícios fictícios.

4. **Manuseio de Erros**

   * Mostra como o processo falha se não houver espera suficiente para o processamento do vídeo.
   * Após alguns segundos, o processo pode ser reexecutado com sucesso.

5. **Análise de Vídeo do YouTube**

   * Também é possível usar uma URL do YouTube.
   * Novo endpoint da API Gemini é usado para aceitar a URL e retornar um resumo em até 3 frases.
   * Exemplo analisado: vídeo do canal Outdoor Boys com descrição detalhada da cena e do conteúdo.

6. **Customização dos Prompts**

   * Gemini pode ser instruído para:

     * Resumir o vídeo.
     * Descrever o conteúdo visual.
     * Extrair conclusões principais.
     * Identificar ferramentas ou tecnologias citadas no vídeo.

---

### Recursos Disponíveis

* Template JSON gratuito com o fluxo de trabalho pode ser baixado da comunidade do autor.
* A API Key do Gemini é obtida em: [Google AI for Developers](https://ai.google.dev/).
* Cursos e comunidade pagos para aprofundamento:

  * **Agent Zero**: fundamentos de IA e automação.
  * **10 horas para 10 segundos**: foco em identificar, projetar e criar automações que economizam tempo.

---

### Conclusão

A integração entre **n8n** e **Google Gemini** permite análises de vídeo altamente detalhadas, com flexibilidade para personalizar prompts e sem custo. A automação cobre desde o upload até o retorno do resultado — inclusive para vídeos do YouTube — com exemplos práticos e repetição segura por *polling*.
