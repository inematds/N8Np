Como instalar o n8n Docker e o Kokoro Docker localmente
Baixe o Docker em: https://www.docker.com/

Instale > Abra o aplicativo Docker na Área de Trabalho

Crie uma rede para conectar os dois containers do Docker:
Computador Apple: Command+Espaço > Procure por Terminal > Digite e execute:

```docker network create my-network

```
Depois, execute o seguinte comando para configurar o servidor Kokoro associado à rede:

```docker run -d --name fastapi-app --network my-network -p 8880:8880 ghcr.io/remsky/kokoro-fastapi-cpu:latest

```
Em seguida, execute o seguinte comando para configurar o servidor n8n associado à rede:

```docker run -d --name n8n-app \
  --network my-network \
  -p 5678:5678 \
  -e WEBHOOK_URL=https://externally-helped-hippo.ngrok-free.app \
  n8nio/n8n:1.88.0

```
Atenção: Substitua "https://externally-helped-hippo.ngrok-free.app" pela sua própria URL do ngrok.

Como instalar o FFmpeg no seu Docker (Para renderizar vídeos sem usar a API andynocode)
No Docker > Container > Copie o ID do container (que aparece abaixo do nome do container) e cole-o no comando abaixo, substituindo a parte {{container id}}.

Exemplo de ID:
e2b38713d607627c6aa25a4ef61ddfee1630256e0a6c58ca75e2f23d7e2998aa

Substitua {{container id}} pelo ID correto no seguinte comando:

```docker exec -it -u root {{container id}} apk add --update python3 py3-pip gcc python3-dev musl-dev curl ffmpeg

```
Exemplo preenchido:

```docker exec -it -u root e2b38713d607627c6aa25a4ef61ddfee1630256e0a6c58ca75e2f23d7e2998aa apk add --update python3 py3-pip gcc python3-dev musl-dev curl ffmpeg

```
Computador Apple: Command+Espaço > Procure por Terminal > Cole e execute o comando com o ID correto do container.

Substitua {{container id}} pelo ID correto no seguinte comando:

