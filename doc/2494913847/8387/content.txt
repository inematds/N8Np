**Resumo completo do vídeo “The Best RAG System On YouTube (Steal This!)”**

O criador apresenta o sistema RAG (Retrieval-Augmented Generation) mais completo que já demonstrou, utilizando:

* **n8n** para orquestração
* **Supabase/Postgres** para banco de dados e memória vetorial
* **Google Drive** como repositório de arquivos observados

### **Fluxo principal dividido em 3 partes**

1. **Agente RAG (amarelo)**

   * Agente que interage com o usuário via chat usando os dados armazenados.
   * Usa Supabase como base vetorial e Postgres para chat history.

2. **Criação de arquivos (verde)**

   * Observa a pasta “projects” no Google Drive.
   * Ao adicionar um arquivo:

     * Detecta o tipo (Google Doc, PDF, Slides, etc).
     * Converte para o formato de texto mais apropriado.
     * Extrai texto e metadados (ID, nome, data, tipo, extensão, versão etc.).
     * Armazena os vetores e metadados no Supabase.

3. **Atualização de arquivos (azul)**

   * Observa modificações nos arquivos da mesma pasta.
   * Ao detectar mudança:

     * Deleta os registros antigos no Supabase com base no `fileID`.
     * Atualiza a versão (V1, V2, V3...) automaticamente usando OpenAI.
     * Reinsere os dados atualizados no banco.

---

### **Exemplos e testes práticos feitos no vídeo**

* **Arquivo “project wheel”** foi:

  * Adicionado como Google Doc → convertido para texto → inserido como V1.
  * Modificado para “Project Butter” → atualizado como V2.
  * Modificado novamente (data alterada) → inserido como V3.

* **Conversas com o agente**:

  * Consulta de informações ("quais as funcionalidades do projeto?").
  * Respostas mostradas são provenientes do conteúdo processado e armazenado.

* **Controle de versões**:

  * Versionamento automático com incremento usando OpenAI.
  * Tratamento especial para tipos de dado (strings vs. números).

* **Processamento de outros formatos**:

  * PDF inserido com mesmo processo e rotas específicas no fluxo.
  * O router do n8n identifica tipo e executa o parser correto.

---

### **Próximos passos sugeridos**

* **Deleção automática de arquivos excluídos no Drive**:

  * Fluxo 1: pega todos os `fileIDs` do Supabase.
  * Fluxo 2: pega todos os `fileIDs` atuais do Drive.
  * Comparação: identifica quais foram deletados.
  * Remove entradas órfãs no Supabase.

---

### **Exemplos de metadados armazenados**

* `fileID`
* `createdAt`
* `modifiedAt`
* `version`
* `fileType`
* `fileExtension`
* `folderPath`
* `fileName`

---


### **Resumo final com pontos chave**

* Sistema RAG 100% automático usando **n8n**, **Supabase** e **Google Drive**.
* Conversas são armazenadas e podem ser consultadas historicamente.
* Atualizações de arquivos são versionadas e substituídas corretamente.
* Há lógica clara para diferentes formatos de arquivo.
* Futuras melhorias incluem limpeza automática do banco para arquivos excluídos.
