No **AI Builder do n8n**, a escolha das palavras faz diferença no que o assistente vai montar. O vídeo mostrou alguns “truques” de vocabulário que garantem que ele crie os blocos certos. Aqui está um guia dos **termos corretos para instruir o assistente**:

---

## 1. Para criar agentes

* Use **“LangChain AI Agent”** em vez de apenas “AI Agent”
  → Isso força o Builder a usar a estrutura de agente com **ferramentas (tools)**, e não só um nó de modelo de linguagem.
* Exemplos:

  * “Build a **LangChain AI Agent** for customer support”
  * “Create a **LangChain AI multi-agent swarm** for content generation”

---

## 2. Para entrada de dados

* Use **“Form”** ou **“Form Node”** quando quiser capturar informações do usuário.
  → Se escrever “Webhook”, ele pode gerar captura via API em vez de formulário.
* Exemplos:

  * “Trigger with a **Form submission** including name, email, phone, company”
  * “Start workflow from a **Form Node** with predefined fields”

---

## 3. Para fontes externas

* Nomeie explicitamente as ferramentas que deseja integrar (ajuda o Builder a buscar o nó certo):

  * **Calendly** → “Calendly Trigger”
  * **Outlook** ou **Gmail** → “Outlook Email Node”, “Gmail Node”
  * **HubSpot** → “HubSpot Create Ticket”
  * **Slack** → “Slack Send Message”
  * **Perplexity** → “Perplexity Research Tool”

---

## 4. Para análise de dados

* Use expressões como **“analyze transcript”**, **“classify inquiry”**, **“score lead quality”**.
* Exemplos:

  * “Analyze Fireflies transcript and classify sales readiness”
  * “Score lead quality from 1 to 10 using OpenAI”

---

## 5. Para fluxos multiagente

* Use **“Master Agent”** ou **“Director Agent”** para o controlador principal.
* Use **“Sub-agent”** ou **“Research Agent”** para os auxiliares.
* Exemplos:

  * “Orchestrate a **Master Content Director Agent** with sub-agents for research and writing”

---

## 6. Para saídas

* Sempre diga **“Generate” + tipo de output**:

  * “Generate one blog post, five Twitter posts, and one LinkedIn post”
  * “Send an Outlook email with summary of the lead”

---

### Resumindo:

* Use **LangChain AI Agent** (e não só “AI Agent”).
* Prefira **Form Node** (quando for formulário) em vez de webhook.
* Cite **ferramentas específicas** (Outlook, HubSpot, Slack, etc.).
* Estruture ações com verbos fortes: **Trigger, Analyze, Classify, Generate**.
* Para multiagente: diferencie entre **Master Agent** e **Sub-agent**.

* Nome
* Sobrenome
* E-mail
* Telefone
* Nome da empresa
* O que está buscando

Esse formulário deve ser o ponto inicial que alimenta o resto do workflow."

### 4. Prompt para Agente LangChain Autônomo

"Crie um agente de IA com LangChain para atuar como um atendente autônomo de consultas de clientes.

O objetivo principal do agente é analisar a consulta e tomar a ação correta.

* Recuperação em base de conhecimento
* Criação de ticket de atendimento no HubSpot
* Envio de mensagem no Slack
* Envio de e-mail no Outlook para resposta direta ao cliente
* Ferramenta de pesquisa na web

Quando o formulário for enviado, o agente deve primeiro pesquisar a empresa online para entender o contexto.
Depois deve determinar se a consulta é de vendas, suporte ou parceria.
Para questões de suporte, deve usar a base de conhecimento para responder diretamente, enviar a mensagem no Slack e abrir um ticket de alta prioridade no HubSpot."

---

"Crie um swarm multiagente com LangChain para geração de conteúdo, disparado por um formulário com um único tópico de blog.
O workflow deve orquestrar um agente principal (diretor de conteúdo) equipado com quatro ferramentas.
O agente principal deve primeiro pesquisar na web os 10 melhores artigos sobre o tópico.
Depois deve acionar o agente de pesquisa para analisar esses artigos e criar um briefing abrangente.
Por fim, deve gerar:

* Um post de blog completo
* Cinco posts para Twitter
* Um post para LinkedIn."

## Hacks do vídeo

1. **Prompts claros e específicos**

   * Se você só escreve “criar um agente de IA”, o sistema pode gerar algo genérico.
   * Use palavras-chave específicas como **“LangChain AI Agent”** para forçar a estrutura correta (em vez de só “AI agent”).

2. **Iteração guiada**

   * Em vez de aceitar o fluxo inicial, refine pedindo ajustes:
     Ex.: trocar webhook por formulário com campos específicos (nome, e-mail, empresa, etc.).
   * O builder ajusta sem precisar recriar do zero.

3. **Uso de mock data**

   * Você pode pedir ao assistente do lado direito para **gerar dados JSON de teste**.
   * Isso permite testar o fluxo antes mesmo de conectar as credenciais reais.

4. **Explicação de cada nó**

   * O copiloto integrado explica **o que cada nó faz** (útil para iniciantes).
   * Você pode perguntar: “O que é este webhook?” ou “Como este parâmetro funciona?”.

5. **Extensão de fluxos com prompts vagos**

   * É possível pedir: “Adicione análise do Fireflies e, se o lead for ruim, coloque em sequência de nutrição”.
   * O sistema cria a extensão automaticamente, inclusive com rascunhos de e-mails.

6. **Agentes hierárquicos (master + subagents)**

   * Novo recurso permite que um **agente use outro agente como ferramenta**.
   * Exemplo: um agente diretor de conteúdo orquestrando agentes subordinados (pesquisa, escrita, posts sociais).

7. **Ajustes em tempo real no prompt**

   * Se você não gostar do texto de saída (ex.: e-mail gerado), basta pedir ao copiloto para **reescrever só aquele trecho**, sem refazer todo o fluxo.

8. **Redução de erros comuns**

   * O builder já conecta nós corretamente (sem “broken nodes” típicos de copiar/colar JSON).
   * Ele também insere **prompts default** dentro dos nós de IA, servindo como base para refinar.

Aqui está um resumo estruturado do vídeo sobre o novo **Construtor de IA Nativo da n8n**:

---

## Visão Geral

A n8n lançou o **AI Assistant Builder**, um recurso nativo que permite criar agentes e automações apenas com prompts em linguagem natural. A ideia é simplificar todo o processo de construção de workflows: sem copiar/colar JSONs, sem depender de servidores externos, e com fluxos prontos para serem ajustados em poucos minutos.

---

## Principais Recursos

1. **Criação instantânea de workflows**

   * Basta digitar ou ditar o que deseja automatizar.
   * O sistema gera um fluxo completo em segundos.

2. **Assistente explicativo (copiloto)**

   * Mostra cada etapa criada.
   * Explica a função de cada nó.
   * Ajuda iniciantes a entender conceitos básicos (ex: webhooks, parâmetros).

3. **Sugestões de prompts prontos**

   * Exemplos como processamento de notas fiscais, assistente de RAG, pipelines de dados etc.
   * Serve como guia para quem ainda não domina prompt engineering.

4. **Integração de múltiplas ferramentas**

   * Conecta automaticamente com Outlook, HubSpot, Slack, OpenAI, Perplexity, Fireflies, entre outros.
   * Basta adicionar credenciais para finalizar.

5. **Iteração rápida**

   * Permite refinar o workflow com novos prompts.
   * Pode corrigir ou estender fluxos já criados (ex.: incluir análise de reuniões do Fireflies ou sequências de e-mails).

---

## Exemplos Mostrados

1. **Qualificação de Leads**

   * Fluxo criado a partir de uma reserva no Calendly → pesquisa da empresa no Perplexity + OpenAI → análise de qualidade → envio de e-mail no Outlook → registro no GoHighLevel.

2. **Extensão com Fireflies**

   * Adiciona análise de transcrição de reuniões para definir se o lead deve ir para sequência de nutrição.
   * O agente gera prompts avançados automaticamente (ex.: avaliação BANT: Budget, Authority, Need, Timeline).

3. **Atendimento Autônomo de Clientes (LangChain)**

   * Criação de um agente com 5 ferramentas: base de conhecimento, criação de ticket no HubSpot, envio de e-mails, mensagens no Slack e pesquisa na web.
   * Workflow inicia por formulário no site.

4. **Swarm Multiagente de Conteúdo**

   * Um agente “diretor de conteúdo” coordena outros agentes subordinados.
   * Exemplo: pesquisa de artigos → geração de briefing → criação de post de blog + posts para redes sociais.

---

## Benefícios

* Criação **rápida**: fluxos funcionais em 20–30 minutos.
* **Menos barreiras**: não exige conhecimento técnico profundo.
* **Aprendizado guiado**: funciona como tutor e copiloto.
* **Flexibilidade**: do simples ao avançado, com agentes hierárquicos e múltiplas ferramentas.

---

## Pontos a Ajustar

* Ainda em **beta** (liberação gradual para usuários).
* Pode gerar erros de configuração (ex.: Gmail em vez de Outlook).
* Exige revisão de variáveis e preenchimento de credenciais.

---

## Conclusão

O **AI Assistant Builder** é um marco no n8n: transforma prompts diretamente em automações completas, com explicações, ajustes e extensões quase instantâneos. Serve tanto para iniciantes quanto para usuários avançados que querem acelerar o design de agentes e workflows complexos.
