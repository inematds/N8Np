## **🛠 1️⃣ Preparação do Ambiente**
**Antes de iniciar, escolha a infraestrutura para rodar o N8N**:
- **Opção Recomendada**: **Servidor Ubuntu na Nuvem (5€ por mês)**
- **Alternativa**: Windows Server 2022 (possíveis problemas com permissões)
  
### **🖥 Criando o Servidor na Nuvem**
- Escolha um provedor de hospedagem barato (ex: DigitalOcean, Linode, Vultr).
- Crie uma instância **Ubuntu 22.04** com no mínimo:
  - **2 CPUs**
  - **4 GB RAM**
  - **40 GB de SSD**
- Acesse o servidor via **SSH**.

---

## **🔧 2️⃣ Instalando o N8N**
No servidor, execute os seguintes comandos para instalar o N8N:

```# Atualizar pacotes
sudo apt update && sudo apt upgrade -y

# Instalar Node.js e npm
curl -fsSL https://deb.nodesource.com/setup_18.x | sudo -E bash -
sudo apt install -y nodejs

# Instalar e configurar N8N
npm install -g n8n

# Criar um usuário para rodar o N8N como serviço
sudo useradd -m -s /bin/bash n8n
sudo su - n8n

# Rodar o N8N
n8n```
Após isso, o **N8N estará rodando localmente na porta 5678**.

---

## **🌍 3️⃣ Configurando um Domínio e HTTPS**
Para acessar o N8N externamente, configure um domínio e um proxy reverso com **NGINX**:

1. Instale o NGINX:
   ```   sudo apt install nginx -y
   ```
2. Instale o Certbot para HTTPS:
   ```   sudo apt install certbot python3-certbot-nginx -y
   ```
3. Configure o NGINX com o domínio:
   ```   sudo nano /etc/nginx/sites-available/n8n
   ```
   **Adicione esta configuração:**
   ```   server {
       server_name seu-dominio.com;

       location / {
           proxy_pass http://localhost:5678;
           proxy_set_header Host $host;
           proxy_set_header X-Real-IP $remote_addr;
           proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
       }
   }
   ```
4. Ative e reinicie o NGINX:
    ```  sudo ln -s /etc/nginx/sites-available/n8n /etc/nginx/sites-enabled/
   sudo systemctl restart nginx
   
```5. Gere um certificado SSL gratuito:
    ```  sudo certbot --nginx -d seu-dominio.com
   
```
Agora, seu N**8N estará acessível via HTTPS **no domínio configurado.
