Resumo:

Como criar um agente de IA para transformar vídeos do YouTube em vídeos com seu próprio avatar de IA, utilizando Heygen, Deepseek AI e SearchAPI.io, sem necessidade de programação.

Passos e ferramentas:

1. Ferramentas usadas:
   - Heygen: Para criar o avatar e gerar o vídeo de IA.
   - Deepseek AI: Para gerar o novo roteiro a partir da transcrição do YouTube.
   - SearchAPI.io: Para extrair automaticamente a transcrição dos vídeos do YouTube.

2. Criação do Avatar:
   - Criar uma conta gratuita no Heygen.
   - Gravar de 2 a 5 minutos de vídeo pessoal para criar o avatar (boas condições de luz, câmera HD, olhar direto para a câmera, pausas entre frases).

3. Configuração das APIs:
   - Gerar chaves de API no Heygen, Deepseek e SearchAPI.io.
   - Configurar as credenciais no n8n para usar essas APIs.

4. Dois Workflows criados:
   - **Workflow 1**: 
     - Extrair a transcrição do YouTube usando SearchAPI.io.
     - Usar Deepseek AI para reescrever a transcrição como um novo roteiro curto, estilo "podcast intro".

   - **Workflow 2**:
     - Enviar o novo roteiro para Heygen.
     - Heygen gera o vídeo com o avatar usando o novo texto.
     - Esperar 5 minutos (ou mais) até a geração do vídeo.
     - Recuperar a URL do vídeo gerado.
     - Exportar todos os dados (ID, status, miniatura e link do vídeo) para o Google Sheets.

5. Configurações importantes:
   - Método POST para chamadas de criação de vídeo no Heygen.
   - Configurar o JSON corretamente para enviar as dimensões do vídeo.
   - Uso de lógica condicional para verificar se o vídeo foi gerado e, se não, esperar mais 5 minutos.

Resultado:

- O vídeo original de 4 minutos foi transformado em um novo vídeo de 21 segundos, com o próprio rosto e voz do usuário.
- Todo o processo de reaproveitamento do conteúdo do YouTube é automatizado.

---

Lista de tópicos com exemplos e respostas:

- Ferramentas usadas: Heygen, Deepseek AI, SearchAPI.io.
- Como criar avatar: Gravação de 2-5 min, seguindo orientações de iluminação e postura.
- APIs necessárias: Criar e configurar no n8n.
- Workflow 1 (Transcrição e Roteiro): Extrai a legenda e cria novo texto com Deepseek AI.
- Workflow 2 (Geração do vídeo): Envia o novo texto para Heygen, gera o vídeo, e salva dados no Google Sheets.
- Tempo de geração: Cada vídeo leva cerca de 5 minutos (pode precisar de tentativas se não concluir na primeira verificação).
- Resultado final: Novo vídeo com seu próprio avatar e voz, pronto para publicação.

Exemplo de resposta:

- "Consigo criar meus próprios vídeos de IA a partir de vídeos do YouTube em cerca de 10 minutos usando Heygen, Deepseek AI e SearchAPI.io."
