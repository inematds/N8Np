Etapa: Renderização com Creatmate

**Objetivo**: juntar 4 vídeos (de 5 segundos cada) e 4 áudios (também de 5s) em **um único vídeo final de 20 segundos**, com aspecto cinematográfico e pronto para redes sociais.


**Template usado**:


Ele fornece um **template chamado "Famous Brands"**.


Esse template no Creatmate é **pré-configurado com 4 blocos de vídeo + áudio de 5s cada**.




**Como usar no n8n**:

Crie uma conta no Creatmate e vá em **"Templates"**.


Clique em **"Source Editor"** e **cole o código-fonte** do template que ele disponibiliza (no PDF ou JSON).


Depois clique em **"Use Template" → "API Integration"**.


Copie o **Template ID**.




**Configuração da requisição HTTP no n8n**:



**Método**: POST


**Endpoint**: URL da API do Creatmate


**Header Auth**:

Header: Authorization


Valor: Bearer SUA_API_KEY





**Body (JSON)**:


Envia:

template_id: ID copiado do template


video1, video2, video3, video4: URLs dos vídeos


audio1, audio2, audio3, audio4: URLs dos áudios






Resultado: o Creatmate processa e retorna a URL do vídeo final renderizado.




**Tempo de renderização**:


Leva em média **60 segundos**.


Ele usa um **método de polling**: espera 1 minuto, e se não estiver pronto, espera mais um pouco e tenta de novo até completar.

### Objetivo do Projeto

Criar uma máquina de criação de **vídeos virais em formato Shorts (TikTok, Instagram, YouTube)** usando **n8n** e **integrações no-code**. Todo o sistema funciona 24/7 e é alimentado por IA.

---

### Etapas do Fluxo (com Ferramentas Usadas)

1. **Entrada via Planilha Google**

   * Pega uma categoria e quatro marcas.
   * Cada linha marcada como “to-do” é processada uma vez por execução.

2. **Geração de Prompts com IA (OpenRouter com GPT-4.1)**

   * Cria prompts específicos para imagem, vídeo e áudio para cada marca.
   * Usa formatação estruturada para separar cada tipo de prompt.

3. **Criação de Imagens com FAL AI (modelo Flux Pro v1.1)**

   * Gera 4 imagens (uma por marca).
   * Configura cabeçalhos, API key e parâmetros no n8n.

4. **Conversão de Imagens em Vídeos com kling (via FAL)**

   * Usa o modelo kling para gerar vídeos cinematográficos de 5 segundos.
   * Envia imagem + prompt de vídeo.

5. **Geração de Áudio com ElevenLabs**

   * Usa o áudio prompt para criar efeitos sonoros personalizados.
   * Cada som tem 5 segundos para sincronizar com os vídeos.

6. **Upload dos Áudios para o Google Drive e Torná-los Públicos**

   * Os arquivos são compartilhados com permissões públicas para serem usados no Creatmate.

7. **Renderização Final com Creatmate**

   * Junta os 4 vídeos e 4 áudios em um único vídeo de 20 segundos.
   * Usa um template do Creatmate via API.

8. **Postagem Automática com Botato**

   * Publica automaticamente no Instagram, TikTok e YouTube Shorts.
   * Cada rede tem pequenas variações no corpo da requisição JSON.
   * Salva URL final no Google Sheets e marca como "done".

---

### Recursos 

* Workflow completo em JSON disponível para download.
* Templates prontos para Creatmate.
* Planilha modelo do Google Sheets.
* Setup guide passo a passo incluso.
