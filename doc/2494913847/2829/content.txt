### Resumo do vídeo: Curso n8n: From Zero to Hero - Configuração, Instalação e Primeiro Fluxo  
  
#### Introdução ao n8n  
- O que é n8n?  
  - Plataforma de automação de fluxos de trabalho, similar ao Make ou Zapier.  
  - Conecta aplicativos para automatizar tarefas repetitivas.  
  - Exemplo: Publicar conteúdo do Airtable no Instagram.  
  
- Características principais:  
  - Código aberto e gratuito.  
  - Controle total e privacidade (pode ser instalado localmente).  
  - Interface visual intuitiva.  
  - Não requer conhecimento de programação, mas permite incluir código.  
  
---  
  
#### Instalação do n8n  
1. Instalar Node.js:  
   - Baixar a versão LTS em nodejs .org.  
   - Executar o instalador seguindo as instruções.  
  
2. Instalar n8n usando npm:  
   - Abrir o terminal (Windows: cmd).  
   - Executar: npm install -g n8n.  
   - Iniciar o n8n: n8n start.  
   - Acessar a interface no navegador: localhost:5678.  
  
3. Configurar credenciais:  
   - Criar credenciais ao acessar pela primeira vez.  
  
---  
  
#### Criação do primeiro fluxo: Determinar se um número é par ou ímpar  
1. Adicionar um formulário como disparador:  
   - Configurar o campo para entrada de número.  
   - Tipo de dado: "número".  
  
2. Adicionar um condicional (If):  
   - Verificar se o resto da divisão do número por 2 é igual a 0.  
   - True: Número é par.  
   - False: Número é ímpar.  
  
3. Salvar e exibir resultados:  
   - Criar um nodo "Set" para salvar o resultado.  
   - Configurar mensagens específicas para os casos "par" e "ímpar".  
  
4. Testar o fluxo:  
   - Inserir valores de teste para verificar o funcionamento.  
  
---  
  
#### Conclusão  
- O vídeo apresenta o básico sobre:  
  - Instalação do n8n.  
  - Configuração inicial.  
  - Criação de um fluxo simples sem programação.  
- Próximos passos:  
  - Explorar nodos e conexões mais avançadas.  
  - Criar automatizações mais complexas.    
- Dica: Pratique para se familiarizar com a ferramenta.
