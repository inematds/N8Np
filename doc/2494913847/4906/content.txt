**"3 fluxos de trabalho de IA que você pode criar HOJE (como iniciante)"**

Como criar **três fluxos de trabalho com inteligência artificial usando a plataforma n8n**, ideal para iniciantes que queiram aprender na prática. 

Todos os fluxos são explicados detalhadamente, com configurações de credenciais, uso de APIs, integração com IA e ferramentas como Google Drive, Gmail, Pinecone, OpenAI, OpenRouter e Tavily.

### Fluxo 1: Pipeline RAG com Chatbot
- **Objetivo**: Criar um chatbot que responde com base em documentos armazenados.
- **Ferramentas usadas**:
  - Google Drive (armazenamento de documentos)
  - Pinecone (vetorização dos documentos)
  - OpenAI (modelo de embeddings)
  - OpenRouter (modelo de linguagem)
  - n8n (automação completa)
- **Conceito**: Utiliza RAG (Retrieval Augmented Generation) — o bot busca a resposta em documentos vetorizados.
- **Passos principais**:
  1. Detecção de novos arquivos no Google Drive.
  2. Vetorização do conteúdo via Pinecone.
  3. Criação de um chatbot com modelo via OpenRouter que busca as respostas no vetor.
  4. Teste do chatbot consultando, por exemplo, a política de garantia de um documento FAQ.

### Fluxo 2: Atendimento automático por e-mail (Customer Support)
- **Objetivo**: Responder automaticamente e-mails de suporte com base em uma base de conhecimento.
- **Ferramentas usadas**:
  - Gmail (recebimento e envio de e-mails)
  - Pinecone + OpenAI (mesma base vetorizada do fluxo 1)
  - n8n (automação com lógica condicional)
- **Passos principais**:
  1. Receber e-mails automaticamente via Gmail.
  2. Usar IA para classificar se o e-mail é de suporte.
  3. Se for, acionar um agente IA que responde com base no conteúdo da base vetorizada.
  4. A resposta é enviada automaticamente e pode ser etiquetada (ex: “Suporte”).

### Fluxo 3: Geração de conteúdo para LinkedIn
- **Objetivo**: Criar automaticamente posts para LinkedIn com base em tópicos definidos em uma planilha.
- **Ferramentas usadas**:
  - Google Sheets (armazenar e atualizar os tópicos e posts)
  - Tavily (pesquisa web automatizada)
  - OpenRouter (modelo de IA para redigir o post)
- **Passos principais**:
  1. Verifica a planilha em busca de tópicos marcados como “to-do”.
  2. Pesquisa o tema na web via Tavily.
  3. IA lê os resultados e redige um post para LinkedIn.
  4. O conteúdo é salvo de volta na planilha com o status atualizado.

---

### Exemplos de resultados esperados:

1. **Chatbot**: Pergunta: *Qual é a política de devolução?* → Resposta com base no documento da empresa.
2. **E-mail automático**: E-mail recebido: *Estou preocupado com meus dados* → Resposta personalizada com emojis, política de privacidade e assinatura de um agente fictício.
3. **Post para LinkedIn**: Tópico: *Geração de imagem com IA* → Post gerado automaticamente com emojis, hashtags e estrutura pronta para publicação.

Aqui estão **dicas diretas e práticas para cada fluxo**:

---

### FLUXO 1 – Chatbot com RAG (Google Drive + Pinecone + IA)

- **Use documentos bem estruturados** (títulos, tópicos claros) para melhor vetorização.
- **Divida documentos longos em chunks pequenos** (ex: 1000 caracteres) para mais precisão.
- **Dê um prompt claro ao agente**, informando que ele deve usar o "Knowledge Base" para responder.
- **Mantenha os namespaces organizados no Pinecone** (ex: `faq`, `produtos`, etc).
- **Teste com perguntas reais** que as pessoas fariam ao chatbot.

---

### FLUXO 2 – Suporte automático por e-mail

- **Ative o modo completo de e-mail (sem "simplify")** para capturar textos longos.
- **Treine bem o classificador** com exemplos reais de e-mails de suporte.
- **Use prompts amigáveis e personalizados** com emojis, assinatura e tom humano.
- **Adicione rótulos no Gmail** para facilitar triagens manuais ou auditorias.
- **Implemente um fallback** para casos que o agente não saiba responder (ex: "encaminhar para humano").

---

### FLUXO 3 – Posts para LinkedIn com IA

- **Use uma planilha com colunas: **`topic`**, **`status`**, **`content`**.
- Ev**ite temas genéricos (ex: "IA"), prefira tópicos específicos (ex: "como gerar imagens com IA").
- Pesquise via Tavily com 2–3 resultados para diversidade de fontes.
- Inclua instruções no prompt para usar emojis e hashtags.
- Agende a execução com gatilho diário e status ‘to-do’ para automação contínua.

Abaixo está o **passo a passo detalhado do Fluxo 3: Geração de conteúdo para LinkedIn com IA e pesquisa web**, usando **n8n**, **Google Sheets**, **Tavily**, **OpenRouter** e **OpenAI**.

---

### TÍTULO:  
**Fluxo 3 – Crie posts diários para LinkedIn com IA, planilha e pesquisa web no n8n**

---

### OBJETIVO:  
Automatizar a criação de posts para LinkedIn a partir de uma lista de tópicos no Google Sheets, pesquisando na web e gerando o conteúdo com IA.

---

### FERRAMENTAS NECESSÁRIAS:
- Conta no [n8n](https://n8n.io/)
- Conta no [Google Cloud Console](https://console.cloud.google.com/)
- Conta na [Tavily](https://www.tavily.com/)
- Conta na [OpenRouter](https://openrouter.ai/)
- Conta na [OpenAI](https://platform.openai.com/) (opcional)

---

### ETAPAS:

#### ETAPA 1 – Agendar ou iniciar manualmente
1. Adicione o nó **Schedule Trigger** (opcional) ou **Manual Trigger**.
2. Se quiser agendar, defina: “Todos os dias às 7h”, por exemplo.

---

#### ETAPA 2 – Obter um tópico do Google Sheets
1. Adicione o nó **Google Sheets > Get Rows**.
2. Crie a credencial via OAuth (como nos fluxos anteriores).
   - Ative a **Google Sheets API** no Google Cloud.
3. Selecione a planilha e aba correta (ex: `LinkedIn_posts`).
4. Aplique um filtro para buscar apenas linhas com status `to-do`.
5. Ative a opção **“Return only first matching row”**.

---

#### ETAPA 3 – Pesquisar o tema na web com Tavily
1. Adicione o nó **HTTP Request**.
2. Vá até [Tavily.com](https://www.tavily.com/) e crie uma conta gratuita.
3. Gere uma API Key e configure a chamada:
   - Método: POST
   - URL: `https://api.tavily.com/search`
   - Headers:
     - Authorization: `Bearer SUA_API_KEY`
     - Content-Type: `application/json`
   - Body (JSON):
     ```     {
       "query": "AI image generation",
       "search_depth": "basic",
       "num_results": 3
     }
     ```
   - Substitua `"AI image generation"` pelo campo dinâmico `{{ $json["topic"] }}`.

---

#### ETAPA 4 – Criar conteúdo com IA
1. Adicione o nó **AI Agent**.
2. No campo **"User Message"**, insira:
   - Artigo 1: `{{ $json["results"][0]["content"] }}`
   - Artigo 2: `{{ $json["results"][1]["content"] }}`
   - Artigo 3: `{{ $json["results"][2]["content"] }}`
3. No campo **"System Prompt"**, insira algo como:
   - “Você é um redator de posts para LinkedIn. Crie um post claro, criativo e impactante sobre o tema com base nos artigos fornecidos. Use emojis e hashtags.”
4. Conecte um modelo via **OpenRouter** (ex: Claude 3.5, GPT-4, Gemini, etc.).
5. Teste a geração do conteúdo.

---

#### ETAPA 5 – Atualizar a planilha com o post
1. Adicione o nó **Google Sheets > Update Row**.
2. Escolha a mesma planilha e aba.
3. No campo **“Matching Column”**, use `topic`.
4. Atualize:
   - `status` → `created`
   - `content` → Resultado do AI Agent

---

### EXEMPLO PRÁTICO:
- Linha na planilha:  
  `topic: AI image generation`, `status: to-do`
- Tavily traz 3 artigos sobre o tema.
- Agente IA gera:  
  “✨ A revolução criativa chegou! Com IA, você transforma ideias em imagens únicas. Sem precisar de designers caros. #IA #Design #Criatividade 💡🧠”
- Linha atualizada na planilha com status `created`.

---

### OPCIONAL – Tornar o processo contínuo:
- Use o nó **Google Sheets > Append Row** para gerar novos tópicos todos os dias.
- Use um **Webhook** para acionar o fluxo com clique ou integração externa.

---

### BENEFÍCIOS:
- Geração diária de conteúdo sem esforço.
- Baseado em pesquisa atual e automatizada.
- Ideal para manter presença ativa e relevante no LinkedIn.

Abaixo está o **passo a passo detalhado do Fluxo 2: Atendimento automático por e-mail com IA (Customer Support)** usando o **n8n**, **Gmail**, **Pinecone**, **OpenAI** e **OpenRouter**.

---

### TÍTULO:  
**Fluxo 2 – Responder e-mails automaticamente com IA usando RAG e n8n**

---

### OBJETIVO:  
Criar um sistema de atendimento por e-mail automatizado, onde a IA lê o conteúdo da mensagem, identifica se é suporte, consulta uma base vetorial (RAG) e responde automaticamente.

---

### FERRAMENTAS NECESSÁRIAS:
- Conta no [n8n](https://n8n.io/)
- Conta no [Gmail / Google Cloud](https://console.cloud.google.com/)
- Conta no [Pinecone.io](https://www.pinecone.io/)
- Conta na [OpenAI](https://platform.openai.com/)
- Conta no [OpenRouter.ai](https://openrouter.ai/)

---

### ETAPAS:

#### ETAPA 1 – Gatilho de novo e-mail no Gmail
1. Adicione o nó **Gmail > Trigger on New Message**.
2. Crie a credencial OAuth no Google Cloud:
   - Ative a **Gmail API**.
   - Configure a tela de consentimento.
   - Crie o client ID e o secret.
3. Conecte ao n8n usando a credencial.
4. Teste recebendo um e-mail real.

---

#### ETAPA 2 – Classificar o e-mail (é suporte ou não?)
1. Adicione o nó **Text Classifier (IA)**.
2. Use o **modelo de linguagem do OpenRouter** (ex: Claude, GPT-4, etc.).
3. Defina duas categorias:
   - `Customer Support`: e-mails com dúvidas sobre produtos, políticas ou serviços.
   - `Other`: qualquer outro tipo de e-mail.
4. Classifique o texto do e-mail (campo `text` do nó Gmail).
5. Crie dois caminhos:
   - Se for `Other`, finalize com um nó **“Do Nothing”**.
   - Se for `Customer Support`, siga para o agente de IA.

---

#### ETAPA 3 – Agente de IA para responder
1. Adicione o nó **AI Agent**.
2. No campo **"User Message"**, insira o conteúdo do e-mail recebido.
3. No campo **"System Prompt"**, oriente a IA:
   - Ex: “Você é o atendente Mr. Helpful da Tech Haven. Responda usando emojis e seja educado. Use a ferramenta ‘Knowledge Base’ para buscar informações sobre políticas.”
   - Diga para responder apenas com o **conteúdo do corpo do e-mail**, sem assunto.
4. Use modelo de linguagem via **OpenRouter**.
5. Adicione a ferramenta **Pinecone Vector Store** ao agente:
   - Configure o mesmo índice e namespace que foi criado no Fluxo 1.
   - Adicione também o **modelo de embeddings da OpenAI**.

---

#### ETAPA 4 – Responder o e-mail automaticamente
1. Adicione o nó **Gmail > Reply to Message**.
2. Pegue o **ID da mensagem original** (do primeiro nó Gmail).
3. Use o **output do agente de IA** como corpo da resposta.
4. Marque a opção para **remover a marca de "enviado via n8n"**.

---

#### ETAPA 5 – (Opcional) Adicionar rótulo no e-mail
1. Adicione o nó **Gmail > Add Label to Message**.
2. Escolha o mesmo ID do e-mail.
3. Adicione o rótulo "Customer Support".

---

### EXEMPLO PRÁTICO:
- E-mail recebido:  
  “Olá, estou preocupado com minha privacidade. Como vocês tratam meus dados?”
- Classificação: **Customer Support**
- Resposta automática:  
  “Olá 😊 Obrigado por entrar em contato! Na Tech Haven, levamos sua privacidade a sério. Seus dados são protegidos conforme nossa política. Veja os detalhes em nosso site. 🛡️”

---

### BENEFÍCIOS:
- Atendimento rápido e personalizado 24h.
- Integração com base de conhecimento vetorizada (RAG).
- Fluxo modular e expansível (suporte, vendas, finanças etc.).

Abaixo está o **passo a passo detalhado do Fluxo 1: Chatbot com RAG (Retrieval-Augmented Generation)** usando o **n8n**, **Google Drive**, **Pinecone**, **OpenAI** e **OpenRouter**.

---

### TÍTULO:  
**Fluxo 1 - Chatbot com RAG no n8n: responda perguntas com base em documentos do Google Drive**

---

### OBJETIVO:  
Criar um chatbot que responde perguntas com base no conteúdo de documentos PDF ou Google Docs, usando uma base vetorial (RAG).

---

### FERRAMENTAS NECESSÁRIAS:
- Conta no [n8n.cloud](https://n8n.io/)
- Conta no [Google Cloud Console](https://console.cloud.google.com/)
- Conta no [Pinecone.io](https://www.pinecone.io/)
- Chave da [OpenAI](https://platform.openai.com/)
- Conta no [OpenRouter.ai](https://openrouter.ai/)

---

### ETAPAS:

#### ETAPA 1 – Criar gatilho de novo arquivo no Google Drive
1. No n8n, adicione o nó **Google Drive Trigger**.
2. Configure o trigger para observar uma **pasta específica** no Drive.
3. Crie as credenciais OAuth no Google Cloud Console:
   - Ative a **Google Drive API**.
   - Configure a tela de consentimento (OAuth).
   - Crie o client ID e secret.
   - Copie e cole no n8n.
4. Teste o trigger para garantir que detecta um novo arquivo.

#### ETAPA 2 – Baixar o arquivo do Drive
1. Adicione um nó **Google Drive > Download File**.
2. Use a **ID do arquivo** do nó anterior (com `{{ $json["id"] }}`).
3. Teste e confirme que o arquivo foi baixado com sucesso (em formato binário).

#### ETAPA 3 – Configurar o Pinecone
1. Crie uma conta no [Pinecone](https://app.pinecone.io/).
2. Crie um **índice vetorial** com o modelo de embedding `text-embedding-3-small`.
3. Gere uma **API Key** no Pinecone e salve.
4. No n8n, adicione o nó **Pinecone > Add documents to vector store**.
5. Conecte:
   - O conteúdo do documento (em binário).
   - Um **text splitter** (para dividir o documento em partes).
   - Um **modelo de embeddings da OpenAI**.

#### ETAPA 4 – Configurar a OpenAI
1. Crie uma conta em [OpenAI](https://platform.openai.com/).
2. Gere uma chave de API.
3. Use o modelo `text-embedding-3-small` para vetorização.
4. Conecte o modelo de embeddings no nó de Pinecone no n8n.

#### ETAPA 5 – Criar o chatbot
1. Adicione o nó **Chat Trigger** (interface de chat interna do n8n).
2. Adicione um nó **AI Agent**.
3. Conecte o chat ao agente.
4. Configure o agente para usar um modelo da **OpenRouter** (ex: Claude, GPT, etc).
   - Gere a API key no [OpenRouter.ai](https://openrouter.ai/).
5. Conecte o agente ao Pinecone usando o mesmo índice e namespace.
6. Configure o modelo de embeddings novamente (mesmo que no passo 4).

#### ETAPA 6 – Testar o Chatbot RAG
1. Faça upload de um documento para a pasta no Google Drive.
2. O fluxo será ativado, o arquivo vetorizado e adicionado ao Pinecone.
3. Abra o chat no n8n e pergunte algo relacionado ao documento.
4. O agente buscará no Pinecone e responderá com base no conteúdo.

---

### EXEMPLO PRÁTICO:
- Documento: `policy_and_faq.pdf`
- Pergunta: “Qual é a política de garantia?”
- Resposta: O agente busca no Pinecone e responde com base no trecho vetorizado do documento.
