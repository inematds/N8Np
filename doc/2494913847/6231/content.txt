e13. Crie seu App: Lovable + Supabase + N8N

Aprendemos a criar um aplicativo no Lovable, conectá-lo com o N8N e o Supabase, e fazer com que ele responda perguntas relacionadas à comunidade usando uma base de dados vetorizada com todas as transcrições dos vídeos.

🔧 O que construímos?  
Aplicativo web do tipo chatbot criado com Lovable.

O chatbot envia perguntas para um webhook no N8N, que se conecta com uma IA para responder.

As respostas são baseadas em uma base de dados vetorizada construída no Supabase com as transcrições dos vídeos.

🪜 Passos detalhados do processo  
1. Criação do App com Lovable  
Usa-se o plano gratuito (5 interações diárias).  
É projetada uma interface moderna com cores roxas pastel e animações de chat.  
Estrutura-se um prompt longo com o ChatGPT que contém um PRD detalhado do aplicativo.  
O prompt é colado diretamente no Lovable para gerar o app.  
Configura-se a autenticação de usuários com e-mail e senha usando o Supabase.  
São criadas duas tabelas automaticamente:  
- **Perfis**: com o e-mail de cada usuário.  
- **Mensagens**: com cada interação do chat (mensagem, resposta, ID da thread, etc.).

2. Conexão com Supabase  
Conecta-se o Lovable ao Supabase para armazenar informações.  
Configura-se a tabela de documentos para guardar as transcrições vetorizadas.  
Cria-se uma sentença SQL fornecida pelo módulo de Supabase VectorStore.

3. Carga massiva de vídeos para a base vetorizada  
Utilizam-se vídeos de uma playlist no YouTube chamada Rack.  
Usa-se o N8N com um módulo do YouTube que coleta os IDs de todos os vídeos.  
Cada vídeo é transcrito usando um ator da API do Apify (YouTube Transcript Ninja).  
As transcrições são carregadas no Supabase como embeddings (modelo text-embedding-3-small).  
Usa-se um loop com controle de erros para processar os vídeos um por um e evitar sobrecarga.

4. Atualização automática com Make  
Configura-se o Make para detectar novos vídeos a cada dia.  
Envia-se o ID do vídeo para o N8N via webhook para continuar o processo de transcrição e upload.

5. Implementação do Agente de IA  
Integra-se um agente no N8N usando o GPT-4.1.  
Passa-se a mensagem do usuário, seu e-mail e ID da thread para o agente.  
O agente busca no Supabase vector store a melhor resposta.  
Caso não encontre nada, comunica de forma natural e tenta ajudar da mesma maneira.  
As respostas são estruturadas, com quebras de linha e links clicáveis.

6. Memória e contexto do chat  
Usa-se o Postgres como sistema de memória, utilizando o ID da thread como chave.  
A tabela **n8n_chat_stories** guarda o histórico de conversas por usuário.

📦 Estado atual do projeto  
O app está publicado e funcional.  
Responde corretamente a perguntas relacionadas a automações.  
Pode crescer com mais vídeos carregados no Rack.  
Está pronto para ser usado como ferramenta de consulta dentro da comunidade.


Como instalar todas as ferramentas (N8N + Supabase + Postgres) no seu servidor

Recursos

Blueprint App Camaleones  
SQL Tabelas Supabase
