**Resumo prático: como fazer a credencial ****Fal.AI**** no n8n:**

Criar **credencial HTTP Request** → Tipo: **Generic Credential Type (Header Auth)**.

No Header:

**Key**: Authorization

**Value**: Key SUA_API_KEY

Depois selecionar essa credencial no Node HTTP Request do Fel AI.

Como a nova API GPT-Image-1 da OpenAI revolucionou o marketing de produtos


O vídeo apresenta como foi criado um **sistema automático de geração de conteúdo visual e vídeos comerciais** utilizando a nova **API GPT-Image-1** da OpenAI, o **n8n**, **Google Sheets**, **Supabase** e **Fel AI**.

Principais pontos:

- A nova API **GPT-Image-1** permite gerar imagens diretamente via automação, sem interação manual.
- Um fluxo de trabalho no **n8n** foi construído para:
  - Gerar **fotos de produtos** a partir de prompts em uma planilha do Google Sheets.
  - Fazer o upload automático dessas imagens para o **Supabase**.
  - Atualizar o Google Sheets com os links das imagens.
  - Criar **vídeos comerciais** baseados nas imagens usando o **Fel AI** (modelo Cling V2).
  - Gerar **infográficos** usando pesquisa no **Perplexity** combinada com a geração de imagens no GPT-Image-1.

Demonstrações práticas:
- Inserindo uma URL e um prompt em uma planilha, o sistema gera quatro imagens de alta qualidade automaticamente.
- A seleção de uma imagem gera um **vídeo comercial** em poucos minutos.
- Infográficos são criados a partir de temas de pesquisa, com prós e contras resumidos automaticamente.

Configurações:
- Integração de **Google Sheets** para gerenciar os prompts e armazenar os resultados.
- **Supabase** configurado para armazenar publicamente as imagens geradas.
- APIs da **OpenAI**, **Fel AI** e **Perplexity** configuradas com autenticação segura.

Observações:
- Não se recomenda usar logos reais para evitar problemas de direitos autorais.
- O sistema pode ser usado por solopreneurs, e-commerces e agências para escalar conteúdo visual de forma automática e sem necessidade de codificação.

Conclusão:
- O tutorial ensina como configurar todo o fluxo no n8n de forma modular, usando apenas arrastar e soltar.
- O autor disponibilizou o fluxo pronto para download na comunidade dele.

Lista dos tópicos abordados:
1. Lançamento da API GPT-Image-1
2. Construção de sistema automático de conteúdo
3. Geração de imagens de produtos com Google Sheets + OpenAI
4. Upload automático das imagens no Supabase
5. Atualização de links no Google Sheets
6. Criação automática de vídeos comerciais via Fel AI
7. Geração de infográficos usando pesquisa no Perplexity
8. Configuração segura de APIs e autenticação
9. Boas práticas (não usar logos de marcas)
10. Disponibilização do fluxo pronto para importação e uso
