**Resumo  "How I Built an AI Agent Auto-Reply System for Threads Using Chrome Extension + n8n (100% Automated)"**

Como criar um sistema de respostas automáticas no Threads da Meta usando uma extensão do Chrome e o n8n como back-end, superando as limitações da API oficial do Threads (que só permite interações com suas próprias postagens).

**Etapas principais do processo:**

1. **Motivo da Extensão Chrome:**
   - A API da Meta é limitada e não permite responder postagens de terceiros.
   - A extensão simula ações do usuário no navegador, permitindo interações automáticas mais amplas.

2. **Requisitos:**
   - Extensão do Chrome (em modo desenvolvedor)
   - OpenAI (para gerar respostas)
   - n8n (como orquestrador backend)

3. **Funcionamento do Sistema:**
   - O usuário define palavras-chave, tipo de postagem e configurações de resposta pela extensão.
   - A extensão busca postagens no Threads e envia o conteúdo via Webhook para o n8n.
   - O n8n processa o conteúdo com o OpenAI, gera uma resposta e a devolve para a extensão.
   - A extensão então publica automaticamente a resposta no Threads.

4. **Criação da Extensão:**
   - O código da extensão é gerado com auxílio do ChatGPT.
   - Inclui os arquivos: `manifest.json`, `settings.html`, `settings.js`, `popup.html`, `popup.js`, `content.js`.
   - Os arquivos são colados no VS Code e carregados via "Load unpacked" no Chrome (modo desenvolvedor ativado).

5. **Configuração do n8n:**
   - Um Webhook recebe os dados da extensão.
   - O conteúdo é processado pelo nó do OpenAI.
   - A resposta é enviada de volta via Webhook Response.
   - A URL do Webhook é colada nas configurações da extensão.

6. **Demonstração final:**
   - Mostra como a extensão automatiza a busca, análise e resposta em tempo real, utilizando o fluxo completo entre Chrome → n8n → OpenAI → Threads.

**Exemplo prático de uso:**
- Definir palavra-chave "automação", tipo de post "recentes", e esperar respostas geradas e publicadas automaticamente no Threads.
