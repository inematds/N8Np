Passo a passo direto para criar a automação de vídeos UGC com modelo virtual:

1. Criar uma planilha no Google Sheets com colunas:

   * Nome da campanha
   * URL pública da imagem (produto + modelo IA)
   * Texto/roteiro
   * Tipo de voz (ex: voz latina, sotaque colombiano)
   * Cenário (parque, jardim, terraço, etc.)
   * Personagem (descrição do avatar)
   * Quantidade de clipes (ex: 3 ou 4)
   * Formato (9:16 ou 16:9)
   * Status (criar/feito/erro)

2. A automação lê essa planilha no n8n.

3. Analisar a imagem de referência (produto + modelo).

4. Gerar prompts automáticos:

   * Prompt para imagem de capa UGC.
   * Prompt para roteiros de cada clipe (8s, 16s, 24s...).

5. Criar a imagem inicial UGC com Seedream (recomendado), Nano Banana ou ChatGPT.

6. Gerar os clipes de vídeo:

   * Usar Veo 3 Fast (mais barato) para testes.
   * Usar Veo 3 Normal (mais consistente) para versão final.

7. Validar idioma do roteiro:

   * IA garante que os textos sejam em espanhol/português.

8. Armazenar imagens e vídeos no Supabase (gera URLs públicas automaticamente).

9. Unir os clipes com Fal.AI em um único vídeo final.

10. Atualizar a planilha com a URL final do vídeo pronto para publicar.

Hacks (com explicação curta)

1. usar seedream como primeira opção para imagem UGC
   por que: é treinado com conteúdo estilo TikTok e gera composições que “saltam” no feed.
   como aplicar: gerar 3 variações por prompt, escolher a melhor via métrica de engajamento (CTR simulado) antes de gerar vídeo.

2. prompt-engineering modular (template + variáveis)
   por que: facilita consistência e escala — um mesmo template cria roteiros para 8s/16s/24s.
   como aplicar: ter um sistema de placeholders na sheet ({{benefício}}, {{call_to_action}}, {{tom}}).

3. gerar 2 vozes por clipe (A/B) e testar com amostra pequena
   por que: sotaque/entonação muda conversão; barato testar com Veo3 Fast.
   como aplicar: criar duas linhas na planilha com mesma mídia; comparar visualizações/CTR.

4. usar Veo 3 Fast para testes e Veo 3 normal só para final
   por que: reduz custo inicial (Fast ≈ $0.40/clipe, Normal ≈ $2/clipe).
   como aplicar: rodar 8-10 variações no Fast, selecionar 1 vencedora e gerar no Normal.

5. colocar validação automática de idioma + tom antes do gerador de voz
   por que: evita clipes em inglês ou texto com inconsistências.
   como aplicar: nó de IA que detecta idioma e solicita reescrita quando necessário.

6. criar “modelo-bandeira” (avatar recurrente) para marca
   por que: identidade visual consistente aumenta reconhecimento e confiança.

Resumo da explicação da automação apresentada:

A automação gera vídeos UGC (conteúdo gerado por usuário) totalmente automáticos a partir de uma imagem do produto e de um modelo virtual criado por IA. O fluxo funciona assim:

* **Entrada via planilha (Google Sheets):** o usuário coloca nome da campanha, imagem do produto (junto de modelo virtual), roteiro, voz, cenário, personagem, número de clipes e formato.
* **Geração de prompts:** cria prompts para a primeira imagem, para o roteiro e para cada clipe de vídeo (8s, 16s etc.).
* **Criação de imagens UGC:** pode ser feita com Seedream, Nano Banana ou ChatGPT (recomendado: Seedream, pois é treinado com estilo TikTok).
* **Criação dos vídeos por clipe:** utiliza Veo 3 Fast (mais barato, US$0,40 por clipe de 8s) ou Veo 3 Normal (mais caro, US$2, mas mais consistente).
* **Validação do idioma:** um nó de IA garante que os textos falados fiquem em espanhol.
* **Combinação final:** os clipes são unidos com Fal.AI, gerando um vídeo único pronto para publicar.
* **Armazenamento:** imagens e vídeos ficam em Supabase, e os links são atualizados na planilha.

**Custos:**

* O mais caro é a geração de vídeo com Veo (Fast ou Normal).
* Restante (imagens e união dos vídeos) custa apenas centavos.

**Destaques:**

* Permite criar modelos virtuais para serem o “rosto da marca”.
* Escala produção de conteúdo sem depender de influenciadores reais.
* Focado em TikTok, Reels e Shorts.
* Blueprint completo será disponibilizado para adaptação em diferentes negócios.

e49. Modelos virtuais para seus produtos

Criar uma automação completa que gera vídeos promocionais tipo UGC (User Generated Content) a partir de uma simples imagem de produto e uma modelo gerada por IA.

Esse sistema é ideal para marcas que vendem em redes sociais e precisam de conteúdo em volume, rápido e de baixo custo, sem necessidade de gravações reais.

🛠️ O que conseguimos com essa automação?

* Gerar vídeos UGC 100% automáticos prontos para TikTok, Reels ou Shorts.
* Criar modelos virtuais personalizados como “rosto” da sua marca.
* Combinar múltiplos clipes com roteiros gerados automaticamente.
* Obter vídeos realistas sem gravações nem contratação de influenciadores.
* Escalar campanhas criativas sem custos de produção.

🧩 Estrutura do fluxo automatizado
**Input via Google Sheets**
Inserção do nome da campanha, imagem do produto (com modelo gerada por IA), roteiro desejado, estilo de voz, cenário, personagem, número de clipes, formato de vídeo etc.

**Análise da imagem de referência**
A imagem combinada do produto + modelo é analisada para gerar uma imagem inicial estilo UGC.

**Geração de prompts para imagem e roteiros**
Criação dos prompts necessários para:

* A imagem de capa.
* Cada clipe de vídeo, conforme duração (8s, 16s etc.).

**Geração de imagem UGC inicial**
Usando Seedream, Nano Banana ou ChatGPT (recomendado: Seedream), é criada a imagem principal.

**Geração de vídeos por clipe**
Criação de clipes individuais (com Veo 3 Fast ou Veo 3 Normal) utilizando os roteiros e prompts gerados.

**Validação do idioma do roteiro**
Um nó de IA intermediário garante que os textos falados estejam em espanhol.

**Combinação dos clipes**
Os vídeos gerados são unidos utilizando Fal.AI, resultando em um único vídeo UGC final.

**Resultado final**
A planilha é atualizada com a URL do vídeo final combinado, pronto para publicação.

🧰 Ferramentas utilizadas

* N8N (motor principal da automação)
* Google Sheets (como input de controle)
* Seedream / Nano Banana / ChatGPT (para geração de imagens)
* Kie.AI (plataforma de modelos IA para imagem/áudio/vídeo)
* Veo 3 Fast / Veo 3 (para geração de clipes de vídeo)
* Fal.AI (para combinar os clipes em um único vídeo)
* Supabase (para armazenar imagens públicas com URL)

🧠 Dicas-chave que aprendemos

* Use Seedream para redes sociais: gera imagens com estilo TikTok, ideal para UGCs virais.
* Toda a lógica parte de uma planilha: permite controlar campanhas em escala, até para clientes diferentes.
* Crie uma modelo única para sua marca: garante consistência visual em todas as peças.
* Otimize custos com Veo 3 Fast para testes e use Veo 3 Normal apenas quando o vídeo já estiver validado.
* Inclua validações de idioma e consistência: assegura resultados finais que não precisam de edição.
* Automação de baixo custo: exceto pela geração com Veo, o restante pode custar menos de US$ 0,10 por vídeo.

**Recursos**

* Blueprint Criador UGC
* Combinar clipes
* Criar imagem GPT Image
* Criar imagem NanoBanana
* Criar imagem Seedream
* Criar Vídeo Veo3
