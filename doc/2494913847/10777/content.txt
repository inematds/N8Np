Aqui vão **hacks e otimizações práticas** para turbinar o sistema de criação de vídeos ASMR com IA no n8n:

---

### **1. Evite refazer partes já processadas**

* Use o botão **“Pin”** em nós como:

  * OpenAI (imagem)
  * Upload para Supabase
  * Geração de vídeo ou áudio com Fai
* Assim, se der erro nos passos finais, você **não perde créditos nem gera tudo de novo.**

---

### **2. Use `.first` quando processar 1 item por vez**

* Evita erro de “não sei qual item usar”.
* Use `.item` **só se for processar múltiplos itens em paralelo.**

---

### **3. Reduza custos com IA**

* Use imagens **mais simples** (ex: textura de vidro ou papel) para economizar tokens em OpenAI.
* Use **vídeos de 3s** em vez de 5s se quiser escalar mais barato.

---

### **4. Armazene o resultado final no seu próprio banco**

* Além do Google Sheets, **gravar no Supabase ou Airtable** permite criar dashboards ou conectar com seu site.

---

### **5. Automatize a publicação nas redes**

* Após gerar o vídeo, conecte com:

  * TikTok API via CapCut Web
  * Instagram (Meta Graph API)
  * YouTube Shorts
* Assim, o conteúdo **sobe automaticamente.**

---

### **6. Crie variações de prompts**

* Use fórmulas no Google Sheets para gerar:

  * Texturas aleatórias
  * Objetos inusitados
  * Estéticas virais (ex: slime, jelly, bubble wrap)

---

### **7. Use Make ou n8n para monitorar o processo**

* Configure alertas no Telegram ou Discord para:

  * Erros no workflow
  * Notificação de vídeo pronto
  * Acompanhamento de produção diária

---

### **8. Gere thumbnails automáticas**

* Use o Creatomate ou Bannerbear para gerar **capas verticais com texto chamativo**, prontos para Shorts e Reels.

---

### **9. Escale com múltiplas planilhas**

* Crie planilhas por nicho (ex: frutas, objetos de cozinha, brinquedos) e **rode fluxos paralelos.**

---

### **10. Crie variações virais com elementos surpresa**

* Use expressões como:

  * “Before cutting, the object started to shake slightly…”
  * “Suddenly, the knife bends as it touches the surface…”

Esses detalhes criam **curiosidade** e aumentam **retenção**.

Aqui está o **passo a passo completo** para criar um sistema de **vídeos ASMR com IA no piloto automático usando o n8n**, baseado no vídeo:

---

### **1. Criar planilha no Google Sheets**

Crie uma planilha chamada `ASMR AI Video System` com as seguintes colunas:

* `Objeto` → Ex: maçã, pedra
* `Textura` → Ex: lava, vidro, pedra
* `Status` → valores: `pending` ou `complete`
* `Output` → campo para receber a URL final do vídeo

---

### **2. Criar workflow no n8n**

#### **2.1 Gatilho de Agendamento**

* Use o nó **Schedule Trigger**
* Configure para rodar automaticamente (por exemplo, a cada hora ou dia)

#### **2.2 Buscar linhas da planilha**

* Adicione o nó **Google Sheets > Get Rows**
* Configure com suas credenciais Google
* Escolha sua planilha e aba
* Adicione filtro: `Status = pending`
* Marque a opção: **"Retornar apenas a primeira linha correspondente"**

---

### **3. Criar Prompts dinâmicos**

#### **3.1 Editar Campos com Add Fields**

* Use o nó **Edit Fields**
* Crie 3 campos:

  * `prompt_img`
    *Ex:* "An {{ \$json.Objeto }} with {{ \$json.Textura }} texture and a man going to cut in half with a small knife but not started yet."
  * `prompt_video`
    *Ex:* "An {{ \$json.Objeto }} with {{ \$json.Textura }} texture and a man going to cut in half with a small knife."
  * `prompt_sound`
    *Ex:* "An ASMR sound effect of cutting {{ \$json.Objeto }} with {{ \$json.Textura }} texture."

---

### **4. Gerar imagem com OpenAI**

* Adicione o nó **OpenAI > Generate Image**
* Use o campo `prompt_img`
* Configure resolução: `1024x1024`
* Gere a imagem

---

### **5. Upload da imagem no Supabase**

* Use o nó **HTTP Request** com método `POST`
* Configure o endpoint da **storage API** do Supabase
* Faça upload da imagem e gere a **URL pública**
* Guarde essa URL para usar no vídeo

---

### **6. Gerar vídeo com IA (Fai / Kling 2.1)**

* Use o nó **HTTP Request** com método `POST`
* Endpoint da API: `https://api.fai.tools/v1/queue`
* Parâmetros:

  * `prompt`: use `prompt_video`
  * `image_url`: URL da imagem gerada
  * `duration`: 5
  * `negative_prompt`: `"blur, distortion, low quality"`
  * `cfg_scale`: 0.5
* Autenticação via **Header** com chave da API Fai

---

### **7. Recuperar URL do vídeo**

* Use outro **HTTP Request** com método `GET`
* Endpoint fornecido pela Fai
* Pegue a URL do vídeo final gerado

---

### **8. Gerar som ASMR com IA (Fai + ElevenLabs)**

* Use **HTTP Request > POST**
* Modelo: `Text to Audio`
* Use o campo `prompt_sound`
* Defina `duration = 5`

---

### **9. Recuperar URL do som**

* Outro **HTTP Request > GET**
* Pegue o link final do áudio gerado

---

### **10. Combinar vídeo + som com Creatomate**

* Use **HTTP Request > POST** para API do Creatomate
* Crie um JSON como este:

```{
  "source": {
    "output_format": "mp4",
    "width": 1080,
    "height": 1920,
    "elements": [
      { "type": "video", "track": 1, "source": "URL_DO_VÍDEO" },
      { "type": "audio", "track": 2, "source": "URL_DO_ÁUDIO" }
    ]
  }
}```

* Use sua **API Key do Creatomate** no header de autenticação

---

### **11. Atualizar a planilha com o link final**

* Use **Google Sheets > Update Row**
* Use o ID da linha original
* Mude `Status` para `complete`
* Preencha a coluna `Output` com o link final do vídeo

---

### **12. Teste final**

* Execute o workflow
* Verifique se o vídeo e o áudio foram combinados corretamente
* Veja se a planilha foi atualizada com o link final
